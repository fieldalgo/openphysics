# 단위·부호·경계조건 선택하기

[English](../../../../modeling/boundaries-units.md) | **한국어**

[문서 홈](../index.md)

경계조건은 솔버가 모델을 받아들이게 하는 조절값이 아니라 외부의 물리적 구속입니다.
실제로 제어하거나 측정하는 값부터 정한 뒤 지원되는 인터페이스를 고르세요.
[두 재료 벽](../packages/simcase/layered_wall_tutorial.md)은 온도 고정과 대류를 함께 쓰는 예제입니다.

## 열 경계조건

| 물리 상황 | 입력 | 부호와 해석 |
|---|---|---|
| 이상적인 온도 제어 표면 | K 단위 Dirichlet 온도 | 필요한 열 유입을 솔버가 `reaction`으로 계산 |
| 열 교환 없음 | 지정하지 않은 자연 경계 | 단열이며 온도 고정은 아님 |
| 알려진 외향 열유속 | `outward_flux`, W/m² | 양수는 열 제거, 음수는 열 주입 |
| 주위 매질과 열 교환 | `convection`, h와 주위 온도 K | 외향 q·n=h(T−Tamb); 주위가 더 뜨거우면 열 유입 |

지원되는 같은 모서리의 열유속과 대류는 합산됩니다. 양 끝 노드가 온도 고정된 모서리에는
이 자연 조건을 함께 넣지 마세요. JSON의 변별 조건은 모서리 온도 충돌을 거부합니다.
정상 열전도의 각 연결 성분에는 Dirichlet 기준 또는 양의 Robin 지지가 필요합니다.
h=0은 온도 기준이 아닙니다. 완전 단열 과도 문제는 저장 항이 있으므로 온도 고정점 없이
초기장에서 진화할 수 있습니다. 과도 열전도는 현재 flux/Robin을 지원하지 않으며,
정상 열→역학 wrapper도 독립 열 솔버의 모든 경계 확장을 받지는 않습니다.

정상 열에서 `sum(load + reaction)`은 처방 외향 열과 대류 유출의 합입니다.
온도 고정 경계의 외향 열은 **reaction의 음수**입니다. 양의 reaction은 물체로 들어오는
열입니다. 정확한 방정식과 callback 규칙은 [flux/Robin 계약](../packages/galerkin/thermal_flux_robin.md)을 따릅니다.

## 전기·역학 구속

- 전압은 전위를 고정합니다. 처방 외향 전류밀도 J·n은 물체 밖으로 나갈 때 양수입니다.
  Python 전기 API에는 명시적 순수 Neumann gauge 경로가 있지만 제한된 JSON 입력도
  이를 지원한다고 가정하면 안 됩니다.
- 변위 구속은 온도가 아니라 선택한 기계 성분을 고정합니다. 연결된 2D 물체에는 세 강체
  모드를 독립적으로 제거하는 구속이 필요합니다. 회전이 남는다면 임의의 자유도 세 개를
  고정하는 것만으로는 충분하지 않습니다.
- Traction은 전역 직교좌표 방향의 면적당 힘입니다. 스칼라 압력이나 총 노드 힘이 아닙니다.
  나머지 자연 경계는 해당 역학 계약의 무하중 경계입니다.
- 평면 응력과 평면 변형률은 서로 다른 물리 근사이며 정확도 옵션이 아닙니다.
  열팽창에는 기준 온도도 필요하고, 온도를 고정해도 변위가 자동으로 고정되지는 않습니다.

[전기전도](../packages/galerkin/electric_steady2d.md), [탄성](../packages/galerkin/elasticity2d.md),
[열탄성](../packages/galerkin/prescribed_temperature_thermoelasticity.md)을 함께 읽으세요.

## 길이와 돌출 깊이

| 물리량 | 단위 | 실제 돌출 깊이를 곱하나? |
|---|---|---|
| 열·역학 엔진 좌표 | m | 아니오 |
| 온도·변위·응력 | K, m, Pa | 아니오 |
| 열유속·전류밀도 | W/m², A/m² | 아니오 |
| 적분한 2D 열·전류율 | W/m, A/m | 예: W 또는 A로 환산 |
| 기계 반력·탄성 에너지 | N/m, J/m | 예: N 또는 J로 환산 |

문서 형상·메시 크기는 선언한 길이 단위를 따르고 SI 접미사 물성은 표시된 단위를 유지합니다.
메셔는 자동 물리 단위 변환을 하지 않으며 열·역학 Python 엔진은 m를 받습니다.
광학 API에는 별도 파장·길이 계약이 있으므로 모든 패키지에 SI 엔진 규칙을 일괄 적용하지 마세요.
Kelvin 입력에는 섭씨를 먼저 변환해 넣어야 합니다. 라벨만 바꿔도 숫자가 변환되지는 않습니다.

## 광학 부호는 인터페이스 경계에서 구분

`physmat`과 JSON은 수동 재료에 양의 소광계수 n+ik를 씁니다. 저수준 모드 솔버는
`exp(+i omega t-i beta z)`와 수동 손실에 대한 음의 허수 유전율을 사용합니다.
문서 실행기가 경계에서 켤레 변환하므로 문서 재료를 다시 변환하지 마세요.
이 관례에서 전방 수동 모드의 Im n_eff는 음수입니다. 모드 장은 상대 정규화된 값이며
자동으로 V/m나 단위 광전력을 의미하지 않습니다. 장 비교나 감쇠 변환 전
[손실 모드 계약](../packages/simcase/lossy_modes.md)을 읽으세요.
