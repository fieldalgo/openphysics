# 물리 문제별 안내

[문서 홈](../index.md)

먼저 풀려는 물리를 고른 뒤 실행 인터페이스를 선택하세요. OpenPhysics의 여러 패키지가
한 해석을 구성하지만, 모든 물리 조합이나 인터페이스가 지원되는 것은 아닙니다.

| 물리 문제 | 읽는 경로 |
|---|---|
| [전자기](electromagnetics.md) | 도파관 단면에서 시작해 scalar/vector 모드, 파장 sweep 또는 직육면체 공동을 선택합니다. 정전기·산란은 Python 엔진을 사용합니다. PML·누설 모드는 메시와 PML을 독립적으로 검사해야 하는 후보이며, 물리적 pole로 인증된 결과가 아닙니다. |
| [열전도](heat.md) | 정상·과도 열전도를 고른 뒤 직사각형 또는 재료 영역 형상을 선택합니다. 경계 부호, Kelvin 온도, 시간 표본과 단위 깊이당 물리량이 모델 계약의 일부입니다. |
| [전기전도·Joule 발열](electric-joule.md) | DC 전기 해석, 전기에서 열로의 단방향 전달, 온도 의존 전도도 반복을 구분합니다. 각각 입력과 수렴 조건이 다르며, 온도 의존 반복이 범용 다중물리 연계 기능을 의미하지는 않습니다. |
| [역학·열탄성 연계](mechanics.md) | 평면 응력·평면 변형률을 고르고 변위 구속과 하중을 정의합니다. 처방 온도 역학, 정상 열→역학, 선택한 과도 열 시간의 역학은 같은 메시를 사용하는 서로 다른 명시적 흐름입니다. |


## 연계 방향을 먼저 구분하기

1. **전기 → 열:** 전기 결과의 Joule source를 같은 메시의 열 해석으로 전달합니다.
2. **온도 의존 Joule:** 온도에 따른 전도도를 반복 갱신하는 제한된 정상 전기·열 문제입니다.
3. **열 → 역학:** 정상 온도 또는 저장된 과도 온도로 역학을 별도 호출하며 열로 되먹임하지 않습니다.

자세한 입력·거부 조건은 각 물리 경로의 계약을 따릅니다. 전체 지원 표는 [도구 개요](../overview.md)에 있습니다.
