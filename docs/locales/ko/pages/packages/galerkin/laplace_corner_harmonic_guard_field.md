# 두 신호선과 전위가 고정된 유한 가드 도체

`galerkin.laplace_corner_harmonic_guard_field.solve_two_ground_harmonic_corner_guard_edges`
는 두 접지 평면 사이의 유한 도체 세 개를 다루는 명시적 정적2D API입니다.
필수 `signals` 인자는0,1,2 중 서로 다른 두 인덱스의 순서를 지정합니다.
나머지 도체의 전위는0으로 고정하며, 그 도체에 유도되는 전류와 손실을
결과에 포함합니다. 측면은 기존 유계 직사각형 Green 함수의 균일 Neumann
경계를 유지합니다.

직사각형 내부에서 서로 떨어진 볼록 다각형 세 개의 리스트/튜플, 미터 단위
`width`/`height`, 명시적인 신호 인덱스를 입력합니다. 예를 들어
`signals=(0,2)`이면 도체1이 전위 고정 가드입니다. 기하 배열 순서와 활성
전류 좌표의 순서는 별개입니다. 부유 도체는 물리 조건이 다르며, 여기서는
부유 전위를 Schur 보완으로 제거하지 않습니다. 전체 세 전압 기저의 정전
용량이 C라면 활성 정전 용량은 C_SS, 전체 전류는 T I_active이며
T=C[:,S] inv(C_SS)입니다.

선택한 활성 기저를 기존 compact harmonic 조립에 입력합니다. 패널당 두
물리 방사형 기저는 모서리 지수와 Gram 가중치를 보존합니다. 제어값은 짝수
`panels_per_edge`10..512, 짝수 `ground_modes`64..4096,
`interpolation_degree=24`입니다. 기본값은 분할48과 접지 모드256입니다.
모서리의 세제곱 병합 후 변마다 n-6개 패널이 남으며 물리 패널512개·밀도
모드1024개가 상한입니다. 기본값은 사각형 도체 세 개에 맞습니다. 꼭짓점이
더 많으면 더 작은 분할값을 명시해야 합니다. 미해결 기하·구적은 대체 계산
없이 거부합니다. 행렬 조건수는1e10 미만이며 원 상반성·세분·잔차/에너지·
접지 전류 보존·면 분할·Gram 일관성의1e-10 기준을 유지합니다.

읽기 전용 `TwoGroundRectangleEdgesResult`의 두 활성 전류 좌표는 입력한
`signals` 순서입니다.

- `whole.capacitance_per_permittivity`는 무차원2x2 행렬입니다. 균일한
  물리 유전율을 곱하면 F/m입니다.
- `whole.current_gram`은 유한 도체 세 개와 평면 두 개의2x2 행렬이며
  단위는1/m입니다. 유한 도체의 행은 다각형 입력 순서입니다.
- `whole.current_integrals`는 모든 유한 도체와 평면의 부호 있는 전류를
  보존합니다. 활성 도체 행은 단위행렬이며 가드 행은0일 필요가 없습니다.
- 변별 Gram·적분 전류·원 도체 소유 인덱스·미터 좌표 끝점은 가드의 면도
  포함하여 모든 도체 면을 보존합니다.

주파수 의존 금속 법칙·거칠기·침투 깊이 조건·비균일 유전체의 별도 전계
추출은 소비자가 담당합니다. 이 정적 API 자체는 재료 모델이나 목표 검색을
제공하지 않습니다.

검증에는 전류 보존·양의 Gram·정확한 면 분할·명시적 신호/다각형 순열·반사·
물리 배율·32->48 패널 비교·두 단계의 별도 외곽 확대가 필요합니다. 등록된
테이퍼 가드 사례에는 동일 메시의4/5/6차 독립 유한요소 근거도 별도로 있으며,
이전에 미해결이었던 기준 비교는 실패 이력으로 남습니다. 다른 기하 계열은
독립 Fourier 전하로 원 세 개를 풉니다. 전위 고정 전류 계수를 각 원과 무한
접지 평면에서 다시 적분하며 Fourier 차수·구적 및 고정밀 접지 적분을
확인합니다. 최종21각형 대조에 앞서 다각형·밀도·유한 외곽을 각각 비교합니다.
유한 상자·다각형은 근사이며 등록된 사례만으로 임의 기하나 실측 정확도를
인증하지 않습니다.

기존 세 활성 도체 API는 세 도체가 모두 활성인 계약을 유지합니다. 다른
플랫폼·제품 소비자 연결·UI는 별도 검증이 필요합니다.
