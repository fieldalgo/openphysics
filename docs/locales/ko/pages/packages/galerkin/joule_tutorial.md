# 첫 Joule 발열 해석: 전력을 열로 전달하기

[English](../../../../../packages/galerkin/joule_tutorial.md) | **한국어**

기존 Python 예제를 실행하고 물리 결과를 해석한 뒤 입력을 하나씩 바꿔봅니다.
엔진을 직접 사용하므로 Studio나 plotting extra는 필요하지 않습니다.

## 시작 전

Python 3.12 이상과 활성화한 가상환경을 사용하세요. 저장소 루트에서 이 튜토리얼에
필요한 두 로컬 패키지를 설치합니다.

```sh
python -m pip install -e packages/galerkin -e packages/galerkin-refsol
```

저장소·환경 준비는 [도구 개요](../../overview.md)를 따르세요. 명령은 `packages/` 안이
아닌 저장소 루트에서 실행합니다. 이 예제들은 터미널에 출력하며 그림이나 결과 파일을 저장하지 않습니다.

## 1. 같은 메시에서 두 해석 정의하기

0.02 m × 0.01 m 직사각형의 왼쪽 전압은 0 V, 오른쪽은 2 V이며 전기전도도는 3 S/m입니다.
양 끝의 온도는 300 K, 열전도율은 5 W/(m K)입니다. 위·아래에는 법선 전류가 없고
열적으로도 단열되어 있습니다.

[예제](../../../../../../examples/galerkin/joule_heating.py)는 `solve_steady_electric`을
먼저 호출한 뒤 같은 메시에서 그 결과를 `solve_steady_joule_heat`로 전달합니다.
전기 해석의 `conductivity` 단위는 S/m, 열 해석은 W/(m K)입니다. 키워드 이름은 같아도
다른 물성입니다. 열 호출에는 K 단위의 새 경계 맵을 전달합니다. 전압은 온도가 아닙니다.

## 2. 실행과 결과 해석

```sh
python examples/galerkin/joule_heating.py
```

```text
Maximum temperature: 300.300000 K
Joule power per length: 6.000000 W/m
Outward heat per length: 6.000000 W/m
```

이 예제의 결과 크기를 보여주며, 마지막 자릿수는 달라질 수 있습니다.
전기장은 `E_x = -2/0.02 = -100` V/m, 전류밀도는 `J_x = sigma*E_x = -300` A/m²입니다.
둘의 내적은 양수여서 `Q = J·E = 30000` W/m³입니다.
깊이당 전력은 `Q*0.02*0.01 = 6` W/m이며, 실제 깊이가 1 mm이면 0.006 W입니다.
DC 문제이므로 AC 평균 계수 1/2를 곱하지 않습니다.

양 끝 온도가 `T0`로 고정된 연속체 정답은 `T(x) = T0 + Q*x*(L-x)/(2*k)`이고,
중앙 온도 상승은 `Q*L²/(8*k) = 0.3` K입니다. P1 해는 이 온도장을 표본화하지만
요소별 열유속은 여전히 근사입니다. 최고 온도 하나의 일치가 장 전체의 수렴을 뜻하지는 않습니다.

## 3. 전압과 열전도율 바꾸기

예제를 `packages/` 밖의 로컬 작업 파일로 복사한 뒤 한 번에 한 항목씩 바꾸세요.

| 변경 | 예상 최고 온도 | 깊이당 전력 | 이유 |
|---|---|---|---|
| 오른쪽 전압 4 V | 301.2 K | 24 W/m | 일정 전도도에서 Q는 전압의 제곱에 비례 |
| 오른쪽 전압 −2 V | 300.3 K | 6 W/m | E와 J가 함께 반전되어 내적은 같음 |
| 열전도율 10 W/(m K), 전압 2 V | 300.15 K | 6 W/m | 열전도가 좋아져 온도 상승은 줄지만 전력은 같음 |

이 예측은 현재의 상수 물성과 경계조건에 해당합니다. 온도 의존 전도도나 대류 문제에
일반적으로 적용되는 비례 법칙은 아닙니다. 다른 메시에서는 전기 해석을 다시 실행한 뒤
열로 전달하세요. 형상·순서·영역 대응이 같아야 하며 자동 보간은 하지 않습니다.

## 4. 단방향 전달로 충분한지 판단하기

이 예제는 전기를 한 번 풀고 열을 풉니다. 온도가 전기전도도를 바꾸지 않습니다.
그 되먹임이 필요하면 재료 유효 온도 범위와 비선형 반복 수용 조건이 있는
별도의 [온도 의존 Joule 계약](temperature_joule_heating.md)을 따르세요.

전류·전력 부호와 검증 근거는 [전기전도 계약](electric_steady2d.md)과
[Joule 계약·검증](joule_heating.md)에 있습니다.
[JSON/CLI 경로](../simcase/electric_joule.md)는 제한된 균질 직사각형 모델을 지원하며
Studio 실행은 없습니다. 해당 예제는 크기와 계수가 다르므로 그대로 실행하면 위 수치와 다릅니다.
