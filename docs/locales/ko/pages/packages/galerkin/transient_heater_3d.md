# 3D 직류 히터 펄스의 과도 열과 열탄성

[English](../../../../../packages/galerkin/transient_heater_3d.md) | **한국어**

저장소 루트에서 `python examples/galerkin/transient_heater_3d.py`를 실행합니다.
[예제](../../../../../../examples/galerkin/transient_heater_3d.py)는 좌표가 m 단위인
정적 `Mesh3D` 하나를 사용합니다. 전원을 켠 상태와 끈 상태의 직류 전도를 각각 풀고,
해당 상태에서 계산한 요소별 줄 발열밀도(W/m³)를 각 시간 구간에 전달합니다. 계산한 절점 온도
이력(K)을 준정적 열탄성에 사용합니다. 히터는 1 s에 켜지고 3 s에 꺼지며 두
전환 시각은 모두 시간 격자에 포함됩니다. 열전도는 구간 중점의 열원을 사용하고
전환 시각의 출력에는 직전에 끝난 구간의 해가 포함됩니다. 전환 직후와 7 s의
결과도 출력합니다.

슬래브 길이는 0.20 m, 정사각형 단면의 한 변은 0.05 m입니다. 초기 온도와
양단 온도는 300 K이고 옆면은 단열입니다. 양단 전압차 2 V와 전기전도도
10 S/m에서 체적 발열은 1000 W/m³, 총 전력은 0.5 W입니다. 열전도도는
2 W/(m K), 체적 열용량은 1000 J/(m³ K)입니다. 양단의 축방향 변위와 모든
노드의 횡방향 변위를 고정합니다. E = 70 GPa, ν = 0, α = 12 × 10⁻⁶/K,
무응력 온도 300 K에서 가열하면 축방향 압축응력이 생깁니다. 차단 후에는
양단을 통한 열 방출로 압축이 완화됩니다.

## 독립 슬래브 해

온도 상승 θ = T − 300 K는 영의 양단·초깃값을 갖는
C θₜ − k θₓₓ = Q I(1 ≤ t < 3)를 만족합니다. 홀수 사인 모드만 기여합니다.
홀수 n에 대해 λₙ = (k/C)(nπ/L)², a = clamp(t − 1, 0, 2) s,
b = max(t − 3, 0) s이면 sin(nπx/L)의 계수는 다음과 같습니다.

```text
Aₙ(t) = [4Q / (C nπ λₙ)] [1 − exp(−λₙ a)] exp(−λₙ b)
```

공간 평균은 Σ 2Aₙ/(nπ)입니다. 양단 축 구속으로 평균 축 변형률은 0입니다.
ν = 0에서 평균 축 응력은 −Eα mean(θ) (Pa)이고, 좌우 반력은 각각
−Aσₓₓ와 +Aσₓₓ (N)입니다. A는 단면적입니다. Fourier 계산은 시각과 위치
배열을 받아 온도장과 평균의 독립 기준을 반환합니다.

회귀 시험은 전체 이력에 걸쳐 노드 온도, 평균 축 응력, 양단 반력의 최대
오차를 각 해석 신호 최고 크기의 6%까지 허용합니다. 전환 시 온도 연속성,
냉각과 응력 완화를 검사하고 축방향 메시와 시간 간격을 따로 세분화합니다.
메시 비교는 공통 간격 1/64 s에서 축방향 4·8·16분할을, 시간 비교는
축방향 24분할에서 1/4·1/8·1/16 s를 사용합니다. 횡방향은 각각 1분할이며
공통 출력 시각에서 비교합니다. 독립 기준만 검사하려면
`python -m pytest -q tests/galerkin/test_transient_heater_3d.py -k reference`를 실행합니다.

통합 예제에서 2 s 펄스가 공급한 열은 1 J입니다. 3 s에서 중앙 단면의
온도 상승은 1.52695 K(기준 1.53838 K), 평균 축응력은 −0.87585 MPa
(기준 −0.88575 MPa)입니다. 7 s에는 각각 0.22860 K와 −0.12185 MPa로
줄어듭니다. 전체 이력 오차는 온도 0.94%, 응력과 양단 반력 각각 1.12%입니다.

그림을 그릴 때는 `solve_heater_history()`의 `(mesh, electric, heat, solid)`,
`slab_reference(time, x)`의 `(rise, mean_rise)`, `axial_history(mesh, solid)`의
`(mean_axial_stress, left_right_reaction)`을 사용할 수 있습니다. 계산한 필드는
`heat.temperature`와 `solid.steps`에서 각각의 시각 배열과 함께 읽습니다.
