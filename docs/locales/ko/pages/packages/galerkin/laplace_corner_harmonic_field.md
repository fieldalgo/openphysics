# 세 활성 도체의 정적 코너 조화기저 전계

`galerkin.laplace_corner_harmonic_field.solve_two_ground_harmonic_corner_three_active_edges`
는 두 접지 평면 사이의 유한 도체 **정확히 세 개**를 모두 활성 전압 기저로
푸는 명시적 2D 정전계·전류밀도 API다. 내부 고정 접지나 부유 가드를 선택하는
기능은 없다. 측벽은 기존 직사각형 Green 함수의 균일 Neumann 조건을 유지한다.
길이 방향 전이부나 full-wave 전파를 계산하는 기능이 아니다.

좌표는 미터다. 도체 다각형은 볼록하고 서로 떨어져 직사각형 내부에 있어야 하며,
기존 측벽 이격 조건을 따른다. `width`, `height`, 짝수 `panels_per_edge` 10..512,
짝수 `ground_modes` 64..4096, `interpolation_degree=24`를 사용한다. 기본값은
분할48·접지모드256이다. 끝의 삼차 구간을 합치면 각 변에 `n-6`개의 물리 패널이
남는다. 물리 패널512개·밀도모드1024개 한도를 유지한다. 기본 분할은 사각형 세 개에
맞고, 꼭짓점이 많은 다각형은 호출자가 작은 분할을 명시해야 한다. 예산 초과는
밀집 행렬 구성 전에 거부하며 형상이나 정확도 기준을 자동으로 대체하지 않는다.

정적 공간 기저는 `rho_p`, `sqrt(3)*(rho_(2p)-rho_p)`다. 물리 질량·코너 지수·표면
전류 Gram 가중치를 보존한다. 조화기저라는 말은 시간 고조파가 아닌 쐐기 공간
모드를 뜻한다. 반공간 블록은 기존 적분을 재사용하고, 비공개 compact 래퍼는
기하 분할 입력 범위만 바꾼다. 상부 평면·측벽 보정과 접지 Fourier 전류의 세분
검사를 유지한다. 조건수 상한은 1e10 미만이며, 평균화 전 상반성·행렬/접지 세분·
잔차/에너지·전류 균형·면 분할 검사는 1e-10을 유지하고 결과에 근거를 남긴다.

반환형 `TwoGroundRectangleEdgesResult`에는 다음 값이 있다.

- `whole.capacitance_per_permittivity`: 유전율로 나눈 무차원 3×3 정전용량.
  균일 물리 유전율을 곱하면 F/m이다.
- `whole.current_gram`: 세 도체와 두 접지 평면 각각의 3×3 행렬. 단위는 1/m이며
  독립적인 단위 도체 전류로 정규화한다.
- 면별 Gram·부호 있는 적분 전류·소유 도체·미터 단위 끝점. 배열은 불변 스냅샷이다.

면별 금속 법칙과 주파수 유전체 추출은 소비자가 담당한다. 이 정적 행렬만으로
전도도·거칠기·표피깊이 허용·재료 분산·목표 역산을 제공하지 않는다.

수치 항등식과 물리 근사를 따로 검증한다. 비대칭 사다리꼴 도체 세 개를 분할
16/32/48, 두 외곽 확대, 반사·도체 순열·이진 길이 스케일에서 확인하고 독립
4차 유한요소 전체 기저 대조를 별도로 기록한다. 원형 세 도체 한계는 독립 Fourier
표면 전하·해석적 자기 적분·접지 다중극 적분을 사용한다. 단일 원의 해석식과
Fourier 차수·구적 수렴을 먼저 검사한 뒤 유한21각형 결과를 비교한다. 다각형·
밀도·외곽 검사는 구분하며 유한 상자·다각형을 정확한 원이라고 부르지 않는다.
이 사례나 내부 잔차로 임의 형상·실측 정확도가 보장되지 않는다.

기존 공개 기하·솔버와 최소 분할 조건은 바뀌지 않는다. 미해결 고정 접지 가드
사례는 이 API의 수락 범위가 아니다. 다른 플랫폼·제품 통합·배포 수락도 뜻하지 않는다.
