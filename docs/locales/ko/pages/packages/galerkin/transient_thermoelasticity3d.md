# 온도 이력으로 계산하는 준정적 3D 열탄성

[English](../../../../../packages/galerkin/transient_thermoelasticity3d.md) | **한국어**

`galerkin.transient_thermoelasticity3d`에서
`solve_thermoelasticity_history_3d`를 가져옵니다. `time`은 초 단위의
유한하고 엄격히 증가하는 `(S,)` 배열입니다. `temperature`는 켈빈
단위의 유한한 비음수 `(S, N)` 배열입니다. 각 행은 동일한 미터 단위
`Mesh3D`의 절점 순서를 따릅니다. 과도 열전도 결과의 `time`과
`temperature`를 그대로 전달할 수 있습니다.

재료·구속·하중 키워드는 [정적 3D 솔버](thermoelasticity3d.md)와 같습니다.
각 표본은 해당 온도에서의 독립 탄성 평형으로 풀며, 미소 변형과 준정적
응답을 가정합니다. 기본값은 초기 시점을 포함한 모든 저장 시점입니다.
`sample_indices`를 제공할 때는 0부터 시작하며 중복 없이 엄격히
증가해야 합니다. 히터 주기를 확인하려면 초기 시점, 히터를 끈 시점과
냉각 시점을 포함합니다. 솔버는 선택된 행을 계산하기 전에 전체 입력
이력을 검증합니다.

결과에는 선택된 초 단위의 `time` 배열, `sample_indices` 튜플과 정적
탄성 결과를 담은 `steps` 튜플이 있습니다. 각 단계는 미터 단위 변위,
무차원 전체 변형률, Pa 단위 응력, N 단위 절점 반력을 제공합니다.
호출 이후 원본 이력을 수정해도 선택 결과는 유지됩니다.

시험은 해석적으로 구한 히터 가열·냉각 온도를 실제 탄성 솔버에 전달합니다.
완전 구속 응력과 반력은 수압 응력 기준해와 비교하고, 자유팽창과 비균일
절점 온도에서의 두 재료 응답도 확인합니다.
