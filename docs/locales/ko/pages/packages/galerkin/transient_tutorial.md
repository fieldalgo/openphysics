# 과도 열전도 튜토리얼: 입력 에너지는 어디에 저장될까?

[English](../../../../../packages/galerkin/transient_tutorial.md) | **한국어**

[정상 열전도 튜토리얼](thermal_tutorial.md) 다음에 읽으세요. 이번에는 경계 전체를 단열해
온도 고정 경계로 열이 빠져나가는 대신 내부에 축적됩니다. 계수는 설명을 위한 간단한 값이며
재료 데이터베이스의 실제 물성이 아닙니다.

## 1. 준비와 실행

Python 3.12 이상과 활성화한 가상환경을 사용합니다. 저장소 준비는
[도구 개요](../../overview.md)를 따르고 저장소 루트에서 실행하세요.

```sh
python -m pip install -e packages/galerkin
python examples/galerkin/transient_heat_uniform.py
```

[스크립트](../../../../../../examples/galerkin/transient_heat_uniform.py)는
1 m × 1 m 정사각형, 4 × 4개 셀, 초기 온도 300 K, 열전도율 2.5 W/(m K),
체적 열용량 **c=4 J/(m³ K)**, 균일 발열 **Q=8 W/m³**를 사용합니다.
체적 열용량은 밀도와 비열의 곱이며 J/(kg K) 단위의 비열 자체가 아닙니다.
`dirichlet={}`는 온도 고정 노드가 없다는 뜻이고 모든 자연 경계가 단열입니다.
정상 열전도와 달리, 이 완전 단열 연결 성분의 과도 해석에는 온도 고정점이 필요하지 않습니다.

## 2. 온도와 에너지 이력 읽기

```text
Time (s): [0.  0.1 0.3]
Mean temperature (K): [300.  300.2 300.6]
Heat content change (J/m): [0.  0.8 2.4]
Stored power after each step (W/m): [8. 8.]
```

나머지 출력은 반올림 수준의 열유속(약 1e-15 W/m² 이하)과 0인 경계 reaction입니다.
마지막 자릿수는 실행 환경에 따라 달라질 수 있습니다.

온도가 공간적으로 균일해 확산 항이 사라지므로 `c*dT/dt=Q`, 즉 `T(t)=300+2*t` K입니다.
면적 1 m²에서 돌출 깊이당 source 전력은 8 W/m이며 0.3 s까지 저장된 열 증가량은
2.4 J/m입니다. 실제 깊이가 0.01 m이면 0.024 J입니다. 온도에는 깊이를 곱하지 않습니다.
스크립트는 최초 `heat_content_j_per_m`를 빼므로 절대 열 함량 진단값이 아니라
에너지의 **변화량**을 출력합니다.

## 3. 시간 표본과 시간 단계 구분하기

| 배열 | 이 예제의 shape | 의미 |
|---|---|---|
| `time_s` | (3,) | 초기 시간을 포함한 요청 시각 |
| `temperature_k` | (3, 25) | 초기장을 포함한 세 노드 상태 |
| `heat_flux_w_m2` | (3, 32, 2) | 각 시각의 삼각형·성분별 열유속 |
| `storage_rate_w_per_m` | (2, 25) | 완료한 두 시간 구간의 저장률 |
| `reaction_w_per_m` | (2, 25) | 각 단계 후 온도 고정 경계 reaction; t0에는 없음 |

`temperature_k[0]`은 숨겨진 첫 단계를 푼 결과가 아니라 초기 상태입니다.
저장률의 0번 행은 시간 표본 0에서 1까지의 구간입니다. 솔버는 주어진 비균일 시간 간격에도
backward Euler를 적용하며 적응적 시간 간격을 선택하지 않습니다. 모든 이력을 보관하므로
메시와 시각 수가 늘면 메모리도 증가합니다. 이 API에는 streaming이나 restart가 없습니다.

## 4. 입력을 통제하며 바꾸기

스크립트를 `packages/` 밖의 로컬 작업 파일로 복사한 뒤 입력 하나씩 바꾸세요.

- `heat_source`를 16으로 두 배 늘리면 마지막 온도는 301.2 K, 열 증가량은 4.8 J/m,
  저장률은 16 W/m입니다.
- `volumetric_heat_capacity`를 8로 두 배 늘리면 마지막 온도는 300.3 K이지만 열 증가량은
  여전히 2.4 J/m입니다. 같은 입력 에너지에 대한 온도 상승이 작아집니다.
- 시각을 `[0., .05, .1, .2, .3]`으로 바꿔도 마지막 균일 온도는 300.6 K입니다.
  일정 source와 공간적으로 균일한 장은 backward Euler가 정확한 특수 경우이므로
  **시간 수렴 시험이 아닙니다.**

시간 의존 경계에서는 초기 노드 온도가 첫 시각의 처방 경계값과 일치해야 합니다.
솔버가 불일치한 초기값을 조용히 덮어쓰지 않습니다. Callback은 결정적이어야 하며,
source load는 요청된 각 구간의 오른쪽 끝 시각에서 표본화합니다.

## 5. 균일장 확인 다음 단계

배열 shape와 초기값 규칙은 [과도 열전도 계약](transient_heat.md), 독립적인 공간·시간 수렴
검사는 [검증 안내](transient_heat_validation.md)를 읽으세요. 거기 연결된 큰 수렴 예제는
검증 작업이며 이 첫 해석을 실행하기 위한 필수 단계가 아닙니다.

이 Python API는 flux/Robin 입력, 온도 의존 물성, 자동 역학 연계를 지원하지 않습니다.
별도 [JSON/CLI 문서](../simcase/thermal_transient2d.md)와
[Studio 안내](../simcase/thermal_transient_studio.md)에서 각 인터페이스의 범위를 확인하세요.
이 스크립트 자체는 파일을 저장하거나 UI를 실행하지 않습니다.
