# 두 접지면 사이의 직선 모서리별 전류

[English](../../../../../packages/galerkin/two-ground-edges.md)

`galerkin.laplace_two_ground.solve_two_ground_rectangle_edges`는
[두 접지면 솔버](two-ground.md)의 각 직선 모서리 전류를 제공한다.
`solve_two_ground_rectangle`와 입력 인수·기본값·허용 범위·거부 조건이 같고,
검사된 풀이를 한 번 수행한다. 기존 전체 표면 API의 결과와 검사는 유지한다.

```python
from galerkin.laplace_two_ground import solve_two_ground_rectangle_edges

result = solve_two_ground_rectangle_edges(
    [[[0.0038, 0.000975], [0.0042, 0.000975],
      [0.0042, 0.001025], [0.0038, 0.001025]]],
    width=0.008, height=0.002, panels_per_edge=64,
    ground_modes=128, interpolation_degree=12,
)
bottom_edge_gram = result.edge_current_gram[0]
```

## 출력과 순서

`result.whole`은 기존 `TwoGroundRectangleResult`이다. 입력 도체 표면 다음에
분리된 아래·위 접지면을 포함한다. 추가 불변 배열은 다각형 모서리만 나타낸다.

| 필드 | 크기 | 의미 |
| --- | --- | --- |
| `edge_owners` | `(E,)` | 0부터 시작하는 입력 도체 번호 |
| `edge_starts`, `edge_ends` | `(E, 2)` | 미터 단위의 방향 있는 물리 끝점 |
| `edge_current_gram` | `(E, N, N)` | 단위 전류 곱의 적분, 1/미터 |
| `edge_current_integrals` | `(E, N)` | 부호 있는 단위 전류 적분 |

`N`은 입력 도체 수, `E`는 전체 꼭짓점 수이다. 도체별 모서리는 승인된
반시계 경계를 따른다. 시계 입력은 뒤집으며, 선호 시작점으로 다시 순환시키지
않는다. 따라서 첫 모서리가 아래 면이라는 뜻은 위 예제처럼 명시적으로
정렬한 사각형에만 해당한다. 소비자는 끝점과 소유 도체로 물리 면 이름을
정해야 한다. 시작 꼭짓점을 바꾸면 모서리 순서는 달라져도 물리 결과는 같다.

각 열은 해당 도체의 전체 전류가 1이 되도록 정규화한다. 개별 모서리 전류는
양수나 음수일 수 있다. Gram은 양의 준정부호지만 비대각 원소는 음수일 수
있다. 접지면은 유한 모서리로 분할하지 않으며 `whole`에서 얻는다.

## 방법과 검사

적분 패널 전하를 단위 전류 열 `q`로 바꿀 때, 물리 길이 `l`인 패널의
기여는 `outer(q, q) / l`이다. 원래 다각형의 한 모서리에서 이 기여를
더해 모서리 Gram을 구하고 같은 패널의 부호 전류도 더한다. 전위 기울기의
유한차분·재료 법칙·인위적 모서리 평활화는 넣지 않는다.

도체별 모서리 Gram의 합은 대각 원소에 따른 분모 하한 없이 원소별 상대
`1e-10`에서 기존 전체 Gram과 일치해야 한다. 부호 합은 절대 `1e-10`을
사용한다. 유한값·상호성·크기로 정규화한 양의 준정부호도 `1e-10`에서
검사한다. `partition_error`는 전체 Gram과의 최대 원소별 상대 차이다.
미해결 분할은 `ValueError`로 거부하며 전체 표면 값으로 대체하지 않는다.

이는 일관성 검사이며 물리 정확도 보장이 아니다. 모서리 전류 때문에 각
면의 양은 패널 해상도에 민감하다. 필요한 양에 대해 패널과 유한 외곽을
세분해야 한다. 넓은 외곽에서는 명시적 접지 모드 수도 늘려야 할 수 있으며,
기존 접지 세분 검사는 해상도가 부족한 선택을 계속 거부한다.

## 검증 범위

모서리 계약 시험은 물리 끝점·부호 전류 보존·불변 스냅샷·기존 전체 결과의
정확 보존과 스케일·도체 순열·반사·방향·순환 시작점 불변식을 다룬다.
기존 입력 및 접지 세분 거부도 유지한다. 삼각형 검사는 네 모서리를
가정하지 않음을 확인하며 임의 다각형의 정확도를 인증하지 않는다.

면별 독립 정확도에는 사전 등록된 패널·메시 세분, 독립 체적 에너지 형상
미분 및 유한 외곽 검사가 추가로 필요하다. 전체 표면의 일치만으로 각 면의
정확도를 보장할 수 없다. 주파수·금속·동박 거칠기·쿠폰 실측 적합·소비자
입력 스키마는 이 API에 포함되지 않는다. 새 플랫폼·출시 인증도 아니다.

## 등록한 직사각 단면

편심 단일 도체·비대칭 쌍·근접 쌍의 세 단면에 대해 64/128/256 패널,
독립 P2 유한요소 메시 두 단계, 각 이동 면의 내부 조화 확장 두 종류를
보존합니다. 독립 계산은 패널 전류식 대신 체적 에너지 형상 미분을 씁니다.
각 면 원소는 독립값 자체를 분모로 상대 2%, 정전용량은 0.05%로
비교하며 분모 하한을 두지 않습니다. 마지막 패널·메시 변화는 각각
면 원소별 1% 이하를 요구합니다. 해석적인 평행판 사례는 독립 계산 구성을
1e-10에서 확인합니다. 독립 솔버와 수치 도구 버전은 근거 provenance에
기록하며 재생 시험은 저장값을 사용하고 FEM을 다시 풀지는 않습니다.
원 세분 풀이가 메모리 한도에 걸린 경우를 위한 별도 참조 경로는 같은 P2
방정식에 대칭 SuperLU 설정을 명시합니다. 해석식과 원래 세 coarse 결과를
1e-10에서 대조한 뒤 사용합니다. 원 자원 실패는 보존하며 이 참조 전용
변경으로 제품 솔버를 변경하지 않습니다.

별도 8/16/32 mm 외곽 상자는 접지 모드 256개를 사용하며 연속 두 변화
모두 면 원소별 1% 이하를 요구합니다. 원래 모드 128개를 쓴 편심 단일
도체 32 mm 사례는 기존 접지 검사에서 거부되었으며 통과로 계산하지
않습니다. 이는 등록한 단면의 유한 외곽 민감도이며 무한 외곽 정확도나
테이퍼·임의 다각형·실측 재료의 인증이 아닙니다.
