# 한 활성 도체와 두 고정 전위 유한 가드

`galerkin.laplace_corner_harmonic_single_active_field.solve_two_ground_harmonic_corner_single_active_edges`
는 서로 떨어진 볼록 유한 도체 세 개가 상자 내부에 있는 정적2D장을 푼다.
필수 정수 `signal`로 활성 인덱스0,1,2 중 하나를 고른다. 나머지 두 도체와
아래·위 평면은0 전위이며 옆 벽은 균일 Neumann 조건이다. 기하 순서와 활성
선택은 독립이다. 부유 기준 도체 모델이 아니다.

결과는 활성 전류 좌표 하나와 모든 물리 경계를 보존한다.
`whole.capacitance_per_permittivity`는 무차원1x1행렬이다. 전체 전류 Gram은
유한 도체 세 개와 평면 두 개 순서이며 단위는1/m다. 부호 있는 전류 적분은
두 가드의 유도 전류를 보존한다. 모든 유한 도체의 각 변에도 별도 Gram과
전류 적분이 있다. 물리 유전율을 곱하면 단위 길이당 정전용량이 된다.
소비자가 정전용량을 다시 축소하거나 가드 손실을 버릴 필요가 없다.

압축 조화기저 방식의 제어·수치 조건을 유지한다. `panels_per_edge`는 짝수
10..512, `ground_modes`는 짝수64..4096, `interpolation_degree=24`이며 기본은
48/256/24다. 전체 기하는 물리 패널512개·밀도 기저1024개 이하여야 한다.
사각형 세 개의48분할은 물리 패널504개다. 패널마다 두 물리 방사형 기저와
원래 Gram 가중치를 유지한다. 기하·적분 조건을 충족하지 못하면 자동 재시도나
대체법 없이 거부한다. 내부 상호성·세분·전류/에너지·면 분할 조건은1e-10,
조건수 한도는1e10 미만이다. 이는 일관성 검사이며 절대 오차 추정이 아니다.

등록 검증은 서로 다른 사다리꼴 도체의 독립 동일 메시 P4/P5/P6 유한요소 기준과,
독립 Fourier 원형 도체 세 개를 사용한다. 선택한 전류 계수를 원형 도체와
무한 평면에서 다시 적분하고 Fourier 차수·구적 및 다중정밀도 접지 적분을
확인한다. 직접 장은 유도 가드 전류를 포함한 고정 전위 대수 축소와 일치해야 한다.
물리 패널·다각형·밀도·독립 외곽 비교, 반사·배율·도체 순서의 기존 기준을
유지한다. 원래 실패 연구·검증 스크립트 기록은 별도로 보존한다. 검증한 사례가
임의 기하나 실측 정확도를 보증하지 않는다.

세 활성 인덱스를 전체 정전용량 결과와 대조하며 결과 스냅샷은 불변이다.
잘못된 제어는 조립 전에 거부한다. 금속 표면 법칙, 비균일 유전체, 제조 템플릿,
SIPI 소비자와 다른 플랫폼은 별도 연결·검증이 필요하다. 기존 두 활성 가드와
세 활성 API는 바꾸지 않는다.
