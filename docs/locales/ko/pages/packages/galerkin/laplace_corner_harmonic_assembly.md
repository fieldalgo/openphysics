# 정적 쐐기 조화 모드의 반공간 조립

`galerkin.laplace_corner_harmonic_assembly`의
`assemble_harmonic_corner_half_space`는 `HarmonicCornerHalfSpaceMatrix`를 반환합니다.
SI 사각형 내부의 서로 떨어진 볼록 다각형에 대해 무한 접지선 y=0 위의 로그 Green
행렬을 조립합니다. 폭과 높이는 기하 승인·정규화에만 사용하며 상단·측면 경계는
없습니다. 이 함수 자체는 전하를 풀지 않습니다.

물리 패널마다 rho_p=p/h*u^(p−1)와 sqrt(3)*(rho_2p−rho_p)를 사용하고 적분 질량은
각각1과0입니다. 시간 고조파가 아닌 정적 공간 쐐기 모드입니다. 인덱스2*i와2*i+1이
이 모드를 나타냅니다. 기존 기하 준비처럼 각 변 끝의 첫 네 세제곱 구간을 합칩니다.
분할은 짝수16–512이며 조밀 행렬 할당 전에 총 물리 패널512개·밀도 미지수1024개
한도를 검사합니다. 자원 실패 시 더 거친 방법으로 자동 전환하지 않습니다.

정확한 자기 적분과 명시적으로 승인한 far·공통 원점·separated·분할 unit-source
적분은 물리적 측도와 자체 한도를 유지합니다. 양방향 블록을 모두 계산하고,
호출자가 대칭 평균하기 전에 미세·거친 행렬 차이와 원시 상호성이 행렬 크기 기준
1e-10 이하여야 합니다. 행렬과 기하 배열은 분리된 읽기 전용 값입니다.
해결되지 않은 쌍은 패널 인덱스를 보고하고 조립을 멈춥니다.

상수 모드 부분공간, 양의 에너지, 반사·이동·방향·도체 순열·공통 축척을 검사합니다.
원형 도체의 해석해 C/epsilon=2*pi/acosh(h/a), 신호 단위 전류 제곱 적분
h/(2*pi*a*sqrt(h²−a²)), 무한 접지 적분1/(2*pi*sqrt(h²−a²))과 비교합니다.
접지 값은 별도로 세분화한 Fourier 적분으로 계산합니다. 외접 다각형이 원형 극한에
접근하는 검사이며 유한 다각형 자체가 정확한 원은 아닙니다. 유한 상단 경계 솔버,
고정 접지 도체 정확도, 실측 일치, 임의 유전체 경계의 모서리 모델이나 다른 운영체제
지원을 입증하지 않습니다.
