# 정적 쐐기 전류의 자기 적분

[English](../../../../../packages/galerkin/laplace_corner_harmonic.md) | **한국어**

`galerkin.laplace_corner_harmonic`은 볼록한 도체 모서리에서 제곱 적분 가능한
전류를 위한 두 수학 함수를 제공한다. 기존 장 솔버의 기저를 선택하거나 바꾸지 않는다.

미터 단위 길이 `h`, `u=s/h`, 지수 `0.5 < p <= 1`에 대해
`rho_a(s) = a/h * u^(a-1)`, `phi0 = rho_p`,
`phi1 = sqrt(3) * (rho_(2p) - rho_p)`로 정의한다. 적분 질량은 `[1, 0]`이다.
지수는 정적 쐐기 해의 첫 두 반지름 방향 항을 따른다. 여기서 harmonic은
Laplace 쐐기 전개를 뜻하며 시간 주파수의 고조파를 뜻하지 않는다.
`p=1`에서는 균일 밀도와 평균이 0인 선형 밀도가 된다.

- `power_panel_harmonic_gram(h, p)`는
  `integral phi_i(s) phi_j(s) ds`의 읽기 전용 대칭 2×2 행렬을 반환한다.
  단위는 미터의 역수이다.
- `power_panel_harmonic_self_log(h, p)`는
  `phi_i(s) phi_j(t) log(|s-t| / 1 metre)`의 이중 적분을 읽기 전용
  대칭 2×2 행렬로 반환한다. 무차원이다.

행과 열 순서는 `phi0, phi1`이다. 길이를 같은 비율로 바꾸면 전류 Gram은
그 비율의 역수만큼 변하고, 자기 로그 적분은 `00` 성분에만 비율의 로그가
더해진다. 물리적 정규화를 그대로 사용한다. 잘못된 실수 스칼라 입력이나
표현할 수 없는 전류 행렬은 거부한다. 작은 비영 교차 성분을 0으로 자르지 않는다.

## 안정적인 자기 모멘트

`delta=1-p`, `f=sum(k>=1) (2^k-1)*zeta(k+1,2)*delta^k`라 두면
교차 성분은 `f/sqrt(3)`, `11` 성분은 `f-3/(4*p)`이다. 구현은 양수 항
64개를 더한다. 각 계수가 최대 `3/2`이므로 남은 스칼라 급수는 허용 구간에서
`1.5*delta^65/(1-delta) < 8.14e-20`이다. 이는 급수 절단 오차의 상한이며
전체 부동소수점 또는 장 정확도의 보장은 아니다. `00` 성분은 기존 닫힌식을 유지한다.

## 검증과 한계

정확한 유리수 밀도 곱 적분으로 binary64 지수 72개를 대조한다. `0.5` 바로
위와 `1` 바로 아래의 값도 포함한다. 물리적 배율, 양의 전류 에너지, 정확한
균일 모드, 읽기 전용 저장소와 수치 거부 조건을 검사한다. 자기 로그 기준값
12개는 Duffy 분할 후 별도로 계산한 60/80자리 mpmath 각도 적분을 사용한다.
기준 계산은 반지름 방향 수학적 분해를 공유하지만 제품의 급수, digamma 또는
zeta 함수는 평가하지 않는다. 비영 성분은 바닥값 없는 상대 `1e-12`로 비교하고,
균일 모드의 교차 성분은 해석적 영으로 확인한다. 기준 도구의 정확한 버전,
라이선스, 입력, 생성기 및 값을 쓰지 않는 재비교 절차를 기록한다.

이 기능은 자기 적분에 한정된다. 상호작용 블록, 조립한 장, 고정 내부 접지 도체,
임의 유전체 경계, 손실 모델의 유효성 및 전체 2D 범위는 별도 검증이 필요하다.
이 적분만으로 실측 또는 다른 실행 환경의 검증을 주장하지 않는다.

기존 상수·선형 밀도 계열과 별도 계약은 [경계 패널](laplace_boundary.md)을 참고한다.

Far, 공통 원점, separated, mixed-source 블록은 별도 [상호작용 계약](laplace_corner_harmonic_interactions.md)을 참고한다.

[비공개 물리 모멘트](laplace_corner_harmonic_moments.md)는 다항식·접지 Fourier 투영에서 같은 질량을 보존하며 장 솔버를 공개하지 않습니다.
