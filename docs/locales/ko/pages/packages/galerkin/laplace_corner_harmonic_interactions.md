# 정적 쐐기 기저의 상호작용 블록

[English](../../../../../packages/galerkin/laplace_corner_harmonic_interactions.md) | **한국어**

`galerkin.laplace_corner_harmonic_interactions`는
[정적 쐐기 밀도 모드](laplace_corner_harmonic.md)의 상호작용을 적분한다.
`rho_a(s)=a/h*(s/h)^(a-1)`, `phi0=rho_p`,
`phi1=sqrt(3)*(rho_(2p)-rho_p)`이며 적분 질량은 `[1,0]`, 지수는 `0.5<p<=1`이다.
시간 고조파가 아닌 정적 Laplace 모드다. `p=1`이면 두 번째 모드는 평균이 0인
일반 선형 밀도가 된다.

벡터는 모두 미터 단위 평면 변위다. offset이 있는 함수에서 첫 선분은
0에서 `first`, 두 번째는 `offset`에서 `offset+second`까지다. 반환되는
2×2 행렬은 각 선분의 `0,1` 모드 순서다. 성분은
`log(distance / 1 metre)`의 적분이며 무차원이다. 공통 길이 배율의 로그는
`00` 성분에만 더해진다.

| 명시적 API | 허용 기하 | 적분 규칙 |
|---|---|---|
| `power_panel_harmonic_far_log` | 길이비 ≤64, 원점 간 거리 ≥길이 합의4배 | 요청 `n=4..64`와 `2n` 비교, 기본32 |
| `power_panel_harmonic_shared_vertex_log` | 원점을 공유하는 비중첩 방향, 길이비 ≤64 | Duffy 반지름 적분은 해석식, 각도 `n/2n`, 기본64 |
| `power_panel_harmonic_separated_log` | 길이비 ≤64, 선분 간 거리 ≥긴 길이의 절반 | 요청 `n/2n`, 기본32 |
| `power_panel_harmonic_constant_log_partitioned` | 쐐기 target과 균일 선형 source, 길이비 ≤1e6, 분리 또는 공통 끝점 | 최대128개 구간에서 고정64/128 양끝 cubic 규칙 |

모든 함수는 읽기 전용 fine/coarse `mean_log_distance` 배열, 요청 차수,
구간 수, 물리적 질량 오차를 담은 `HarmonicPanelLogResult`를 반환한다.
지수와 벡터의 모양·자료형은 유한 실수 조건을 만족해야 한다. mixed 함수는
이진 입력 그대로의 위상 검사로 내부 교차와 중첩을 거부한다.
기하 또는 수치 거부가 다른 방법의 자동 실행으로 이어지지 않는다.

`rho_p`, `rho_(2p)`의 양수 적분 측도는 해석적 정규화를 그대로 유지한다.
계산된 합으로 질량 `[1,0]`을 검사하지만 가중치를 다시 정규화하지 않는다.
질량이 0인 성분의 상수는 중심화한 로그식에서 해석적으로 제거하며,
실수 로그 절댓값 항등식으로 작은 실수 증가분을 보존한다. 물리적 길이의
로그는 `00`에만 더한다. 공통 원점 블록은 반지름 변수를 해석적으로 적분하고,
mixed 블록은 정확한 균일 source 적분과 물리적 target 밀도 계수를 사용한다.

Coarse/fine 성분 차이는 `1e-12*max(1,abs(fine))` 이하이고, 질량 오차는
`1e-12` 이하여야 한다. 이는 적분 함수의 수치 검사이며 장·이산화·물리 정확도의
상한은 아니다. 기하가 유효해도 유한 계산 한도를 넘으면 거부될 수 있다.

## 근거와 한계

저장된 mpmath1.3.0 비교71건은 far18건, 공통 원점30건, separated5건,
mixed18건이다. 비영 기준 성분에는 바닥값 없는 상대 `1e-12`를 적용한다.
기준 방법은 Taylor 모멘트, Duffy 적응형 각도 적분, 중심화하지 않은 고정밀
텐서 적분, mixed-source 항등식의 적응형 적분이다. 일부 수학 항등식 또는
적분 측도 계열을 공유한다는 점을 명시한다. 독립적인 완전한 장 솔버 비교가
아닌 구조 비교다. 버전, BSD-3-Clause 라이선스, 입력, 생성기와 값을 변경하지
않는 재비교 절차를 기록한다.

균일 공통 방향의 닫힌 적분식, 좌표 대칭, 물리적 배율, 원시 상반성,
읽기 전용 저장소와 입력·세분화 거부도 검사한다. 이전 연구의 입력 허용범위
실패와 complex-log 계산 실패는 보존하며 그 기준을 완화하지 않았다.

자기 적분과 상호작용만으로 조립 행렬, 고정 내부 접지 도체, 장 수렴,
실측 또는 다른 실행 환경을 검증했다고 볼 수 없다. 기존 솔버 API, 기본값과
기준 자료는 별도로 유지한다.
