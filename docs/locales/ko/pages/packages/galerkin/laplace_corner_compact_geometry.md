# 비공개 코너 패널의 간결한 분할

내부 `_laplace_corner_compact_geometry` 도우미는 기하만 준비합니다.
공개 심볼을 내보내지 않으며 기존 기하·장 솔버의 설정을 바꾸지 않습니다.
기존 읽기 전용 `CornerPanelGeometry`를 반환합니다.

각 변에서 3차 사상은 `t^3 / (t^3 + (1-t)^3)`입니다. 양끝의 세분 구간
네 개씩을 코너 멱 패널로 묶고 나머지는 상수 멱 패널로 둡니다.
짝수 세분 수 10부터 512까지 허용하며 물리 패널은 변마다 `count - 6`개입니다.
세분 수 10·12·14는 물리 패널 4·6·8개에 해당합니다.
코너 멱은 `pi / (2*pi - interior_angle)`이며 물리 가중치는 바꾸지 않습니다.

세분 수 8이면 서로 다른 꼭짓점에서 시작한 멱 패널이 바로 맞닿으므로 거부합니다.
10 이상이면 코너 패널 사이에 상수 패널이 있습니다. 별도 장 솔버의 기존 패널
한도 안에서 더 많은 다각형 변을 검토할 때 사용할 수 있는 위상 구조이며,
이 분할만으로 장 정확도를 확인하지는 않습니다.

볼록성·분리·상자 내부 배치·측벽 여유·미터 단위·전체 기하 패널8192 한도와
분해할 수 없는 길이 검사는 기존 계약을 유지합니다. 전체 한도는 분할 생성 전에
검사합니다. 장 조립기의 더 작은 한도는 별도로 유지하며 이 도우미를 자동으로
채택하는 장 솔버는 없습니다. 기존 공개 기하의 최소 세분 수는 여전히16입니다.

독립 검사는 유리수 3차 노드, 삼각형·직사각형의 해석적 코너 멱, 변 길이,
부호 있는 면적과 끝점 연결 수를 사용합니다. 반사·시계 방향 입력·2의 거듭제곱
길이 축척·읽기 전용 저장소도 검사합니다. 기존 세분 범위에서는 세 사각형과
정다각형의 모든 기하 기술자가 공개 기하 결과와 바이트 단위로 같습니다.
기하의 검증이며 원형 도체·유전체 접합·고정 전위 도체·장 수렴·플랫폼의 검증이 아닙니다.
