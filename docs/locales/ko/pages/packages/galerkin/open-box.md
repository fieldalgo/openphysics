# 접지 벽 없는 균질 경계 패널

[English](../../../../../packages/galerkin/open-box.md)

`galerkin.laplace_open_box.solve_open_rectangle`는 네 벽 모두 법선 플럭스가 0인
균질 직사각형 안의 정전위 닫힌 도체를 푼다. 접지 평면이 없으며, `grounds`에
적은 도체가 0 전위로 전체 귀환 전류를 나른다(unbacked coplanar 선로와 같음).
[아래 접지](laplace_boundary.md)·[두 접지](two-ground.md) 해법과 그 결과는
바뀌지 않는다. 사용 예제는 영문 문서와 같다.

| 입력 | 계약 |
|---|---|
| `polygons` | 직사각형 안쪽에 엄격히 들어가는 서로 떨어진 엄격 볼록 닫힌 다각형 1–16개([두 접지](two-ground.md) 다각형 허용 검사). |
| `width`, `height` | 유한 양수, 폭/높이 `[0.25,16]`. |
| `grounds` | 0 전위 도체의 번호: 하나 이상, 중복 없음, 신호 도체가 하나 이상 남아야 함. 필수이며 기본값이 없다. |
| `panels_per_edge` | 정수 1–256(기본 32), 전체 패널 2048개 이하, 양끝 3차 격자. |
| `interpolation_degree` | 10·12·14·16(기본 12), 차수−2와 비교. 자동 변경 없음. |

`OpenRectangleResult`는 불변 사본을 담는다:

| 필드 | 뜻 |
|---|---|
| `capacitance_per_permittivity` | `(s,s)` 모든 접지를 0 전압으로 둔 신호 전하/신호 전압 ÷ 유전율. |
| `current_gram` | `(n,s,s)`, 1/m, 입력 도체마다 하나: 신호 `i`의 적분 전류 1에 대한 `j_i*j_j` 표면 적분. |
| `current_integrals` | `(n,s)`: 신호는 단위 행렬, 접지들이 −1을 나눠 가진다. 벽에는 전류가 없다. |
| `signal_indices`, `ground_indices` | 신호와 접지의 입력 위치. |

방법은 상수 Galerkin 경계 이산화다. 모든 벽의 법선 플럭스가 0인 직사각형의
그린 함수(Neumann 함수)를 닫힌 형태로 조립한다: 높이 두 배 주기의 띠 함수에
`y'`, `−y'` 영상(위아래 벽)과 `2nW ± x'` 거울 사본(옆벽)을 더한다. 자유 공간
로그는 가까운 패널 쌍에서 정확히 적분하고 매끄러운 나머지만 tensor 상자에서
보간한다. 벽까지 거리가 자신의 크기보다 가까운 군집은 각 도체의 가장 가까운
벽 거리보다 넓지 않은 상자(최대 256개, 그보다 가까우면 필드 계산 전에 거부)를
쓰고 `smooth_interpolation_boxes`가 그 수를 보고한다.

닫힌 Neumann 직사각형의 총전하는 0이다. 그래서 핵은 `f(r)+f(r')` 꼴 항을
빼고 더한 차이까지만 정해지며, 이런 항은 공통 전위만 바꾸고 전하는 바꾸지
않는다. 각 영상의 원거리 선형 증가가 이런 항이므로 뺀다. 계는 합이 0인
부분공간(Householder 기저와 Cholesky 분해)에서 풀고 공통 전위는 나중에
되찾는다. 시험은 이런 항을 더해도 해가 같음을 확인한다.

행렬 세분·원시 상반성·잔차·전하 합·에너지·전류 보존 검사는 1e-10이며, 축약
행렬 조건수 상한은 1e10 미만이고 전류 Gram 행렬은 양의 반정부호여야 한다.
이 검사는 해결되지 않은 계산을 거부할 뿐 패널·바깥 상자 수렴을 보이지 않는다.
호출자가 자신의 형상에서 확인해야 한다.

`tests/galerkin/test_laplace_open_box.py`의 검증(이 구현을 쓰지 않는 기준과 비교):

- 핵이 독립 x 코사인 급수와 1e-12 이내로 일치한다(총전하 0으로 볼 수 없는 항을
  뺀 뒤, 폭/높이 1·4·1/4·16). 중성 쌍의 법선 미분은 모든 벽에서 0이고 원천 둘레
  플럭스는 −2π이다.
- 두 원형 도선(a/d = 0.2): 상자가 커질수록 오차가 단조 감소하며 기본의 4배
  상자에서 1e-3 미만. 상자 오차(~1/L²)와 다각형 오차(~1/n²)를 모두 외삽하면
  π/acosh(d/2a)와 1e-6 이내(관측 8.3e-8).
- 한 벽 옆과 모서리의 가는 도선이 벽 거리 상자에서 영상 전하식과 2e-4 이내.
- unbacked coplanar 선로가 같은 상자의 scikit-fem P2 부피 해와 모서리 격자 메시에서
  1e-3 이내, 세분에 따라 감소(Linux 3.0e-4, 1.3e-4, 5.4e-5).

시험 파일은 패널 세분·대칭 귀환 전류·결합 상반성·거부 사례도 다룬다. 연구 단계에서
SIPI unbacked coplanar 템플릿 3종도 P2와 비교했다(두 메시에서 1.1e-4, 4.3e-5). 이
유한 비교는 일반 정확도 자격이 아니다. 금속·주파수·거칠기·전송선 법칙은 없다.

런타임 모듈 하나를 더하며 새 의존성은 없다. 시험은 기존 BSD-3-Clause scikit-fem
기준 도구와 meshine을 쓴다. 저장소 루트에서
`python -m pytest -q tests/galerkin/test_laplace_open_box.py`를 실행한다. 한
플랫폼 결과가 다른 플랫폼을 보이지 않는다.
