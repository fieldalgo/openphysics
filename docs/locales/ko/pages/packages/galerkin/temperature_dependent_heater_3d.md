# 3D 정전압 히터의 온도 의존 저항

[English](../../../../../packages/galerkin/temperature_dependent_heater_3d.md) | **한국어**

저장소 루트에서 `python examples/galerkin/temperature_dependent_heater_3d.py`를
실행합니다. [예제](../../../../../../examples/galerkin/temperature_dependent_heater_3d.py)는
`galerkin.transient_joule_heat3d.solve_transient_joule_heat_3d`로 계산한 노드
온도를 같은 사면체 메시의 `galerkin.transient_thermoelasticity3d.solve_thermoelasticity_history_3d`에
전달합니다. 온도 의존 전도체를 상수 전기전도도 모델과 비교합니다.

비저항은 ρ(T) = ρ₀[1 + β(T − T₀)]입니다. 콜백은 사면체별 평균 절대 온도
(K)를 받아 σ(T) = σ₀/[1 + β(T − T₀)]를 S/m 단위로 반환합니다. 모델의 유효
범위는 양끝을 포함한 298–320 K이며 이 범위에서 분모는 양수입니다.
σ₀ = 10 S/m, T₀ = 300 K, β = 0.25 K⁻¹입니다. 정전압에서 온도가 올라가면
전류와 전력이 줄어드는 효과를 보기 위해 β를 크게 잡았습니다.

도체 길이는 0.20 m, 폭과 두께는 각각 0.05 m입니다. 왼쪽은 300 K로
유지하고 오른쪽은 표면 열전달계수 40 W/(m² K)로 300 K 환경에 대류
냉각합니다. 나머지 면은 열적으로 절연합니다. 양단 전압차는 1 s부터
3 s까지 2 V, 나머지 시간에는 0 V입니다. 두 전환 시각은 시간 격자점입니다.
전압은 구간 중점에서 평가하고 전도도는 수렴한 구간 끝 온도에서
평가합니다. 표의 각 시각(s)에는 직전 구간 전력(W)을 표시합니다.
전환 시 전압은 급변할 수 있으며 온도와 응력은 연속입니다.

양의 단자 전류는 도체 안으로, 양의 표면 열손실은 밖으로 흐릅니다.
전기 입력의 시간 적분과 저장열 및 경계 열손실을 J 단위로 비교합니다.
온도 단위는 K입니다. 양단의 축방향 변위와 모든 횡방향 변위를 고정하면
평균 축응력(Pa)은 압축에서 음수이며 좌우 지지 반력(N)은 도체 안을
향합니다. E = 70 GPa, ν = 0, α = 12 × 10⁻⁶/K입니다.

## 독립 단열 기준해

정전압 단열 도체는 T₀에서 균일하게 가열됩니다. θ = T − T₀일 때 입력
전력은 P₀/(1 + βθ)이며 P₀ = σ₀A ΔV²/L = 0.5 W입니다. 총 열용량은
Cᵥ Vol = 0.5 J/K입니다. Cᵥ Vol dθ/dt = P₀/(1 + βθ)를 적분하면
다음과 같습니다.

```text
θ + βθ²/2 = P₀ t / (Cᵥ Vol)
I = P₀ / [ΔV (1 + βθ)]
σₓₓ = −Eαθ
(F_left, F_right) = (−Aσₓₓ, Aσₓₓ)
```

2 s에서 온도 상승은 1.65685 K, 전류는 0.17678 A, 평균 축응력은
−1.39176 MPa입니다. 시험은 8·16·32개 시간 구간에서 1차 시간 수렴을
확인하고, 구간 끝 온도에 따른 전류로 암시적 결합을 검사합니다. 열손실
모델에서는 에너지 수지, 상수 전도도 대비 입력 에너지·온도·압축 감소,
차단 뒤 냉각과 응력 완화를 확인합니다.
`python -m pytest -q tests/galerkin/test_temperature_dependent_heater_3d.py`로
시험을 실행합니다.
