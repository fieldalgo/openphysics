# 정적 쐐기 모드의 물리적 모멘트

비공개 `_laplace_corner_harmonic_moments` 모듈은 이미 승인한 기하의 다항 투영과
접지 전류 Fourier 모멘트를 준비합니다. 공개 장 솔버나 새로운 기하·재료 승인 경로가
아닙니다. [정적 쐐기 기저](laplace_corner_harmonic.md)의 rho_p와
sqrt(3)*(rho_2p−rho_p)를 쓰며 물리적 질량은1과0, 일차 모멘트는 p/(p+1)와
sqrt(3)*p/((p+1)*(2*p+1))입니다. 구적 가중치를 재정규화하지 않습니다.

각 거듭제곱 가지를 양의 Jacobi 측도로 적분합니다. 질량0 투영에서는 공통 기준점을
빼고 매끄러운 쌍선형 투영에는 해석적 질량을 적용합니다. 접지의0차 모드는 해석식으로
전체 전하를 보존합니다. 나머지 Fourier 모드는 명시한 차수의 물리 구적으로 계산합니다.
작은 지수 차이는 `expm1`으로 계산해 접지 바로 근처와 얇은 높이에서 값을 보존합니다.
호출자가 기하 승인·자원 한도와 별도 행렬·장·패널·외곽 비교를 책임집니다.

낮은 차수 다항식은 정확한 이진 유리수 적분과 비교하며 상수·일차·쌍선형 커널,
균일 패널의 닫힌 Fourier 적분과 접지 전하를 검사합니다. 각 접지에서 거리2^-40,
높이2^-20인 경우를 쌍곡선 사인 진폭과 구면 Bessel 모멘트에 상대1e-12·절대0으로
대조합니다. 잘못된 수치적 질량과 비유한 투영은 거부합니다. 기존 선형 도우미와 장
솔버는 바꾸지 않으며 이 비공개 검사만으로 전체 장·고정 접지·실측 정확도·다른 운영체제
지원을 입증하지 않습니다.
