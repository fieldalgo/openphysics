# 3D 직류 전기 → 정상 열 → 열탄성

[English](../../../../../packages/galerkin/electrothermomechanical_3d.md) | **한국어**

저장소 루트에서 `python examples/galerkin/electrothermomechanical_3d.py`로
가열 도체 예제를 실행합니다.
예제의 `solve_electrothermal_bar(nx)`로 앞의 전기·열 계산을 실행할 수 있습니다.

1. 좌표가 m 단위인 `Mesh3D`에서 [정상 직류 전기전도](electric_steady3d.md)를 풉니다.
2. 사면체 순서를 유지한 채 `joule_power_density` (W/m³)를
   [정상 열전도](thermal3d.md)의 `heat_source_density`에 전달합니다.
3. 같은 메시에서 `heat.temperature` (K)를 `solve_thermoelasticity_3d`에
   전달합니다. 변위와 지지 반력은 노드별 (N × 3) 배열로 각각 m와 N입니다.
   전체 변형률과 인장을 양수로 하는 응력은 사면체별 대칭 텐서 (T × 3 × 3)로
   각각 무차원과 Pa입니다. 전단 변형률은 텐서 성분을 사용합니다.

고정 물성을 사용해 정적 메시에서 단방향으로 연결합니다. 길이 0.2 m,
단면 0.05 m × 0.05 m인 도체의 양단 전압차는 2 V, 전기전도도는
σ = 10 S/m, 열전도도는 k = 2 W/(m K)입니다. 왼쪽 끝은 300 K로 고정하고
오른쪽 끝은 h = 20 W/(m² K)로 300 K 환경에 대류 냉각합니다. 옆면은
절연합니다. 양끝의 축방향 변위와 모든 횡방향 변위를 고정합니다.
ν = 0, E = 70 GPa, α = 12 µm/(m K), 무응력 온도는 300 K입니다.

## 독립 기준해

옴의 법칙에서 전류는 0.25 A, 전력은 0.5 W이며
Q = σ(ΔV/L)² = 1000 W/m³입니다. 온도 상승 θ는 −k θ″ = Q,
θ(0) = 0, −k θ′(L) = h θ(L)을 만족합니다. θ(x) = b x − c x²로 두면
c = Q/(2k), b = (QL + h c L²)/(k + hL)입니다. 대류 열손실은 1/6 W,
고정 온도단의 열손실은 1/3 W이고 평균 온도 상승은 10/3 K입니다.

ν = 0, 횡변위 0에서 축방향 평형과 양단 구속을 적용하면
σₓₓ = −Eα mean(θ) = −2.8 MPa이고
uₓ(x) = α ∫₀ˣ [θ(s) − mean(θ)] ds입니다. 횡방향 수직 응력은 −Eαθ이고
전단은 0입니다. 전역 x 방향으로 왼쪽 지지 반력은 +7 kN, 오른쪽은 −7 kN입니다.

회귀 시험은 삼각형 면 위에서 대류를 독립 적분하고 전력·열수지의 상대
오차를 10⁻⁹ 이하로 검사합니다. 축방향 4·8·16 분할과 횡방향 각각 1 분할에서
해석해와 비교합니다. 최종 메시 상대 오차 한계는 온도 상승 2%, 축 변위 5%,
변형률 및 응력 텐서 15%, 양끝 반력 3%입니다. 온도·변위·변형률·응력 오차는
각 세분화 단계에서 감소해야 합니다.
