# 유한 두께 기본 메시 검증

[English](../../../../../packages/sipi/default-mesh.md) | **한국어**

[단면 API와 한계](overview.md)

모서리 목표 크기는 층 두께·트레이스 폭·트레이스 사이 간격의 최솟값 / 100이며,
각 양수 도체 두께 / 10으로 제한합니다. 이전 규칙은 도체 두께도 /100 최솟값에 넣었습니다.
정전 메시에서 고체 도체 내부는 제외되므로 아래 사례에서는 선 주변 전체를 두께 /100까지
세분하는 비용이 불필요하게 컸습니다. 해석기와 명시적 메시 옵션은 바뀌지 않습니다.

## 재현과 기준

개발 환경을 설치한 뒤 저장소 루트에서 실행합니다:

```sh
OPENBLAS_NUM_THREADS=1 python -m pytest -q tests/sipi
```

`test_default_mesh.py`는 구리 두께 0, 5, 35, 105 µm 마이크로스트립에서 기본값과 세분값을 비교합니다.
h = 1 mm, w = 1 mm, εr = 4.3, 상자 폭 40 mm, 공기 높이 20 mm입니다.
세분 시 edge_size·far_size·grade를 함께 반으로 줄이고 Z0·εeff 차이가 0.5 % 이내여야 합니다.
35 µm 구리의 균일 유전체 결합 스트립라인도 C/C0/L 및 even/odd/차동/공통 임피던스를 0.5 %로 검사합니다.
폭/간격/접지면 간격은 0.4/0.1/1 mm, εr = 4, 상자 폭은 6 mm입니다.
35 µm 마이크로스트립의 절점 수는 이전 기본값의 절반 미만이어야 합니다.
기존 해석 기준해 V1–V5의 허용오차는 그대로 유지합니다. 메시 간 일치는 민감도 검사이며 정확해의 증명이 아닙니다.

2026-10-30 KST, Linux, Python 3.12.14, NumPy 2.5.4, SciPy 1.18.1에서 SIPI 시험 36개가 모두 통과했습니다.
소스 시험 결과이며 설치 배포판·다른 플랫폼 결과는 CI에서 별도로 확인해야 합니다.

## 대표 계산 비용

위 35 µm 마이크로스트립, OpenBLAS 스레드 1개에서 측정했습니다.

| 설정 | 절점 | Z0 (Ω) | εeff | 메시 시간 (s) |
|---|---:|---:|---:|---:|
| 이전 기본값, edge 0.35 µm | 38,266 | 70.303901 | 3.064522 | 7.12 |
| 새 기본값, edge 3.5 µm | 12,034 | 70.275092 | 3.065323 | 2.56 |
| 새 기본값의 세 설정을 모두 반분 | 28,716 | 70.353904 | 3.065071 | 5.05 |

절점 수는 68.6 % 감소했습니다. 새 기본값과 세분값 사이 차이는 Z0 0.112 %, εeff 0.0083 %입니다.
시간은 한 호스트에서 한 번 측정한 관찰값으로 성능 보장이 아닙니다.
더 얇은 5 µm 사례는 여전히 계산 비용이 큽니다. 옆면을 분할하기 위해 두께 제한을 유지했기 때문입니다.
이 결과가 브라우저 성능을 증명하지는 않습니다.

## 독립 비교

비공개 연구 재현에서 새 기본값을 2026-10-26에 생성한 scikit-rf 2.2.0(BSD-3-Clause)
Hammerstad–Jensen `MLine`의 과거 출력과 비교했습니다. 이번 변경에서는 기준 도구를 **다시 실행하지 않았습니다**.
설정은 `disp='none'`, `diel='frequencyinvariant'`, `rho=0`, `rough=0`이며,
유한 두께 보정을 적용한 준정적 `zl_eff`·`ep_reff`와 비교합니다.
w/h = 0.25, 0.5, 1, 2, 4; εr = 4.3, 9.8; h = 1 mm; t = 35 µm;
상자 폭 40h·공기 높이 20h인 열 사례에서 새 기본값을 실행했습니다.

차이는 Z0 −0.194~+0.123 %, εeff +0.233~+0.652 %입니다. 이산화와 두께 근사가 다른 도구 비교이므로
보고용이며 통과 판정에 쓰지 않습니다. 해석 기준해 검증은 이 수치와 독립적입니다.
이 검사만으로 시험 범위 밖의 정확도가 입증되지는 않습니다.

새 형상에서는 메시 세분과 상자 절단을 별도로 확인해야 합니다. 이 규칙은 적응형 오차 추정기가 아니며
모든 간격·물성 대비·제조 형상을 포괄하지 않습니다.
