# 실험적 모델 작업공간

[English](../../../../../packages/simcase/workspace.md) | **한국어**

선택 의존성 `simcase[studio]`를 설치하고 `simcase-studio`를 실행한 뒤,
첫 화면의 **Open experimental model workspace**를 누르거나 같은 로컬 서버의
`/workspace`를 여세요. 기존 광학·열 편집기는 `/`에 있습니다.
별도 프록시, JavaScript 빌드, CDN 또는 새 의존성은 필요하지 않습니다.

## 모델 편집

애플리케이션을 고르고 모델 트리나 그림에서 물체·경계를 선택한 뒤 속성을
편집합니다. 광학 애플리케이션은 실제 2D 모드 계산을 실행합니다.
가열 도파관 애플리케이션은 설정 미리보기입니다. 결합 그림, 전압, 기계 조건을
선택해도 연성 물리 계산이 실행되지는 않습니다.

광학 어댑터는 실리카 안의 Si 또는 SiN 직사각형 코어와 300–900 nm 폭을
지원합니다. 높이 220 nm, 파장 1550 nm, 코어 메시 30 nm, 계산창
[-1.5, 1.5, -1.2, 1.2] µm, PEC 경계, 후보 두 개로 고정됩니다.
이 조건은 결과와 함께 표시됩니다. 다른 지원 광학 해석은 기존 편집기를
사용하세요. 작업공간이 엔진의 모든 API를 노출하지는 않습니다.

잘못된 숫자 입력은 화면을 옮겨도 유지됩니다. 저장·열기·실행 전에 수정하거나
버려야 합니다. 실행 취소·다시 실행은 최대 60회 편집을 유지하며, 결과의 입력
복원도 새 편집으로 기록합니다. 넓은 화면에서는 패널 폭을 조절할 수 있으며
브라우저에 저장됩니다. revision은 로컬 편집 순서이며 Git 커밋이 아닙니다.

모델 그림에서 확대·축소, 이동, 전체 맞춤을 사용할 수 있습니다. 그림에 포커스를
두고 +/−, 방향키, Home으로도 조작합니다. 확대는 100–400%이며 각 뷰의 카메라는
탭에서 화면을 이동해도 유지됩니다. 가열 도파관은 개념도입니다. 광학전용 뷰는 x/y 동일 축척과 nm 치수를 갖는
2D 단면입니다. 코어·계산창은 실행 문서와 같은 형상 계약을 사용합니다. 코어는
x 중심 정렬, y = 0–220 nm이며 창은 x = ±1500 nm, y = ±1200 nm입니다.
코어·실리카 배경만 표시하며 히터와 원근 투영은 제외합니다. Boundaries에서
고정된 네 PEC 경계를 확인할 수 있으며 열·기계 경계조건으로 지정하지 않습니다.
CAD 편집기는 아닙니다. 카메라 변경은 입력·편집 이력·저장 파일·계산 결과를 바꾸지 않습니다.

광학 Geometry / Bodies에서 코어 가장자리를 드래그하면 중심을 유지하며 폭을 바꿉니다. 점선 미리보기는 놓을 때 적용되고 Escape나 포인터 취소는 버립니다. 드래그 한 번은 되돌리기 한 번으로 처리합니다. 폭은 300–900 nm, 드래그 간격은 1 nm입니다. 핸들에서 방향키(10 nm, Shift: 1 nm), Home/End도 사용할 수 있으며 잘못된 숫자 입력이 있으면 조작을 차단합니다.

## 결과와 파일

최근 성공한 실행 여섯 개를 보관합니다. 후보의 장 분포를 보거나 두 실행을
비교할 수 있습니다. 후보 번호는 모드 추적 결과가 아닙니다. 장 색상은 후보마다
벡터 크기를 따로 정규화한 값이며, 광학 전력이나 공통 물리 색상 척도가 아닙니다.

입력 JSON은 설계를, 세션 JSON은 검증된 결과까지 저장합니다. 열기로 복원하며
입력 파일은 64 KiB, 세션은 16 MiB로 제한합니다. CSV·PNG 내보내기도 제공합니다.
작업공간 버전 1 형식은 headless simcase JSON 문서와 다릅니다. 새로고침만으로
노트북이 자동 복원되지 않으므로 먼저 세션을 저장하세요.

실행 전에 `/api/workspace/capabilities`를 확인합니다. 계약 버전 1과
`optical-fixed-v1` 어댑터는 위 고정 조건, `optical: true`, `coupled: false`,
`simcase_version`을 알립니다. 계약이 없거나 다르면 실행을 차단하며
**Check connection**으로 재시도합니다. 실행 시 보고된 simcase 패키지 버전을
기록하고 세션 JSON에도 보존합니다. 전체 엔진 의존성이나 Git 이력을 나타내는
정보는 아닙니다. 버전 정보가 없는 기존 버전 1 세션은 출처 미상으로 읽습니다.

## 범위와 검증

실험적 편집기이며 CAD나 범용 멀티피직스 솔버가 아닙니다. 광 흡수 → 열 → 변형과
형상 피드백은 아직 연결되지 않았습니다. 형상 그림과 결합 카드는 물리 검증의
근거가 아닙니다. 이 UI는 솔버나 수치 합격 기준을 바꾸지 않습니다.
[패키지 개요](overview.md)에 따라 서버는 로컬에서 사용하세요.

저장소 루트에서 관련 검사를 실행합니다.

```bash
node --test tests/simcase/*.cjs
python -m pytest -q tests/simcase/test_studio_workspace.py tests/simcase/test_studio.py
```

작업공간 검사는 버전·조건 협상, 숫자 입력, 편집 이력, 노트북·세션 검증, 장 데이터,
HTTP 자산을 다룹니다. 배포 검사에서도 설치 자산을 복사해 작업공간 JavaScript
검사를 실행합니다. 이 검사는 필수 전체 CI나 독립 물리 검증을 대체하지 않습니다.
