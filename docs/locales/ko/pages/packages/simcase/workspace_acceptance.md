# 작업공간 수용 점검표

[English](../../../../../packages/simcase/workspace_acceptance.md) | **한국어**

빌드를 검토할 때 [작업공간 안내](workspace.md)와 함께 사용합니다. 커밋, wheel 해시,
OS, Python, 브라우저, 명령, 결과와 실패를 기록하세요. 소스 시험, 설치 패키지 확인,
실제 브라우저 작업은 서로 다른 증거이며 하나로 다른 항목을 대신하지 않습니다.

## 자동 검사

설정된 개발 환경의 저장소 루트에서 실행합니다.

```bash
node --test tests/simcase/*.cjs
python -m pytest -q tests/simcase/test_studio_workspace.py
python tools/check_markdown_links.py
```

공통 Studio 동작을 바꿨다면 모든 `test_studio*.py` 모듈도 실행합니다. 전체 CI와 배포물
검사는 [개발 안내](../../development.md)를 따릅니다. 배포물 수용 시 `simcase.__file__`이
시험 설치 경로를 가리키는지 확인하고 설치된 자산을 제공해야 합니다. 엔진 의존성이
설치본인지 소스인지 기록하세요. 엔진 소스를 사용한 시험은 전체 스택의 독립 설치를
입증하지 않습니다.

## 브라우저 작업

사용하지 않는 로컬 포트에서 `simcase-studio --workspace`를 실행합니다. 첫 사용자
검사는 별도 브라우저 프로필이나 시험 origin에서 하며 기존 세션을 먼저 보존합니다.
시작 Applications 화면에서 실제 광학 계산과 설정 전용 연성 모델을 구분할 수 있어야 합니다.

| 작업 | 예상 관찰 |
|---|---|
| Optical waveguide 선택, 600 × 300 nm와 Silicon 설정 | Geometry와 Study가 일치하고 편집 중 자동 계산하지 않습니다. |
| 범위 밖 치수를 입력하고 다른 화면에 갔다 돌아오기 | 잘못된 초안은 보이고 Run은 차단되며 수용된 모델은 유지합니다. 수정하면 준비 상태가 돌아옵니다. |
| Mesh 생성 후 폭을 700 nm로 변경 | 명시적 재생성 전까지 이전 입력의 메시임을 표시하고 자동 계산하지 않습니다. |
| Check inputs 후 모델 변경 | 보고서가 캡처 입력과 이전 상태를 표시하며 Run은 새 입력을 다시 검증합니다. |
| 600 × 300 nm 실행, 결과 이름 지정·고정 | 실제 장과 두 후보 굴절률에 작업·입력·버전 출처를 표시합니다. |
| 700 × 300 nm 실행 후 A/B 비교 | 캡처 치수·재료를 식별할 수 있고 후보 순위가 같은 모드라는 주장을 하지 않습니다. |
| 후보·성분 변경, 지점·단면 조회 | 두 그림의 물리 좌표가 같습니다. 상대 정규화된 저장 삼각형 표본이며 보간한 절대장이 아닙니다. |
| 세션 및 선택 실행 저장 후 각각 다시 열기 | 파일 범위에 맞는 입력·결과 수·이름·고정·비교·보기를 복원합니다. 파일 출처를 표시하고 재계산하지 않습니다. |
| Browser recovery saved 확인 후 새로고침·복구 | 결과·보기가 recovered로 돌아오고 솔버는 시작하지 않습니다. 입력 Undo는 복구 문서에서 새로 시작합니다. |
| 계산 도중 Stop waiting, 입력 편집, Resume | 현재 모델을 교체하지 않고 캡처한 작업을 회수합니다. Stop waiting은 서버 계산 취소가 아닙니다. |
| 작업이 연결된 상태에서 시험 서버 재시작 | 이전 서버 식별자를 거부해 새 서버의 다른 작업과 혼동하지 않습니다. 시험 전 파일 세션을 보존합니다. |
| 기존 노트북에 저장 실행 가져오기 | 추가·교체 수를 검토하고 현재 입력·입력 Undo를 유지합니다. 충돌 내용은 노트북 전체를 보존하며 거부합니다. |
| 보관 실행 여섯 개 모두 고정 | 신규 Run은 차단하고 입력 점검·메시 생성은 허용합니다. 하나를 해제하면 보관 여유가 돌아옵니다. |
| 가열 도파관 템플릿 선택 | 설정·연결 편집은 가능하지만 연성 실행은 불가하며 가짜 열·기계 결과를 표시하지 않습니다. |

지원하려는 각 브라우저에서 키보드 선택·보이는 포커스·패널 경계·긴 실행명,
1280 × 800 및 1920 × 1080 배치와 200% 확대도 확인합니다. 미시험 조합은 명시하세요.
숫자 검증·Undo·파일 복구와 시각적 확인은 구분합니다.

## 로컬 관찰, 2026-10-26

Windows의 데스크톱 내장 브라우저에서 새로 설치한 `2d9966e` simcase wheel로
폭 600/700 nm, 높이 300 nm의 두 광학 설계를 실행하고 이름·고정,
비교·probe·단면·파일 저장·새로고침·브라우저 복구를 완료했습니다. 실행 두 개와
고정 한 개가 복원됐습니다. 해당 캡처 문서를 Python API로 다시 실행한 유효굴절률은
같은 환경에서 일치했습니다. 이는 전달·작업 흐름의 일관성 확인이며 독립 물리 정확도나
메시·계산 창 수렴 인증이 아닙니다.

비교 배치와 실행 옵션 변경 후 최종 `c46970f` 패키지는 별도로 빌드·검사했습니다.
배치는 소스 서버의 브라우저에서도 확인했으며 최종 wheel에서 처음부터 전체 사용자
흐름을 다시 실행한 것은 아닙니다. 관련 소스 Studio Python 313개와 소스 Studio
Node 202개가 통과했습니다. 설치본
작업공간 Node 73개와 HTTP·CLI 12개가 통과하고 설치 UI 바이트가 소스와 일치했습니다.
다른 엔진 패키지는 worktree 소스와 기존 의존성을 사용했습니다. 전체 저장소 CI,
전 패키지 독립 설치, 다른 OS·브라우저, 모든 화면·확대 조합, 실제 사용자 pilot는
이 관찰로 입증하지 않았습니다. 새 외부 의존성은 추가하지 않았습니다.

## 출시 판단

각 작업의 실제 결과·시간·개입·실패 원인을 보존합니다. 에이전트 브라우저 점검으로
처음 사용하는 사람의 시험을 대신하지 않습니다. 필수 CI·배포·플랫폼·접근성 검사와
합의한 사용자 pilot를 검토하기 전에는 제품 출시 준비 완료로 표시하지 않습니다.
일반 CAD 편집과 전기 → 열 → 기계 → 광학 연성은 별도 개발이며 이 점검표가 해당
기능의 가용성을 인증하지 않습니다.
