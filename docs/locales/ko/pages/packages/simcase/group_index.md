# 단일 study의 군굴절률

[English](../../../../../packages/simcase/group_index.md) | **한국어**

파장 sweep은 이미 군굴절률 `n_g = n_eff − λ0 dn_eff/dλ0`를 돌려줍니다
([개요](overview.md#추적-벡터-파장-sweep)). 단일 `em.modes2d` study는 문서가 요청할 때 이를 돌려줍니다.

```json
"results": {"group_index": {"wavelength_step": "1 nm"}}
```

## 계약

- **정의.** 진공 파장의 중앙 차분으로 n_g = n_eff − λ0 · dn_eff/dλ0입니다. 실행은 평소대로
  자기 λ0 지점을 풀므로, `effective_index`와 장은 이 선택이 없는 같은 문서의 값입니다.
  이어서 같은 메시를 λ0 − Δλ와 λ0 + Δλ에서 풉니다. sweep의 각 지점과 똑같이 재료마다
  각 파장에서 값을 구하므로 재료 분산이 들어갑니다. 옆 파장이 재료의 유효 범위 밖이면
  재료 자신의 메시지로 실행이 실패합니다.
- **대응.** λ0의 각 모드를 sweep의 분해 모드 추적기 검사로 양쪽 풀이의 후보와 대응시킵니다.
  벡터 결과는 `electric-l2-assignment-v1`, 스칼라 결과는 `scalar-l2-assignment-v1`입니다.
  검사는 다음과 같습니다.
  - 정규화한 L2 overlap 제곱의 최적 할당
  - overlap ≥ 0.8
  - 전체 할당 여유 ≥ 0.1
  - 꽉 찬 탐색의 마지막 후보가 아님
  - n_eff 1e-5 이내에 다른 후보나 다른 λ0 모드가 없음

  옆 풀이는 sweep과 같은 후보 수 max(2 mode_count, mode_count + 4)를 탐색합니다. 이것이
  추적기의 기본 설정이며, 단일 study는 `study.tracking`을 읽지 않습니다.
  λ0 풀이는 실행 자체의 풀이로 후보가 mode_count개뿐입니다. 그래서 λ0에서 축퇴 검사는
  요청한 모드끼리만 보고, 탐색 경계 검사는 없습니다. 요청하지 않은 λ0 후보와 가까운 요청
  모드는 옆 파장에서도 여전히 가까울 때만 걸립니다. 옆 풀이는 모든 후보에 대해 이를
  검사합니다. 이는 sweep의 가운데 지점보다 약한 검사입니다.
- **차분.** 대응된 세 값은 추적 sweep과 같은 2차 `np.gradient`를 거칩니다. 파장은 커널의
  마이크로미터 파장 λ0 ∓ Δλ이고, sweep 값처럼 쓴 값의 `float(정확한 미터 × 10⁶)`입니다.
- 실행은 어떤 풀이보다 먼저 세 파장에서 재료가 무손실인지 확인합니다.
- **대응되지 않은 모드**는 어느 쪽에서든 값이 없습니다. `summary.json`에서는 `null`,
  `fields.npz`에서는 NaN입니다. 이유에는 옆 파장과 실패한 검사가 나옵니다. 실행은
  실패하지 않습니다.

  같은 경우 sweep은 전체가 실패합니다. 단일 지점 선택은 식별하지 못한 모드를 알리고
  나머지는 그대로 둡니다. 흔한 예는 광섬유의 축퇴된 HE11 쌍입니다.

## 문서

| 키 | 형식 | 기본값 | 허용 |
|---|---|---|---|
| `results.group_index` | 객체 | 없음: 군굴절률 없음 | `bend`가 없는 무손실 항목의 `single` study(`pml`이 있으면 값은 복소수) |
| `results.group_index.wavelength_step` | 단위를 붙인 길이(`"1 nm"`, `"0.001 um"`, `{"value": .., "unit": ..}`) | `"1 nm"`, `defaults_applied`에 기록 | 1 pm ≤ Δλ ≤ λ0 / 20(정확한 값), 아니면 `E-DOMAIN` |

다음 경우 이 키는 `E-CONTRACT`로 거절됩니다.

- sweep과 함께 쓸 때(파장 sweep은 이미 `group_index`를 줍니다)
- `bend`와 함께 쓸 때
- 실행 시 세 파장 중 어디서든 재료가 손실성일 때

다중물리 문서는 알 수 없는 `results` 키로 거절합니다(`E-KEY-UNKNOWN`). 이번 릴리스 이전의
리더는 이름으로 거절합니다.

```text
results.group_index: unknown key "group_index" in results. … (E-KEY-UNKNOWN)
```

## 결과

- `group_index`: 기존 키이자 레지스트리 양입니다. `(지점 = 1, 모드)`, 단위 1이며
  `summary.json`과 `fields.npz`에 들어갑니다(`location` `study_points_modes`).
- `group_index_method`는 `summary.json`에만 들어갑니다.

```json
{"method": "central_difference", "wavelength_step": {"value": 1e-09, "unit": "m"},
 "tracking": "electric-l2-assignment-v1", "reasons": [null, "vacuum_wavelength 1.549 um: …"]}
```

`reasons`는 모드마다 항목이 하나입니다. 값이 있는 모드는 `null`, 없는 모드는 그 이유입니다.

**열린 경계(PML).** `pml`이 있고 `bend`가 없으면 n_eff가 복소수이므로 n_g = n_eff −
λ0 dn_eff/dλ0도 복소수입니다. 이때 `group_index`는 `effective_index`처럼 `{"re", "im"}`입니다. 옆
풀이는 항목의 PML과 목표를 그대로 씁니다. 짝짓기는 추적기의 물리 가중치를 쓰므로 겹침을 물리
창에서 잽니다. 첫 짝짓기는 목표 근처에서 하고, 탐색의 가장자리는 목표에서 가장 먼 후보입니다.
추적하는 PML sweep과 같은 방식입니다. null 규칙은 같습니다. 복소 n_g는 스펙트럼 미분이며 에너지
속도가 아닙니다. 검증(slice P3, V11)은 열린 경계 점검의 누설 슬래브를 씁니다: 실리카 500 nm 위
Si 220 nm, 그 아래 Si, PEC 옆벽, TE, 1 nm 간격. 기준값은 physmat 분산을 넣어 1549 nm와 1551 nm에서
구한 `refsol.lossy_slab.substrate_leaky_mode`의 중앙 차분 3.706654 − 2.688e-4i입니다.
- 기본 메시에서 n_g는 Re가 5.24e-3 낮고 Im이 2.7 % 벗어납니다. 거의 모두 n_eff 자체의 오차입니다:
  Re n_eff가 −4.76e-3 벗어납니다. 이 오차는 메시를 반으로 나눌 때마다 줄어듭니다.
- dn_eff/dλ0는 상대 1e-3 안입니다.
- 그래서 기본 메시에서 등록한 1e-3 / 2 % 기준은 실패했고, 결과를 본 뒤 다른 점검으로 바뀌었습니다
  ([열린 경계의 모드 식별](workspace.md#열린-경계의-모드-식별)).
- **한계.** 1D 누설 슬래브 기준값과 비교하면 dn_eff/dλ0는 배포 메시 방식에서 상대 5.6e-4에서 7.3e-4까지
  다릅니다. 코어에서 먼 메시만 세밀하게 하면 최대 1.2e-3까지 다릅니다. Re n_g로는 약 1e-3이며, 기본
  메시의 n_eff 오차(약 5e-3)보다 작습니다. 원인은 찾지 못했습니다. 시험한 경우(따로 적지 않으면 × ½에서의
  기울기 상대 오차):

  | 경우 | 기울기 오차 |
  |---|---|
  | 배포 메시 방식, × 1 / × ½ / × ¼ | 5.61e-4 / 7.29e-4 / 7.29e-4 |
  | PML 강도 3 대신 6 | 7.29e-4 |
  | PML 1 µm 대신 2 µm | 6.84e-4 |
  | 두 모형 모두 Si·SiO2 상수 굴절률 | 6.82e-4 |
  | 두 모형 모두 2 nm 간격 | 7.29e-4 |
  | 먼 영역 크기와 요소 크기를 한 번 더 반으로 | 1.18e-3 |
  | 세밀화 거리 2 µm | 1.15e-3 |

`field_layout`과 다른 모든 키는 그대로입니다. 선택이 없는 결과는 이전 릴리스의 결과와
같습니다. 로그에는 옆 파장, null 모드와 그 이유, 값이 나옵니다. 실행 시간은 단일 지점
풀이의 약 세 배이고, 옆 풀이가 후보를 더 많이 탐색하므로 조금 더 걸립니다.

계산하지 않는 것은 다음과 같습니다.

- 장 적분 군굴절률
- 손실 모드, 굽힘의 개방(PML) 모드
- 결합된 다중물리 항목
- 어떤 매개변수의 sweep
