# 내 계산의 수렴 확인하기

[English](../../../../validation/convergence.md) | **한국어**

[문서 홈](../index.md)

작은 대수 잔차는 이산 방정식을 잘 풀었다는 뜻이며 보존은 전달 물리량의 합이 맞는다는 뜻입니다.
둘 중 어느 하나만으로 이산 모델과 물리 문제 사이의 오차가 제한되지는 않습니다.

## 1. 판단할 물리량과 기준부터 정하기

물리 위치의 온도, 적분 열유량, 변위, 공동 주파수, 전파 손실 중 필요한 물리량을 고르세요.
결과를 보기 전에 사용 목적에 맞는 정확도 요구를 정합니다. 모든 실행에서 같은 물리량·단위·
경계조건·재료 법칙을 비교합니다. 새 메시에서는 노드 ID가 일반적으로 바뀌므로 같은 배열
index가 같은 점을 뜻하지 않습니다. 장은 일관된 물리 위치에서 평가하거나 norm을 적분하고,
길이가 같다는 이유로 대응하지 않는 배열을 빼지 마세요.

## 2. 한 번에 한 근사만 바꾸기

| 문제 | 독립적으로 바꿔볼 항목 |
|---|---|
| 정상 열·전기·역학 | 재료 경계·하중·큰 기울기 부근 요소 크기와 형상 표현 |
| 과도 열 | 고정 메시의 시간 간격, 시간 오차를 통제한 뒤 메시 |
| 닫힌 도파관 모드 | 메시와 외부 window, 후보 선택·추적 |
| PML·열린 모드 | 메시·물리 window·PML 두께·강도를 독립적으로 변경 |
| 공동 | 메시, 탐색 target/window, 모드 중복도와 식별 |

재료 계수나 경계조건을 바꾸는 것은 다른 물리 문제이지 수렴이 아닙니다.
모드는 단순히 반환된 첫 고유값이 아니라 적절한 계약에 따라 같은 branch 또는 subspace를 비교합니다.

## 3. 작은 수렴 표 남기기

메시·설정, 자유도, 목표 물리량, 가능한 경우 기준해 오차, 이전 해상도와의 차이를 기록하세요.
Q가 0에 가까우면 상대 오차는 무의미할 수 있으므로 타당한 절대 척도를 사용합니다.
정확한 오차를 알고 간격을 균일하게 절반으로 줄였다면
`p=log(e_coarse/e_fine)/log(2)`로 관측 차수를 추정합니다. 기준해가 없을 때 세 실행의
차이로 점근 추세를 볼 수는 있지만 진짜 오차의 증명이나 자동 수용 규칙은 아닙니다.
비단조 변화·반올림·특이점·여러 오차의 경쟁은 추정을 무효화할 수 있습니다.

벽 예제로 실행을 분리해 보존하는 연습을 합니다.

```sh
python examples/simcase/layered_wall.py out/wall-h4 --mesh-size-mm 4
python examples/simcase/layered_wall.py out/wall-h2 --mesh-size-mm 2
python examples/simcase/layered_wall.py out/wall-h1 --mesh-size-mm 1
```

source가 없는 이 벽의 정확한 구간별 선형 온도는 이미 P1 공간에 있습니다.
반올림 수준의 오차로 수렴 차수를 측정할 수는 없습니다. 실제 공간 오차가 줄어드는 예제로는
[동축 수렴 스크립트](../../../../../examples/galerkin/coax_convergence.py)가 로그 형태의
정확한 해와 비교하고 로컬 `coax_convergence.npz`를 만듭니다. 마지막 차수 >1.8 기준은
등록된 해당 문제에 속하며 모든 모델의 일반 기준이 아닙니다.

과도 해석은 같은 물리 시각에서 비교합니다. 가장 세밀한 공간 계산을 더 작은 시간 간격으로
반복해 시간 오차가 공간 오차를 가리지 않는지 확인하세요.
[과도 검증 안내](../packages/galerkin/transient_heat_validation.md)는 이산 고유모드 시간 검사와
별도의 제조해 PDE 검사를 제공합니다. 큰 이력은 많은 메모리를 요구하므로 작업량을 먼저 확인하세요.

## 4. 모델 가정과 이산화 한계 구분하기

평면 변형률 메시를 세분화해도 평면 응력 모델이 되지 않습니다. 완전 접촉 경계를 세분화해도
접촉 열저항이 생기지 않습니다. PML 설정을 바꾼다고 모든 후보가 물리적 pole로 인증되지는
않습니다. 균일 온도·상수 물성 예제는 유용한 대조군이지만 임의의 불균일·비선형 문제를
검증하지는 않습니다.

결과를 보고할 때 입력, 코드·환경 버전, 수렴 표, 비교 방법, 관측 변화, 해결하지 못한 한계를
함께 남기세요. 관련 [독립 검증](index.md)을 인용하고 자신의 검사가 추가하는 근거를 설명합니다.
좋아 보이는 그림, 완료된 실행, 저장소 CI 통과가 자신의 모델 해상도를 평가하는 일을 대신하지는 않습니다.
