# 슬래브 해석해로 도파로 검증하기

[English](../../../../validation/slab-tutorial.md) | **한국어**

[문서 홈](../index.md)

새 2D 도파로를 해석하기 전에 독립적인 분산 관계를 아는 슬래브를 사용합니다.
이 실습에서는 메시 오차와 유한 외곽 경계 때문에 생기는 오차를 구분합니다.
활성화된 환경의 저장소 루트에서 실행하세요.

```sh
python -m pip install -e packages/galerkin -e packages/galerkin-refsol
python examples/galerkin/slab_convergence.py
```

[예제](../../../../../examples/galerkin/slab_convergence.py)는 코어 굴절률 3.48,
클래딩 굴절률 1.444, 두께 0.22 µm, 파장 1.55 µm인 무손실 벡터 TE 슬래브를 풉니다.
파장 의존 내장 재료 대신 명시적인 상수 굴절률을 사용합니다. 좁은 스트립의 폭은
0.1 µm이며 모든 길이는 µm, `k0`는 역 µm 단위입니다.

## 기준 문제 맞추기

`refsol.slab.modes`는 독립적인 무한 클래딩 분산 관계를 풉니다. 대칭 TE0에서는
`κd = 2 atan(γ/κ)`이고 `κ = k0 sqrt(n_f² − n_eff²)`,
`γ = k0 sqrt(n_eff² − n_clad²)`입니다. 기본 모드 기준값은 약 **2.851738987**입니다.

벡터 스트립의 옆면 PEC는 x 방향 전기장의 TE 계열을 선택합니다. 멀리 떨어진 위·아래
경계도 PEC입니다. 이 벡터 구성에서 옆면 자연 경계는 다른 편광을 선택합니다. 벡터
경계조건을 스칼라 정식화에 옮길 때는 해당 계약을 확인하세요. 구조화 메시의 행에
두 재료 경계를 정확히 맞추어, 메시를 바꿀 때 계단형 재료 경계가 이동하지 않게 합니다.

## 창을 고정하고 메시 세분화하기

`scale`은 x와 y를 함께 세분화합니다. 양쪽 클래딩 여유 폭이 각각 1.5 µm일 때
로컬 실행에서 다음 값을 얻었습니다. 반올림한 교육용 관찰값이며 보편적인 새 합격
기준은 아닙니다.

| Scale | 유효굴절률 | TE0 기준 상대 오차 |
|---|---|---|
| 1 | 2.849397304 | 8.211e-4 |
| 2 | 2.851146825 | 2.076e-4 |
| 4 | 2.851590520 | 5.206e-5 |

두 방향의 간격을 절반으로 줄이면 오차가 약 4분의 1로 줄어듭니다. 물리적인 TE 장이
x 방향으로 일정하더라도 벡터 edge 기저가 삼각형 대각선을 통해 방향을 결합하므로,
y만 세분화하면 수렴이 정체될 수 있습니다. 비교 중 재료·파장·창·모드 선택은 유지하세요.

## 간격을 고정하고 창 확대하기

두 번째 계열은 `scale=4`를 유지하고 메시를 성기게 만드는 대신 행을 추가하여
클래딩 여유 폭을 늘립니다. 여유 폭 0.1·0.5·1.5 µm의 상대 오차는 각각 약
4.586e-2·6.530e-5·5.206e-5입니다. 좁은 창은 물리적 경계 문제 자체를 바꾸므로
메시만 세분화해도 무한 클래딩을 복원할 수 없습니다. 이 예제의 큰 창에서는 남은
오차가 주로 메시 오차 수준에 머뭅니다.

스크립트는 클래딩과 코어 굴절률 사이에서 가장 큰 실수 굴절률을 선택합니다. 이
무손실 기본 모드 대조군에 맞는 선택이며 일반적인 모드 추적이나 모든 후보의 물리적
타당성 증명은 아닙니다. 모델을 바꿀 때 편광과 장의 구속을 확인하세요. 흡수·누설
모드에는 [도파로 결과 해석](../results/waveguide-modes.md)과 PML별 검사가 필요합니다.

## 자신의 모델에 적용하기

기준해·모드 식별·메시 간격·창 크기·오차를 기록합니다. 관심 물리량의 허용 오차를
정하고 각 수치 축을 따로 세분화하세요. TE 슬래브 통과가 임의 스트립 형상·재료
데이터·흡수·방사 손실을 검증하지는 않습니다. 기존 TE/TM 편광과 2차 수렴 합격 검사는
[슬래브 테스트](../../../../../tests/galerkin/test_slab_modes.py)에 있습니다.
[수렴](convergence.md)과 [실행 기록](../results/run-records.md)을 참고하세요.
