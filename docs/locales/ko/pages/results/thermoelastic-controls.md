# 열팽창·응력·반력 해석하기

[English](../../../../results/thermoelastic-controls.md) | **한국어**

[문서 홈](../index.md)

연성 순서는 [첫 열 → 역학 튜토리얼](../packages/galerkin/thermoelastic_tutorial.md)을
따릅니다. 여기서는 역학 해석을 분리하기 위해 균일 온도를 직접 지정합니다.
`galerkin`을 설치한 환경의 저장소 루트에서 실행하세요. 열방정식을 풀거나 전체
연성 계산을 인증하는 예제는 아닙니다.

```sh
python examples/galerkin/thermoelastic_controls.py
```

[예제](../../../../../examples/galerkin/thermoelastic_controls.py)는 1 m 정사각형,
E=70 GPa, ν=0.3, α=12e-6/K, T=313.15 K, 무응력 Tref=293.15 K를 사용합니다.
따라서 `a = α(T−Tref) = 2.4e-4`이며 온도 입력은 절대 켈빈입니다.

## 구속조건을 독립적인 균일 해와 비교하기

| 모델 | 변위 | 수직응력 | 깊이당 에너지 |
|---|---|---|---|
| 면내 자유, 평면응력 | `u=a(x,y)` | 모든 수직응력 0 | 0 J/m |
| 면내 자유, 평면변형률 | `u=(1+ν)a(x,y)` | σxx=σyy=0; σzz=−Ea=−16.8 MPa | 2016 J/m |
| 경계 고정, 평면변형률 | `u=0` | σxx=σyy=σzz=−Ea/(1−2ν)=−42 MPa | 15120 J/m |

앞의 두 경우는 왼쪽 아래 x/y, 오른쪽 아래 y를 고정하여 균일한 면내 팽창을 막지
않으면서 강체 운동을 제거합니다. 해당 노드 번호는 이 구조화 메시에만 적용됩니다.
경계 고정 모델은 모든 경계 노드의 두 성분을 고정합니다. 온도 경계조건이 변위
구속조건을 부여하지는 않습니다.

평면변형률은 εzz=0이므로 두께 방향 자유 팽창이 불가능합니다. 따라서 면내 자유
상태에도 압축 σzz와 물리적 에너지가 존재합니다. 면적 A에 대해 위 두 평면변형률
에너지는 원래 3D 탄성 에너지에서 얻는 `A E a²/2`, `3 A E a²/[2(1−2ν)]`입니다.
이 에너지를 변위와 열 등가 하중 내적의 절반으로 대체하지 마세요. 무응력 상태에
남는 작은 수치 응력은 부동소수점 오차입니다.

## 반력과 결과 위치 읽기

`displacement`는 노드별 m 단위입니다. `stress`는 삼각형 중심의 `(σxx,σyy,τxy)`이며
단위는 Pa, `sigma_zz`는 별도 배열입니다. 비균일 P1 온도에서는 응력이 일반적으로
삼각형 내부에서 변하므로 중심값은 표본이며 완전한 상수 장이 아닙니다. 이 예제는
온도가 균일하므로 해석적 응력도 균일합니다.

`reaction`은 돌출 깊이당 지지 반력 N/m입니다. 물리적 체적력이나 표면력이 없으면
반력의 합과 지지 모멘트가 0에 가까워야 합니다. 예제는 둘 다 출력합니다. 경계 고정
모델의 서로 반대인 비영 반력이 평형을 이루므로, 순반력이 0이라고 무응력 상태는
아닙니다. 이 미터 규모 대조군에서 MPa 응력에 비해 반올림 잔차는 약 1e-7 N/m
수준입니다. 다른 모델에서는 규모를 고려한 허용 오차를 사용하세요.

열 등가 하중은 조립 항이며 별도의 외부 물리력이 아닙니다. 하중이 있는 모델에서는
물리적 체적력과 전체 경계 표면력을 힘·모멘트 평형에 포함합니다. N/m·J/m에 실제
깊이 m를 곱하면 N·J이고 깊이당 모멘트 단위는 N입니다.
[역학 단계 계약](../packages/galerkin/prescribed_temperature_thermoelasticity.md)과
[전체 표면력 계약](../packages/galerkin/thermoelastic_traction.md)을 참고하세요.

## 비균일 열 결과에 적용하기

응력 해석 전에 기준 온도·구속조건·평면 가정·전달한 메시의 동일성을 확인합니다.
변위·에너지·특이 지지점 모서리에서 떨어진 응력을 각각 세분화해 확인하세요. 이상화된
모서리의 증가하는 최대 응력이 곧 solver 버그나 수렴한 재료 파손 예측은 아닙니다.
정상 열 → 역학 워크플로는 단방향·소변형률입니다. 변형을 열 문제에 되먹임하거나
구조 동역학을 계산하지 않습니다. 응력을 보고할 때
[실행 기록](run-records.md)과 [수렴 근거](../validation/convergence.md)를 함께 보관하세요.
