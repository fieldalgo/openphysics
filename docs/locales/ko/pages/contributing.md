# 기여 안내

[English](../../../contributing.md) | **한국어**

OpenPhysics는 개발 중인 프로젝트입니다. [패키지 개요](overview.md)와
[구현·검증 계약](index.md)부터 확인하세요. `develop`은
통합 브랜치이자 기본 브랜치이며 pull request의 대상입니다. 기능 브랜치에는
아직 수용 검증을 통과하지 않은 작업이 있을 수 있습니다.

재현 가능한 버그나 변경 제안은 이슈로 등록하세요. 커밋, Python·운영체제 버전,
입력 단위, 최소 예제, 기대 결과와 실제 결과를 포함하세요. 첨부 전에 인증정보,
개인정보와 기밀 모델을 제거하세요. 보안 취약점은
[보안 안내](security.md)의 비공개 경로로 신고하세요.

[개요·설치 안내](overview.md)에 따라 저장소 루트에서 설치·실행하세요.
고정한 Linux 검증 환경, 선택 도구·데이터와 격리 배포 검사는
[ci 한국어 안내](../../../../ci/docs/locales/ko/pages/README.md)를 따릅니다. GitHub Actions는 활성화돼 있으며 push·pull request에서 실행됩니다.
기여 검증 시 정확한 workflow 결과와 artifact를 확인하세요.
직접 수행한 검사의 정확한 명령, 종료값, 실패와 선택 기능 skip을 기록하세요.

물리 기능 변경에는 독립 해석해와 메시 수렴 검사가 필요합니다. 기존 수치 기준을
유지하고 한계를 보고하세요. 제품 코드·주석·API·실행 예제는 영어로 작성하고,
사용법·검증 설명의 완전한 영어판과 한국어판을 함께 갱신하세요. 일부 시험의
통과나 문서 변경이 새로운 운영체제 지원을 입증하지는 않습니다.

변경 범위를 명확하게 유지하세요. 인증정보, 생성된 빌드 디렉터리, 로컬 환경 파일,
비공개 연구자료를 커밋하지 마세요. 원저작자 고지를 보존하고 새 의존성·데이터·복사한
코드의 이용 조건과 출처를 확인하세요. 기여에는 저장소의 [Apache-2.0](../../../../LICENSE)가
적용되며 제3자 자료의 예외는 [NOTICE](../../../../NOTICE)와 각 패키지 고지에 기록합니다.

기본 언어는 영어입니다. README와 기여·보안 진입 문서는 영어로 유지하고,
영어·한국어 문서와 언어 전환은 `docs/` 디렉터리 안에서만 제공합니다.
