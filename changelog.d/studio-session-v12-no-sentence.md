# Changed

## English

- Studio: opening or restoring an optical session of any version no longer adds a sentence about run numbering; a session written before version 12 holds no run numbers, its runs are numbered by their place in the file, and Studio writes an older version only when that numbering is exact. [Workspace](docs/packages/simcase/workspace.md#optical-session-files-version-12).

## 한국어

- Studio: 어떤 버전의 광학 세션을 열거나 복원해도 더는 실행 번호에 대한 문장을 붙이지 않습니다. 버전 12 이전에 쓴 세션은 실행 번호를 담지 않고 그 실행은 파일 안 자리로 번호가 매겨지며, Studio는 그 번호가 정확할 때만 이전 버전을 씁니다. [작업 공간](packages/simcase/workspace.md#광학-세션-파일버전-12).
