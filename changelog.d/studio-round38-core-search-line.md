# Changed

## English

- Studio: **Compare shows the core search above the plots** (round 38, D4). At 1440 × 900 the plots fill Compare's first view, and the round-37 button sat below them. When Compare matches no modes and a closed run has no core mode, one line under the Matched modes toolbar, above the plots, now reads *A · Run 2 has no core mode: its modes are mostly in Substrate, which touches the window edge.* with the round-37 button moved onto it and labelled *Use Run 2's inputs with search near 2.46 · 4 modes*. Its action and the Messages line are unchanged: it makes that run's inputs current, sets the shortcut and opens Model, running nothing. The description keeps its reason and its *Open Run 2 in Results* link. Opening Compare no longer scrolls past the line. The matching, mode numbers, values, file formats, run records and the *Slab modes first* dialog are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare가 코어 검색을 그림 위에 보여 줍니다**(38차, D4). 1440 × 900에서는 그림이 Compare의 첫 화면을 채우고 37차 단추는 그 아래에 있었습니다. Compare가 모드를 하나도 짝짓지 못하고 닫힌 실행에 코어 모드가 없으면, 이제 Matched modes 도구 막대 아래, 그림 위에 한 줄 *A · Run 2 has no core mode: its modes are mostly in Substrate, which touches the window edge.*이 나오고, 37차 단추가 이 줄로 옮겨져 *Use Run 2's inputs with search near 2.46 · 4 modes*라는 이름을 갖습니다. 동작과 Messages 줄은 그대로입니다: 그 실행의 입력을 현재 입력으로 만들고, 바로 가기를 설정하며, Model을 열고, 아무것도 실행하지 않습니다. 설명은 이유 문장과 *Open Run 2 in Results* 링크를 그대로 지킵니다. Compare를 열 때 이 줄을 넘어 스크롤하지 않습니다. 짝짓기, 모드 번호, 값, 파일 형식, 실행 기록과 *Slab modes first* 대화 상자는 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
