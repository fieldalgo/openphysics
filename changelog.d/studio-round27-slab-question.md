# Added

## English

- Before a closed-window optical run whose window would list slab modes first (the slab warning shown, Modes to return "Highest n_eff"), Run study asks once: "Substrate touches the window edge, so a closed-window run returns its slab modes first. Search near the core instead?" with Set search near 2.46 · 4 modes and run, Run as set, and Cancel. Run as set runs exactly as before; Studio asks again only after the geometry, the boundary or Modes to return changes. The warning and its buttons stay.
