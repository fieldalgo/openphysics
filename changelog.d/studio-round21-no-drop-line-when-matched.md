# Changed

## English

- Studio: **no drop line beside "No need to run".** While the current inputs equal a kept run's, the line *If you run: drops Run 3 (…) · pin it to keep it* beside Run study is hidden, as Messages says no run is needed; it returns once the inputs differ from every run. The heated model's line follows the same rule. [Workspace](docs/packages/simcase/workspace.md).
