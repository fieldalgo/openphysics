# Changed

## English

- `simcase`: **Studio 3D shows µm throughout, gives the Domain's ranges, and meshes from the ribbon (experimental).**
  - Every note and label in a 3D model shows µm. For example, the Parameters row reads *t_ox = 10 µm · via_w = 20 µm*. Inputs keep what was written (*10 um*).
  - The Domain row gives each axis's range: *x 0–200 · y 0–200 · z 0–610 µm*, and *x −1–1 · y −1–1 · z 0–1 m* for card 2.
  - In a 3D model, the ribbon's **Mesh** opens Mesh 1 and meshes when meshing is allowed. Otherwise Messages gives the header's reason. A 2D model's ribbon is unchanged.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D가 어디서나 µm를 쓰고, Domain의 범위를 보이며, 리본에서 메시합니다(실험적).**
  - 3D 모델의 모든 설명과 이름표가 µm를 씁니다. 예를 들어 Parameters 행은 *t_ox = 10 µm · via_w = 20 µm*로 읽힙니다. 입력 칸은 쓴 그대로입니다(*10 um*).
  - Domain 행은 축마다의 범위를 보입니다: *x 0–200 · y 0–200 · z 0–610 µm*, 카드 2는 *x −1–1 · y −1–1 · z 0–1 m*.
  - 3D 모델에서 리본의 **Mesh**는 메시할 수 있으면 Mesh 1을 열고 메시합니다. 아니면 Messages가 머리말의 이유를 말합니다. 2D 모델의 리본은 그대로입니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
