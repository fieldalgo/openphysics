# Changed

## English

- `simcase` Studio workspace: **fixes from the fifth agent usability round** (screen only; the engine, documents, routes and session files are unchanged, and coupled runs stay out of every file). (F5) In Connections each port has its own row with its dot on the node edge, and a wire starts and ends at the dots of the ports its coupling joins, so Heat 1's wire leaves from "temperature", not beside "heat flux". (F1) When the model equals the last run again (a coupling removed and added back, or Undo), Messages, the dock heading and the status bar say one sentence, "Model matches run 1 again: results are current", and the edit notice no longer asks for a Run. (F2) An optical Results page shows the n_eff table first and the coupled temperature and index maps below it. (F3) The ▶ of the Run buttons has an empty alternative text, so their accessible names are "Run" and "Run optical study". (F4) "Also solve without heater" stays in the toolbar while no temperature coupling exists, disabled, with the reason "needs a temperature coupling". (F6) Before leaving a model whose runs only this tab holds (another model, the template again, an opened file or inputs) Studio asks first, names the run that would be lost and offers the save that fits (Save model file, or Save session for optical runs in no session file); the save indicator now reads "Session file … sent to your browser's Downloads · time", never claiming a disk save. (F7) The multiphysics graphics footer names the length unit (µm), a numeric edit replaces "Model ready…" in Messages, and a Width edit says where Left x moved to keep the centre.

## 한국어

- `simcase` Studio 작업 공간: **다섯 번째 에이전트 사용성 라운드에서 나온 수정**(화면만 바뀌며 엔진, 문서, 경로, 세션 파일은 그대로이고 결합 실행은 어느 파일에도 넣지 않습니다). (F5) Connections에서 포트마다 자기 줄이 있고 점은 노드 가장자리에 있으며, 선은 결합이 잇는 포트의 점에서 시작하고 끝나므로 Heat 1의 선은 "heat flux" 옆이 아니라 "temperature"에서 나갑니다. (F1) 모델이 다시 마지막 실행과 같아지면(결합을 지웠다가 다시 추가, 또는 Undo) Messages, 도크 제목, 상태 표시줄이 "Model matches run 1 again: results are current"라는 한 문장을 보여 주고, 편집 알림은 더 이상 Run을 요청하지 않습니다. (F2) 광 모드 Results 쪽은 n_eff 표를 먼저, 결합 온도와 굴절률 지도를 그 아래에 보여 줍니다. (F3) Run 버튼의 ▶에 빈 대체 텍스트를 주어 접근 가능한 이름이 "Run"과 "Run optical study"가 됩니다. (F4) 온도 결합이 없는 동안에도 "Also solve without heater"가 도구 모음에 남아 꺼진 채 "needs a temperature coupling"이라고 이유를 밝힙니다. (F6) 이 탭에만 있는 실행을 가진 모델을 떠나기 전(다른 모델, 템플릿 다시 열기, 파일이나 입력 열기) Studio가 먼저 묻고, 잃을 실행을 밝히며 맞는 저장(Save model file, 세션 파일에 없는 광 실행이면 Save session)을 제안합니다. 저장 표시는 이제 "Session file … sent to your browser's Downloads · 시각"이며 디스크에 저장됐다고 하지 않습니다. (F7) 다중물리 그래픽 하단이 길이 단위(µm)를 밝히고, 숫자 편집이 Messages의 "Model ready…"를 바꾸며, Width 편집은 중심을 지키려 Left x가 어디로 옮겨졌는지 알려 줍니다.
