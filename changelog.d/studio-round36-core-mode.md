# Changed

## English

- Studio: **Compare names the core mode** (round 36, C1). A mode that its run's notes call the core mode (the same rule as the Results note *Mode 3 is the core mode: …*, closed or open) now carries *(core)* in the **Matched modes** picker and in the rows of the table *Modes of A and B matched by field overlap*: for the T18 slab shortcut's closed run against the open run, *A mode 3 (core) ↔ B mode 1 (core) · overlap 0.99 · TE-like* and the row *3 ↔ 1 (core)* (one mark when both sides are core modes, so the table keeps its width; one side reads *— ↔ 1 (core)*). When the two runs' first modes are not matched with each other but their core modes are, one line above the table reads *Core modes: A mode 3 ↔ B mode 1 · overlap 0.99*. A run with no core-mode note (a closed run as set, the core-only Design A/B runs) gets no mark. The matching rule, mode numbers and order, the default pick, Compare's other text, values, file formats and run records are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare가 코어 모드를 밝힙니다**(36차, C1). 실행의 안내가 코어 모드라고 부르는 모드(닫힌 실행이든 열린 실행이든 Results 안내 *Mode 3 is the core mode: …*와 같은 규칙)에 이제 **Matched modes** 선택 목록과 *Modes of A and B matched by field overlap* 표의 행에서 *(core)*가 붙습니다: T18 슬래브 바로 가기의 닫힌 실행과 열린 실행에서는 *A mode 3 (core) ↔ B mode 1 (core) · overlap 0.99 · TE-like*와 행 *3 ↔ 1 (core)*(양쪽이 코어 모드면 표시 한 번, 표 너비를 지키려고; 한쪽만이면 *— ↔ 1 (core)*). 두 실행의 첫 모드끼리는 짝지어지지 않았지만 코어 모드끼리 짝지어졌으면 표 위에 한 줄 *Core modes: A mode 3 ↔ B mode 1 · overlap 0.99*가 나옵니다. 코어 모드 안내가 없는 실행(그대로 실행한 닫힌 실행, 코어만의 Design A/B 실행)에는 표시가 붙지 않습니다. 짝짓기 규칙, 모드 번호와 순서, 처음 고른 쌍, Compare의 다른 문구, 값, 파일 형식과 실행 기록은 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
