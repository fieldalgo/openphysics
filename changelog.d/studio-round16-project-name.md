# Changed

## English

- Studio: **a project name that came from a file name follows Save As.** The first save's file name became the project name and Save As did not rename it, so the header read *waveguide-AB · design-a-ng.json* (all five users were confused). Now such a name follows each file the project is saved to; a name set with Rename stays. The header and the Open notice use that name; the file format's `name` is unchanged. [Workspace](docs/packages/simcase/workspace.md).
