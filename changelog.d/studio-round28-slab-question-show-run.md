# Changed

## English

- When a run already has the results of the slab shortcut's inputs (Nearest to n_eff 2.46, Modes to find 4 and the other current inputs), the slab question's first button reads "Set search near 2.46 · 4 modes · show Run 6": it sets those inputs and shows that run instead of running a copy, by the same rule as the panel button's "No need to run". Run as set and Cancel are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- 슬래브 바로 가기 입력(Nearest to n_eff 2.46, Modes to find 4와 나머지 현재 입력)의 결과를 이미 가진 실행이 있으면 슬래브 질문의 첫 버튼이 "Set search near 2.46 · 4 modes · show Run 6"입니다: 그 입력을 정하고 사본을 실행하지 않고 그 실행을 보여 주며, 패널 버튼의 "No need to run"과 같은 규칙을 씁니다. Run as set과 Cancel은 그대로입니다. [작업 공간](packages/simcase/workspace.md).
