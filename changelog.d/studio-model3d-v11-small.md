# Changed

## English

- `simcase`: **Studio 3D: the Parameters table fits its pane, the ribbon has Run, and card 1 names its preset source (experimental).**
  - The Parameters table shows each parameter on two lines (name, value and Delete; then kind, range, SI value and use), so the Use column is no longer clipped.
  - For a 3D model, the ribbon's Compute group has **Run**. It runs as the header's Run does, or Messages gives its reason.
  - Card 1's note adds *Preset: heat source 1e12 W/m³ in Si (top) (4 W)*.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D: Parameters 표가 창에 맞고, 리본에 Run이 있으며, 카드 1이 미리 넣은 열원을 밝힙니다(실험적).**
  - Parameters 표는 매개변수마다 두 줄(이름, 값, Delete; 그다음 종류, 범위, SI 값, 쓰임)로 보여 Use 열이 더는 잘리지 않습니다.
  - 3D 모델에서 리본의 Compute 묶음에 **Run**이 있습니다. 머리말의 Run처럼 실행하거나 Messages가 그 이유를 말합니다.
  - 카드 1의 설명에 *Preset: heat source 1e12 W/m³ in Si (top) (4 W)*가 붙습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
