# Changed

## English

- `simcase`: **Studio 3D's message after a run uses the values table's words for the place (experimental).** A maximum at a node shared by two regions now reads *Run 1 complete: maximum 336.05 K at the SiO2 / Si (top) interface.*, matching the Settings row, instead of *in SiO2*.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 실행 뒤 메시지가 위치를 값 표의 말로 씁니다(실험적).** 두 영역이 나누는 노드의 최대는 이제 *in SiO2* 대신 Settings 행과 같이 *Run 1 complete: maximum 336.05 K at the SiO2 / Si (top) interface.*로 읽힙니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
