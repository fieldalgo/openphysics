# Changed

## English

- Studio: **a File menu at the left of the ribbon, with Save As.** **File › Open…** (Ctrl+O) opens a session file or a model file of any model; **File › Save** (Ctrl+S) and **File › Save As…** (Shift+Ctrl+S) save the session file; **File › Export › Model file…** replaces More › Save inputs only, **File › Export › Model with runs (session file)…** is Save As, **File › Browser copy** holds the browser draft and **Edit › Reset design** replaces More › Reset design (the More menu and Open inputs file are gone; the ribbon's **Open…** and **Save** stay as shortcuts). The menus are `role="menu"` lists usable by keyboard with their shortcuts shown. Where the browser has a save dialog (`showSaveFilePicker`: Chrome, Edge and Opera on a secure page such as `http://127.0.0.1`), Save As writes the chosen file, Messages says *Saved to …*, and Save writes it again without asking; a cancel says *Save As cancelled; nothing was written.* and a failed write leaves the file unchanged. Elsewhere, or when that dialog is refused, Studio asks for the file name (letters, digits, spaces and `. _ - ( )`, `.json` added) and the browser downloads it (*sent to your browser's Downloads*). Model files are named after the model (`optical-waveguide.json`, no longer `studio-workspace-v2.json`), and messages call them model files, never projects. The Library's **Open session file…** has one place, at the top of the page. File contents are unchanged. [File menu and file kinds](docs/packages/simcase/workspace.md#file-menu-and-file-kinds).

## 한국어

- Studio: **리본 왼쪽에 File 메뉴와 Save As가 생겼습니다.** **File › Open…**(Ctrl+O)은 어느 모델의 세션 파일이든 모델 파일이든 열고, **File › Save**(Ctrl+S)와 **File › Save As…**(Shift+Ctrl+S)는 세션 파일을 저장합니다. **File › Export › Model file…**이 More › Save inputs only를 대신하고, **File › Export › Model with runs (session file)…**은 Save As와 같으며, **File › Browser copy**에 브라우저 초안이, **Edit › Reset design**에 More › Reset design이 있습니다(More 메뉴와 Open inputs file은 없어지고, 리본의 **Open…**과 **Save**는 바로 가기로 남습니다). 메뉴는 키보드로 쓸 수 있는 `role="menu"` 목록이며 단축키를 보여 줍니다. 브라우저에 저장 대화상자(`showSaveFilePicker`: `http://127.0.0.1` 같은 보안 페이지의 Chrome, Edge, Opera)가 있으면 Save As는 고른 파일에 쓰고 Messages에 *Saved to …*가 나오며, Save는 묻지 않고 그 파일에 다시 씁니다. 취소하면 *Save As cancelled; nothing was written.*이 나오고, 쓰기가 실패하면 파일은 그대로입니다. 그 밖의 브라우저나 대화상자가 거부되면 Studio가 파일 이름(글자, 숫자, 공백과 `. _ - ( )`, `.json` 추가)을 묻고 브라우저가 내려받습니다(*sent to your browser's Downloads*). 모델 파일은 모델 이름을 따르며(`studio-workspace-v2.json`이 아닌 `optical-waveguide.json`), 메시지는 이를 project가 아닌 model file이라고 부릅니다. Library의 **Open session file…**은 페이지 맨 위 한 곳에 있습니다. 파일 내용은 바뀌지 않습니다. [File 메뉴와 파일 종류](packages/simcase/workspace.md#file-메뉴와-파일-종류).
