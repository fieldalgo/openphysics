# Changed

## English

- Studio: **over 16 MiB, browser recovery keeps as many fields as fit, newest first, and names the runs it left out.** After the selected and pinned runs' fields, browser recovery of an optical session now adds the other runs' fields newest first while the record stays within 16 MiB, where it kept the selected and pinned runs' fields only. The header and the save indicator read *kept for recovery in this browser without the fields of Run 1 and Run 2*, the Messages line ends *Browser recovery keeps every field but those of Run 1 and Run 2.*, and a restore adds *Fields not kept for Run 1 and Run 2; …*. File › Save still asks about the selected and pinned runs; the record format, the limit and records below it are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **16 MiB를 넘으면 브라우저 복구가 들어가는 만큼 장을 새것부터 보존하고, 뺀 실행을 밝힙니다.** 광학 세션의 브라우저 복구는 선택·고정 실행의 장만 보존하던 데서, 이제 그 뒤 나머지 실행의 장을 기록이 16 MiB 안에 머무는 동안 새것부터 더합니다. 헤더와 저장 표시는 *kept for recovery in this browser without the fields of Run 1 and Run 2*, Messages 줄은 *Browser recovery keeps every field but those of Run 1 and Run 2.*로 끝나고, 복원은 *Fields not kept for Run 1 and Run 2; …*를 덧붙입니다. File › Save는 여전히 선택·고정 실행에 대해 묻고, 기록 형식, 한도, 한도 아래 기록은 그대로입니다. [워크스페이스](packages/simcase/workspace.md).
