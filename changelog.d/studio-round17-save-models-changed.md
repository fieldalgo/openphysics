# Fixed

## English

- Studio: **Save asks for a name when the project's models changed.** After a project file was saved or opened by download, adding the heated model and pressing Save downloaded the two-model project under the optical file's name without a word. Save now opens the Save As name dialog, prefilled with that name and saying what changed; otherwise it downloads at once as before. The save picker path is unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **프로젝트의 모델이 바뀌면 Save가 이름을 묻습니다.** 프로젝트 파일을 내려받기로 저장하거나 연 뒤 가열 모델을 더하고 Save를 누르면, 두 모델의 프로젝트를 말없이 광학 파일 이름으로 내려받았습니다. 이제 Save는 그 이름을 채운 Save As 이름 대화상자를 열고 무엇이 바뀌었는지 밝힙니다. 그 밖에는 전처럼 바로 내려받습니다. 저장 선택 창 경로는 그대로입니다. [워크스페이스](packages/simcase/workspace.md).
