# Changed

## English

- `simcase`: **Studio 3D's mesh status is clearer (experimental).**
  - A finished mesh reads *Meshed Component 1 in 2.8 s: 2,176 nodes, 9,238 tetrahedra, 4 regions.* It names the component as the tree does and gives the elapsed time.
  - A new mesh clears the last run's status line.
  - Mesh 1's statistics are headed *Kept mesh (before the last change)* once the document's mesh no longer matches them, a refusal included.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 메시 상태가 더 분명해집니다(실험적).**
  - 끝난 메시는 *Meshed Component 1 in 2.8 s: 2,176 nodes, 9,238 tetrahedra, 4 regions.*로 읽힙니다. 트리처럼 구성 요소를 부르고 경과 시간을 줍니다.
  - 새 메시는 지난 실행의 상태 줄을 지웁니다.
  - 문서의 메시가 더는 맞지 않으면(거절 포함) Mesh 1의 통계에 *Kept mesh (before the last change)*라는 제목이 붙습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
