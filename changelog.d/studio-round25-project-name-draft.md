# Fixed

## English

- Studio: **a project name being typed on the Library is kept when the page redraws.** A browser recovery update right after File › Open redrew the Library and put the stored name back over the name being typed, so **Rename** then kept the old name; the field now keeps the typed name, its focus and its selection. [Workspace](docs/packages/simcase/workspace.md#project-files).

## 한국어

- Studio: **Library에서 입력 중인 프로젝트 이름이 페이지를 다시 그려도 남습니다.** File › Open 직후 브라우저 복구 갱신이 Library를 다시 그리면서 입력 중인 이름 위에 저장된 이름을 되돌려 놓아, **Rename**이 예전 이름을 유지했습니다. 이제 입력란은 입력한 이름과 포커스, 선택 범위를 유지합니다. [워크스페이스](packages/simcase/workspace.md#프로젝트-파일).
