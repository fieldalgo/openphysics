# Added

## English

- Studio: **Search near n_eff in a closed window.** Physics › Optical modes has a **Search near n_eff** box (off by default) with its field; under a closed run's edge note, **Search near 2.46 · 4 modes** turns it on with 4 modes and runs nothing. A targeted run lists only modes above n = 1.45 (*Found 3 of 4 modes near n_eff 2.46, above n = 1.45.*, *1 mode at or below n = 1.45 was left out.*), names the core mode (*Mode 2 is the core mode: 64 % of |E|² is in Core, which does not touch the window edge.*) and is tagged *closed near 2.46*. Its session is version 11 (only with such a run kept; other files keep version 7, 9 or 10 byte for byte), a changed or removed target needs a run, and **Use this run's inputs** restores the target; the box is not saved in model files yet. [Search near n_eff in a closed window](docs/packages/simcase/workspace.md#search-near-n_eff-in-a-closed-window).

## 한국어

- Studio: **닫힌 창에서 Search near n_eff.** Physics › Optical modes에 기본으로 꺼진 **Search near n_eff** 상자와 필드가 있고, 닫힌 실행의 가장자리 안내 아래 **Search near 2.46 · 4 modes**가 모드 4개로 이를 켜며 아무것도 실행하지 않습니다. 목표 실행은 n = 1.45보다 큰 모드만 싣고(*Found 3 of 4 modes near n_eff 2.46, above n = 1.45.*, *1 mode at or below n = 1.45 was left out.*), 코어 모드를 밝히며(*Mode 2 is the core mode: 64 % of |E|² is in Core, which does not touch the window edge.*), *closed near 2.46*으로 표시됩니다. 그 세션은 버전 11이고(그런 실행이 보관될 때만; 다른 파일은 버전 7, 9, 10으로 바이트까지 같음), 목표를 바꾸거나 끄면 실행이 필요하며, **Use this run's inputs**가 목표를 되돌립니다. 상자는 아직 모델 파일에 저장되지 않습니다. [닫힌 창의 Search near n_eff](packages/simcase/workspace.md#닫힌-창의-search-near-n_eff).
