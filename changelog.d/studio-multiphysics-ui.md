# Added

## English

- `simcase`: **Studio edits and runs multiphysics models.** The start page's *Heated silicon waveguide* card (heat → optical modes, coupled) opens a multiphysics document that the workspace edits in place. The model tree has solve-order badges and a Couplings group. **Add physics** lists the installed kinds from the provider manifests. **Add coupling** offers only inputs that can take the chosen output, and says why the others cannot. Connections is drawn from the document's couplings, with invalid couplings in red and cycles boxed until **Accept iteration step** writes the proposed loop. A live check puts every problem in Messages, on the tree, in Settings and on the diagram, in plain words with one-click fixes. **Run** shows per-physics and loop progress from the engine's events and has **Stop run**. Results have a page per physics with the T and n maps, and a coupling check. A failed or stopped run keeps no partial result. The server routes are `/api/multiphysics/*` (capabilities, template, validate, run, job progress, stop, result). `multiphysics` joins `simcase.__all__` so that Studio stays an ordinary consumer of the engine. Single-physics applications are unchanged. Checked: Node tests of the pure functions, Studio route tests (refusals, a template round trip, loops through the engine's test-local kinds, engine diagnostics mapped into the workspace's words), and a real-browser check whose coupled n_eff equals the engine's run of the same document exactly. [Multiphysics models in the workspace](docs/packages/simcase/workspace.md#multiphysics-models-heat--optical-modes).

## 한국어

- `simcase`: **Studio가 다중물리 모델을 편집하고 실행합니다.** 시작 화면의 *Heated silicon waveguide* 카드(열 → 광 모드, 결합)는 작업 공간이 그 자리에서 편집하는 다중물리 문서를 엽니다. 모델 트리에는 풀이 순서 배지와 Couplings 묶음이 있습니다. **Add physics**는 설치된 종류를 제공자 매니페스트에서 읽어 보여 줍니다. **Add coupling**은 고른 출력을 받을 수 있는 입력만 고를 수 있게 하고 나머지는 이유를 밝힙니다. Connections는 문서의 결합으로 그리며, 잘못된 결합은 빨갛게, 순환은 **Accept iteration step**이 제안된 반복을 쓸 때까지 상자로 표시합니다. 실시간 검사가 문제마다 Messages, 트리, Settings, 그림에 쉬운 말과 한 번에 고치는 버튼으로 보여 줍니다. **Run**은 엔진 이벤트로 물리별·반복별 진행을 보여 주며 **Stop run**이 있습니다. Results는 물리마다 T·n 지도가 있는 쪽과 결합 검사를 둡니다. 실패하거나 멈춘 실행은 부분 결과를 남기지 않습니다. 서버 경로는 `/api/multiphysics/*`(capabilities, template, validate, run, 작업 진행, stop, result)입니다. Studio가 엔진의 평범한 사용자로 남도록 `multiphysics`를 `simcase.__all__`에 더했습니다. 단일 물리 애플리케이션은 바뀌지 않습니다. 검사: 순수 함수의 Node 시험, Studio 경로 시험(거부, 템플릿 왕복, 엔진의 시험용 종류로 돈 반복, 작업 공간 문구로 옮긴 엔진 진단), 결합된 n_eff가 같은 문서의 엔진 실행과 정확히 같은지 확인하는 실제 브라우저 검사. [작업 공간의 다중물리 모델](packages/simcase/workspace.md#다중물리-모델-열--광-모드).
