## English

- After repeated Download again of the same project file in one tab, the header names the number the browser likely gave: the second repeat says "(your browser may have named it design-a-ng (2).json)", the first "(1)" as before. Save As or Open starts the count again. [Workspace](docs/packages/simcase/workspace.md).
