# Changed

## English

- Studio: **an estimate for runs with group index, and a button to turn it off.** With *Also compute group index* on, the line beside Run study now ends with an estimate from the newest run of this tab with the same boundary (three times its time when it had no group index), *Open boundary · 2 searches · group index on (3 solves) · about 3 min*, and none without such a run. A **Turn off group index** button sits beside it. The option stays an input and no run turns it off. In the optical model. [Workspace](docs/packages/simcase/workspace.md).
