# Changed

## English

- Studio: **the status line names both geometries.** When the viewed run has other inputs, the dock heading and the status bar read *Run 1 · Design A 600 × 300 nm · current inputs 700 × 300 nm* (with the same geometry, at most two of the settings that differ). The change list of **Use this run's inputs** stays in the run panel where the button was until the next input edit, as well as in Messages, and a session save says *Current inputs (650 × 300 nm) have no run yet.* when no run has the current inputs. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **상태 줄이 두 기하를 모두 밝힙니다.** 보고 있는 실행의 입력이 다르면 도크 제목과 상태 표시줄이 *Run 1 · Design A 600 × 300 nm · current inputs 700 × 300 nm*이라고 합니다(기하가 같으면 다른 설정을 두 개까지). **Use this run's inputs**의 변경 목록은 Messages에 더해 다음 입력 편집까지 실행 패널의 버튼 자리에 남고, 현재 입력의 실행이 없으면 세션 저장이 *Current inputs (650 × 300 nm) have no run yet.*이라고 알립니다. [워크스페이스](packages/simcase/workspace.md).
