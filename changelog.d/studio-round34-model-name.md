# Changed

## English

- Studio: **in a Messages line that names both models, the current-inputs sentence names the optical model** (round 34, M2). After a project open or a two-model restore, the line ends with *Optical waveguide: current inputs are Run 2 · Design B's.* (*Optical waveguide: current inputs are Run 3's.* for an unnamed run, *Optical waveguide: current inputs (650 × 300 nm) have no run yet.* when no run has them), using the optical model's title as the line names it. A line that names one model keeps *Current inputs are Run 2 · Design B's.* Which inputs become current, the heated model's messages, file formats and values are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **두 모델을 밝히는 Messages 줄에서 현재 입력 문장이 광학 모델을 밝힙니다**(34차, M2). 프로젝트 열기나 두 모델 복원 뒤 줄은 그 줄이 쓰는 광학 모델 제목으로 *Optical waveguide: current inputs are Run 2 · Design B's.*(이름 없는 실행이면 *Optical waveguide: current inputs are Run 3's.*, 그 입력의 실행이 없으면 *Optical waveguide: current inputs (650 × 300 nm) have no run yet.*)로 끝납니다. 모델 하나를 밝히는 줄은 *Current inputs are Run 2 · Design B's.*를 그대로 씁니다. 어떤 입력이 현재 입력이 되는지, 가열 모델의 메시지, 파일 형식과 값은 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
