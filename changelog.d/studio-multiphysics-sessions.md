# Added

## English

- Studio: **multiphysics models are saved with their runs.** **Save session** and **Open session** are the first commands of the Project group in every model (optical, heat, Joule heating and multiphysics). A multiphysics model is saved as a session file of version 8 (`"application": "multiphysics"`) with up to six runs and their names and pins, the without-heater results and the view; optical sessions are still written as version 7, byte for byte as before, and versions 6 and 7 open unchanged. Each run keeps the server's reply with every map (mesh, temperatures, refractive index and its change), every value bit for bit (negative zero as `-0.0`), and a SHA-256 digest that detects a damaged or hand-edited file but is not an authentication. Over 16 MiB, Save session asks before keeping the maps of the selected and pinned runs only. Opening checks every model with the server and every stored array before anything in the tab is replaced; results are read from the file, not recomputed. Browser recovery keeps multiphysics models too. **More › Save inputs only** and **Open inputs file** keep the model file alone, and Open session also opens a model file. Multiphysics sessions need this Studio or newer: an older Studio refuses a version 8 file with "Unsupported session format or run count." [Session files of multiphysics models](docs/packages/simcase/workspace.md#session-files-of-multiphysics-models-version-8).

## 한국어

- Studio: **다중물리 모델을 실행과 함께 저장합니다.** **Save session**과 **Open session**이 모든 모델(광학, 열, Joule 가열, 다중물리)에서 Project 묶음의 첫 명령입니다. 다중물리 모델은 버전 8 세션 파일(`"application": "multiphysics"`)로 저장하며, 최대 여섯 실행과 그 이름·고정, 히터 없는 결과, 화면 상태를 담습니다. 광학 세션은 여전히 이전과 바이트 단위까지 같은 버전 7로 쓰고, 버전 6과 7은 그대로 열립니다. 실행마다 서버 응답을 모든 맵(메시, 온도, 굴절률과 그 변화)과 함께 비트 단위로(음의 0은 `-0.0`) 보관하고, 손상되거나 손으로 고친 파일을 알아내는 SHA-256 다이제스트를 붙입니다(인증은 아님). 16 MiB를 넘으면 Save session이 고른 실행과 고정한 실행의 맵만 둘지 먼저 묻습니다. 열기는 탭의 무엇이든 바꾸기 전에 모든 모델을 서버로, 저장된 모든 배열을 검사하며, 결과는 다시 계산하지 않고 파일에서 읽습니다. 브라우저 복구도 다중물리 모델을 보관합니다. **More › Save inputs only**와 **Open inputs file**은 모델 파일만 다루고, Open session도 모델 파일을 엽니다. 다중물리 세션에는 이 Studio 이상이 필요합니다: 이전 Studio는 버전 8 파일을 "Unsupported session format or run count."로 거부합니다. [다중물리 모델의 세션 파일](packages/simcase/workspace.md#다중물리-모델의-세션-파일버전-8).
