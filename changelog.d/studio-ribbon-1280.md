# Fixed

## English

- Studio: **the ribbon fits a 1280 px window.** Once a model was open, the Compute group's fixed 460 px box beside Run study took the ribbon 112 px past a 1280 × 800 window (its right edge at 1392 px). Up to 1400 px the box is 340 px, still of fixed size, so the ribbon ends at 1272 px. The workspace browser check asserts no horizontal overflow at 1280 × 800 on Results and Model with optical runs. [Workspace](docs/packages/simcase/workspace.md#first-optical-study).
