# Changed

## English

- Studio: **the run banner no longer moves the panels.** *Optical run complete…* (and **Stop waiting** while a run goes) is an overlay on the right of the view's title row, one line high, so the model tree, the settings and the workspace keep their place when it appears or leaves, and it covers no control (checked at 1440 × 900 and 390 × 844). On Compare the run list's *Compare A* and *Compare B* are badges after the run's label; the text and the accessible name still end in *· Compare A*. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **실행 배너가 더는 패널을 움직이지 않습니다.** *Optical run complete…*(실행 중에는 **Stop waiting**)는 보기 제목 줄 오른쪽의 한 줄짜리 덧씌움이므로, 나타나거나 사라질 때 모델 트리, 설정, 작업 영역이 제자리에 있고 어떤 컨트롤도 가리지 않습니다(1440 × 900과 390 × 844에서 확인). Compare에서 실행 목록의 *Compare A*, *Compare B*는 실행 레이블 뒤의 배지이며, 텍스트와 접근 가능한 이름은 여전히 *· Compare A*로 끝납니다. [워크스페이스](packages/simcase/workspace.md).
