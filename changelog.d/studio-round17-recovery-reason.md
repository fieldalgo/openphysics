# Fixed

## English

- Studio: **"browser recovery unavailable" says why.** With two pinned open-boundary runs of a strip over a substrate (about 7.5 MB each), the optical recovery snapshot was over 16 MiB and the header read only *browser recovery unavailable*. It now reads *browser recovery unavailable: session over 16 MiB · File › Save keeps your work*, and a write the browser refuses for space reads *browser recovery unavailable: this browser’s storage is full · File › Save keeps your work*. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **"browser recovery unavailable"이 까닭을 밝힙니다.** 기판 위 스트립의 고정한 열린 경계 실행 둘(각각 약 7.5 MB)이 있으면 광학 복구 스냅숏이 16 MiB를 넘었는데 머리글은 *browser recovery unavailable*만 보였습니다. 이제 *browser recovery unavailable: session over 16 MiB · File › Save keeps your work*로, 브라우저가 공간 부족으로 쓰기를 거부하면 *browser recovery unavailable: this browser’s storage is full · File › Save keeps your work*로 나옵니다. [워크스페이스](packages/simcase/workspace.md).
