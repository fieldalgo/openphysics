# Added

## English

- Studio: **the optical model tree has a Results group**, as the heated multiphysics tree has: once there is a run, *Results · run N* with *Runs · N of 6* (opens Results) and, with two runs, *Compare* (opens Compare), in the same ARIA tree with its keys and one tab stop. The node of the page shown is selected. *Runs · N of 6* and the run list's *Up to six runs are kept* come from the same run limit. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **광학 모델 트리에 Results 그룹이 생겼습니다.** 가열 다중물리 트리처럼 실행이 생기면 *Results · run N* 아래 Results를 여는 *Runs · N of 6*과, 실행이 둘이면 Compare를 여는 *Compare*가 같은 ARIA 트리(같은 키, 탭 정지 하나)에 놓입니다. 보이는 페이지의 노드가 고른 것으로 표시됩니다. *Runs · N of 6*과 실행 목록의 *Up to six runs are kept*는 같은 실행 한도에서 옵니다.
