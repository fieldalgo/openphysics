# Changed

## English

- Studio: **Compare says why nothing matched.** When Compare matches no mode and a run's mode 1 is mostly in a shape touching the window edge, the empty-match line adds *A · Run 6: its modes are mostly in Substrate, which touches the window edge; the core mode was not found.* and a link **Open Run 6 in Results**. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare가 짝이 없는 까닭을 말합니다.** Compare가 짝지은 모드가 없고 한 실행의 모드 1이 대부분 창 가장자리에 닿는 형상 안에 있으면, 빈 짝 줄에 *A · Run 6: its modes are mostly in Substrate, which touches the window edge; the core mode was not found.*와 링크 **Open Run 6 in Results**가 붙습니다. [워크스페이스](packages/simcase/workspace.md).
