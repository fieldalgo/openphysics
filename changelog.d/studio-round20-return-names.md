# Changed

## English

- Studio: **the Library's return cards name their model.** Two models of one project both read *Return to model (2 runs)*, so their accessible names collided; they now read *Return to Optical waveguide (2 runs)* and *Return to Heated silicon waveguide (2 runs)* (*Return to Optical waveguide* without runs). [Workspace](docs/packages/simcase/workspace.md).
