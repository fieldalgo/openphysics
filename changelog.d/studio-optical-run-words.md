# Changed

## English

- `simcase` Studio workspace: **usability fixes to the optical and multiphysics words** (screen only; the solver, templates, documents, results, session files and tolerances are unchanged). After an optical run the dock heading and the status bar name the run they describe, *Run 1 · solved from the current inputs*, and after an edit *Inputs changed since run 1 · press Run to update*; before any run they keep *Nothing is computed until you press Run* and *Optical adapter ready · explicit Run required*. The optical Study settings show the wavelength with **Edit in Optical modes**, which opens its one field. The multiphysics n_eff table calls its rows *Candidate 1*, … with the optical caveat and the number of modes asked for (*This model asks for 1 mode: Modes 1 › Modes to find*). Physics types, names in the file, the format line and input arity are under a closed **File details**. The coupling From list shows *Modes 1 effective index (single numbers, not a map)*, still greyed. A model just chosen reads *New model · not saved* until its first edit; Joule heating has its own card icon; the start page says plainly what choosing a model does; Messages says when **Also solve without heater** is ticked again after a coupling comes back. [Workspace guide](docs/packages/simcase/workspace.md).

## 한국어

- `simcase` Studio 작업 공간: **광·다중물리 화면 문구의 사용성 수정**(화면만 바뀌며 솔버, 템플릿, 문서, 결과, 세션 파일, 허용오차는 그대로). 광 실행 뒤 도크 제목과 상태 표시줄은 자신이 설명하는 실행을 *Run 1 · solved from the current inputs*로, 편집 뒤에는 *Inputs changed since run 1 · press Run to update*로 밝힙니다. 실행 전에는 *Nothing is computed until you press Run*과 *Optical adapter ready · explicit Run required*를 그대로 씁니다. 광 Study 설정은 파장과 함께 그 입력란 하나를 여는 **Edit in Optical modes**를 보여 줍니다. 다중물리 n_eff 표의 행은 *Candidate 1*, …이고 광 애플리케이션과 같은 주의와 요청한 모드 수(*This model asks for 1 mode: Modes 1 › Modes to find*)가 붙습니다. 물리 type, 파일 속 이름, 형식 줄, 입력이 받는 소스 수는 닫힌 **File details** 안에 둡니다. 결합의 From 목록은 *Modes 1 effective index (single numbers, not a map)*를 회색으로 보여 줍니다. 방금 고른 모델은 첫 편집 전까지 *New model · not saved*로 표시되고, Joule 가열 카드는 자기 아이콘을 가지며, 시작 화면은 모델을 고르면 무엇이 일어나는지 쉽게 밝히고, 결합이 돌아와 **Also solve without heater**가 다시 켜지면 Messages가 알려 줍니다. [작업 공간 안내](packages/simcase/workspace.md).
