# Changed

## English

- Studio: **Use this run's inputs** says only what changes, from → to (*Current inputs set from Run 1 · design A: Width 700 → 600 nm · Modes to find 4 → 2. The next run uses them; Undo takes them back.*). In the multiphysics model, when an edit makes the model equal to the last run again, the sentence reads *No need to run: Run 1 already has these results. Run study adds a copy with the same values* and Messages offers **Show Run 1**. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Use this run's inputs**가 바뀌는 것만 이전 → 이후로 밝힙니다(*Current inputs set from Run 1 · design A: Width 700 → 600 nm · Modes to find 4 → 2. The next run uses them; Undo takes them back.*). 다중물리 모델에서 편집으로 모델이 마지막 실행과 다시 같아지면 문장은 *No need to run: Run 1 already has these results. Run study adds a copy with the same values*이고, Messages가 **Show Run 1**을 내놓습니다. [작업 공간](packages/simcase/workspace.md).
