# Changed

## English

- `simcase`: **Studio 3D says which names select only the picked face (experimental).**
  - Each name in the Names box is marked *only this face* or *also face 3*.
  - An interior face adds *Interior face: hide Si (top), the region above it, with Regions in the view toolbar to see it.*
  - The engine's names are unchanged.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D가 어느 이름이 고른 면만 고르는지 말합니다(실험적).**
  - Names 상자의 이름마다 *only this face* 또는 *also face 3*이 붙습니다.
  - 안쪽 면은 *Interior face: hide Si (top), the region above it, with Regions in the view toolbar to see it.*를 덧붙입니다.
  - 엔진의 이름은 바뀌지 않습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
