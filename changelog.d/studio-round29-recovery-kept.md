# Changed

## English

- Browser-recovery offers name the browser copy's time with "kept", not "saved", which testers read as a file save that never happened: "Restore newest from this browser: … · file optical-and-heated.json, changed since · kept 8:48 PM", "… · older · kept 5:38 AM". Where the time is a file's save time ("same as file x.json, saved 9:24 PM"), "saved" stays. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- 브라우저 복구 제안이 브라우저 사본의 시각을 "saved" 대신 "kept"로 밝힙니다. 테스터들이 "saved"를 일어나지 않은 파일 저장으로 읽었습니다: "Restore newest from this browser: … · file optical-and-heated.json, changed since · kept 8:48 PM", "… · older · kept 5:38 AM". 시각이 파일의 저장 시각인 곳("same as file x.json, saved 9:24 PM")은 "saved" 그대로입니다. [작업 공간](packages/simcase/workspace.md).
