# Changed

## English

- `simcase` Studio workspace, multiphysics model: **fixes from the fourth agent usability round** (screen only; the engine, documents, routes and single-physics session files are unchanged). (M1) An edit after a run marks its Study rows **Out of date (last run: …)**, and the dock heading and footer say the model changed since run N; the same content again (a coupling removed and added back) is current again. (M2) The heater-off column is valid by the content of the optical model it solved, not by the order of runs. (M3) **Also solve without heater** beside Run (on for the template, about 1 s) solves Modes 1 alone after the coupled run, and the table says what that is: no temperature input, every material at n₀, its index at T_ref = 300 K. (M6) The shift column is **Δn_eff (coupled − without heater)**, signed with 8 decimals (+0.00215086). (M5) Run has the ▶ of Run optical study. (M4) The Project group shows **Open model file** and **Save model file**; the session commands are hidden, and the title says runs stay in this tab, not in the file. (M7) An optical temperature input with no source is a warning on Modes 1 (“Temperature input has no source: uses n₀ at T_ref (300 K)”), and a removed coupling leaves a message with **Undo**. (M8, M9, R4) Static port dots that point to Add coupling, “2 physics · no couplings”, the λ mark for optical modes, µm in the graphics, start-page cards in one aligned row, and a button look for the **λ 1550 nm** chip. [Workspace guide](docs/packages/simcase/workspace.md).

## 한국어

- `simcase` Studio 작업 공간의 다중물리 모델: **네 번째 에이전트 사용성 라운드에서 나온 수정**(화면만 바뀌며 엔진, 문서, 경로, 단일 물리 세션 파일은 그대로). (M1) 실행 뒤 편집하면 Study 행이 **Out of date (last run: …)**가 되고, 도크 제목과 하단이 실행 N 뒤 모델이 바뀌었다고 알립니다. 내용이 다시 같아지면(결합을 지웠다가 다시 추가) 다시 현재가 됩니다. (M2) 히터 없는 열의 유효성은 실행 순서가 아니라 따로 푼 광 모델의 내용으로 정합니다. (M3) Run 옆 **Also solve without heater**(템플릿에서 켜짐, 약 1초)가 결합 실행 뒤 Modes 1을 따로 풀고, 표가 그 기준을 밝힙니다: 온도 입력 없음, 모든 재료가 n₀, 곧 T_ref = 300 K에서의 굴절률. (M6) 차이 열은 **Δn_eff (coupled − without heater)**이며 부호와 소수 8자리로 나옵니다(+0.00215086). (M5) Run에 Run optical study와 같은 ▶가 붙습니다. (M4) Project 묶음에 **Open model file**과 **Save model file**이 나오고 세션 명령은 숨기며, 제목이 실행은 이 탭에 남고 파일에 없다고 밝힙니다. (M7) 소스가 없는 광 온도 입력은 Modes 1의 경고가 되고(“Temperature input has no source: uses n₀ at T_ref (300 K)”), 지운 결합은 **Undo**가 있는 메시지를 남깁니다. (M8, M9, R4) 끌지 않는 포트 점과 Add coupling 안내, “2 physics · no couplings”, 광 모드의 λ 표시, 그림의 µm, 한 줄로 맞춘 시작 화면 카드, 버튼처럼 보이는 **λ 1550 nm** 칩. [작업 공간 안내](packages/simcase/workspace.md).
