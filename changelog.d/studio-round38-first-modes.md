# Changed

## English

- Studio: **Compare says what each run's first mode is** (round 38, C2). When the pair shown is a core pair and a run's mode 1 is not a core mode, is mostly in a shape that touches the window edge and matches no mode of the other run, one line under the Matched modes toolbar, above the plots, reads *Mode 1 of A · Run 3 is a Substrate mode and matches no mode of B; the core modes are A mode 3 ↔ B mode 1.* There is no line otherwise. The table's *Core modes* line, the matching, mode numbers, the default pick, values, file formats and run records are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare가 각 실행의 첫 모드가 무엇인지 말합니다**(38차, C2). 보여 주는 쌍이 코어 쌍이고 한 실행의 모드 1이 코어 모드가 아니며, 창 가장자리에 닿는 형상에 대부분 있고, 다른 실행의 어떤 모드와도 짝지어지지 않으면, Matched modes 도구 막대 아래, 그림 위에 한 줄 *Mode 1 of A · Run 3 is a Substrate mode and matches no mode of B; the core modes are A mode 3 ↔ B mode 1.*이 나옵니다. 그 밖에는 이 줄이 없습니다. 표의 *Core modes* 줄, 짝짓기, 모드 번호, 기본 선택, 값, 파일 형식과 실행 기록은 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
