# Changed

## English

- Studio: **an untitled project opened from a session or model file says it changed since that file.** Once changed, a project made by File › Open of `run-a.json` reads *Untitled project · changed since run-a.json, not saved · …*, where it read *not saved to a file* beside the status bar's *Changed since session file run-a.json*. Only a project that never had any file keeps *not saved to a file* (round 24, B2, the coordinator's follow-up). [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **세션·모델 파일에서 연 이름 없는 프로젝트가 그 파일 이후로 바뀌었다고 말합니다.** File › Open으로 `run-a.json`을 열어 만든 프로젝트는 바뀐 뒤 상태 표시줄의 *Changed since session file run-a.json* 옆에서 *not saved to a file* 대신 *Untitled project · changed since run-a.json, not saved · …*입니다. 어떤 파일도 없었던 프로젝트만 *not saved to a file*입니다(round 24, B2, 코디네이터의 후속 결정). [워크스페이스](packages/simcase/workspace.md).
