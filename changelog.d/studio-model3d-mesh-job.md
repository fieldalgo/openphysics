# Added

## English

- `simcase`: **the geometry lab meshes a 3d component in a cancellable job and shows the mesh (experimental).** The page shows the `I-MESH-ESTIMATE` estimate first ("Estimate 48,000 tetrahedra · about 30 s", at 0.6 ms per tetrahedron) and disables **Mesh** with the refusal above `mesh.element_count_limit`; the server refuses such a request before any process starts. **Mesh** runs `simcase.build_mesh3d` in a child process (`multiprocessing`, `spawn` on every platform) that **Cancel meshing** terminates ("Meshing cancelled; nothing kept."), so a meshloom input that never returns can still be ended. The page shows the steps Studio knows, the elapsed time and "taking longer than the estimate" past twice the estimate; one 3D mesh job runs per server (429 otherwise). The server keeps the latest mesh per component, keyed by the SHA-256 of the canonical geometry and mesh blocks, and answers only its surface: a mesh view draws the exterior and interface triangles by region with mesh edges, and a pick gives the same face names; stats list nodes, tetrahedra, regions and the min and median quality. New routes `/api/model3d/mesh`, `/api/model3d/mesh/estimate` and `/api/model3d/jobs/…`. Checks W8 (CI job `studio-mesh3d-w8`, main pushes and manual dispatch), W9 and W12 pass; W14 is recorded with software GL only, its gate not run. [3D view, Mesh](docs/packages/simcase/studio_3d.md#mesh).

## 한국어

- `simcase`: **형상 실험실이 3d 구성 요소를 취소할 수 있는 작업으로 메시하고 메시를 보여 줍니다(실험적).** 페이지는 먼저 `I-MESH-ESTIMATE` 추정("Estimate 48,000 tetrahedra · about 30 s", 사면체당 0.6 ms)을 보여 주고, `mesh.element_count_limit`를 넘으면 거부 문구와 함께 **Mesh**를 끕니다. 서버도 그런 요청은 프로세스를 시작하기 전에 거부합니다. **Mesh**는 `simcase.build_mesh3d`를 자식 프로세스(`multiprocessing`, 모든 플랫폼에서 `spawn`)에서 돌리고 **Cancel meshing**이 그 프로세스를 끝내므로("Meshing cancelled; nothing kept."), 끝나지 않는 meshloom 입력도 멈출 수 있습니다. 페이지는 Studio가 아는 단계, 경과 시간, 추정의 두 배를 넘으면 "taking longer than the estimate"를 보여 주며, 서버마다 3D 메시 작업은 하나만 돕니다(아니면 429). 서버는 구성 요소마다 마지막 메시를 정규화한 형상·메시 블록의 SHA-256을 키로 보관하고 겉면만 답합니다. 메시 보기는 바깥 삼각형과 경계면 삼각형을 영역별 색과 메시 모서리로 그리고, 고르면 같은 면 이름이 나오며, 통계는 절점, 사면체, 영역, 품질 최솟값과 중앙값입니다. 새 경로는 `/api/model3d/mesh`, `/api/model3d/mesh/estimate`, `/api/model3d/jobs/…`입니다. 검사 W8(CI job `studio-mesh3d-w8`, main push와 수동 dispatch), W9, W12가 통과하고, W14는 소프트웨어 GL로만 기록했으며 관문은 돌리지 않았습니다. [3D 보기, 메시](packages/simcase/studio_3d.md#메시).
