# Changed

## English

- Studio: **the status line names where the current inputs come from.** When the viewed run has other inputs and another run has the current ones, it ends with *current inputs from Run 2 · Design B* (it read *Run 2 has them*), so after reopening a file it is clear which run's inputs are current. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **상태 표시줄이 현재 입력의 출처를 밝힙니다.** 보고 있는 실행의 입력이 다르고 다른 실행이 현재 입력을 가지면 줄이 *current inputs from Run 2 · Design B*로 끝납니다(전에는 *Run 2 has them*). 그래서 파일을 다시 연 뒤에도 어느 실행의 입력이 현재인지 알 수 있습니다. [워크스페이스](packages/simcase/workspace.md).
