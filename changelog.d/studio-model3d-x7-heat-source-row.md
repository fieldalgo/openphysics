# Added

## English

- `simcase`: **Studio 3D's run table names the heat source (experimental).**
  - After Tmin, a **Heat source** row reads the run's total source and its regions, for example *4 W in Si (top)*; several regions read *N W in A, B*.
  - The regions come from the run record's document. A run without a heat source has no such row.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 실행 표가 열원을 밝힙니다(실험적).**
  - Tmin 다음 **Heat source** 행이 실행의 총 열원과 그 영역을 읽어 줍니다. 예: *4 W in Si (top)*. 영역이 여럿이면 *N W in A, B*입니다.
  - 영역은 실행 기록의 문서에서 옵니다. 열원이 없는 실행에는 이 행이 없습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
