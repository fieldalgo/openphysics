# Changed

## English

- `simcase`: **Studio 3D's Use for → Fixed temperature takes the temperature in the same row (experimental).**
  - A **Temperature (K)** box appears beside the name.
  - **Apply** waits for a valid value and says why (*Type a temperature in K to apply.*).
  - The node is then written with that value (*Fixed temperature 330 K on stack.top.top.*) in one Undo step. Before, it was written at 300 K and edited afterwards.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 Use for → Fixed temperature가 같은 줄에서 온도를 받습니다(실험적).**
  - 이름 옆에 **Temperature (K)** 상자가 나옵니다.
  - **Apply**는 올바른 값을 기다리며 이유를 말합니다(*Type a temperature in K to apply.*).
  - 그런 다음 그 값으로 노드를 씁니다(*Fixed temperature 330 K on stack.top.top.*). Undo 한 단계입니다. 전에는 300 K로 쓴 뒤 고쳐야 했습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
