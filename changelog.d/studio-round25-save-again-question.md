# Changed

## English

- Studio: **on the download path, Save asks before it downloads a file again.** Where the browser has no save dialog (Firefox, Safari), File › Save and Ctrl+S of a project file this tab already downloaded ask *Download design-a-ng.json again? This browser cannot replace the earlier file and may name the new one design-a-ng (1).json.* with **Download again**, **Save As…** and **Cancel**; they downloaded again with no question, and the browser named the copies *(1)*, *(2)*. Cancel writes nothing; Save As… opens the name dialog. The first Save of a project with no file, a file opened or restored, and the browser's save dialog (Chrome, Edge) are unchanged (round 25, A2). [Workspace](docs/packages/simcase/workspace.md#file-menu-and-file-kinds).

## 한국어

- Studio: **다운로드 경로에서 Save가 파일을 다시 내려받기 전에 묻습니다.** 저장 대화상자가 없는 브라우저(Firefox, Safari)에서 이 탭이 이미 내려받은 프로젝트 파일의 File › Save와 Ctrl+S는 *Download design-a-ng.json again? This browser cannot replace the earlier file and may name the new one design-a-ng (1).json.*와 **Download again**, **Save As…**, **Cancel**을 묻습니다. 전에는 묻지 않고 다시 내려받아 브라우저가 사본에 *(1)*, *(2)*를 붙였습니다. Cancel은 아무것도 쓰지 않고, Save As…는 이름 대화상자를 엽니다. 파일이 없는 프로젝트의 첫 Save, 열거나 복원한 파일, 브라우저의 저장 대화상자(Chrome, Edge)는 바뀌지 않습니다(round 25, A2). [워크스페이스](packages/simcase/workspace.md#file-메뉴와-파일-종류).
