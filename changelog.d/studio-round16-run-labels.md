# Changed

## English

- Studio: **a run of several shapes names each shape and its size.** *Run 5 · 2 shapes · Silicon* now reads *Run 5 · Core 500 × 220 + Substrate 3000 × 700 nm · Silicon* (the first three shapes, then *+N more*), and an open run adds *· open (PML 1 µm)* in the run list and the Compare pickers. Single-shape labels are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **형상이 여럿인 실행은 형상마다 이름과 크기를 적습니다.** *Run 5 · 2 shapes · Silicon*이 이제 *Run 5 · Core 500 × 220 + Substrate 3000 × 700 nm · Silicon*으로 읽히고(처음 세 형상, 그 뒤 *+N more*), 열린 경계 실행은 실행 목록과 Compare 선택 목록에 *· open (PML 1 µm)*을 덧붙입니다. 형상 하나인 실행의 이름은 그대로입니다. [워크스페이스](packages/simcase/workspace.md).
