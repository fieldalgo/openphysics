# Fixed

## English

- Studio: **Run numbers no longer change within a tab.** When the six-run limit dropped the oldest unpinned run, the others were renumbered (Run 5 became Run 4) without a word. A new run now takes the largest number used so far + 1, every *Run N* (run list, Compare, status line, messages) keeps it, and Messages names the dropped run: *Run 3 (700 × 300 nm · 4 modes) was dropped: up to six runs are kept; pin a run to keep it.* Files are unchanged; opening a file numbers its runs from 1. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **탭 안에서 실행 번호가 바뀌지 않습니다.** 실행 여섯 개 한도가 가장 오래된 고정되지 않은 실행을 내보내면 나머지 번호가 말없이 바뀌었습니다(Run 5가 Run 4로). 이제 새 실행은 지금까지 쓴 가장 큰 번호 + 1을 받고, 모든 *Run N*(실행 목록, Compare, 상태 표시줄, 메시지)이 그 번호를 유지하며, Messages가 내보낸 실행을 밝힙니다: *Run 3 (700 × 300 nm · 4 modes) was dropped: up to six runs are kept; pin a run to keep it.* 파일 형식은 그대로이며 파일을 열면 실행 번호를 1부터 매깁니다. [워크스페이스](packages/simcase/workspace.md).
