# Changed

## English

- Studio: **Library and Save As words.** The card button reads *Open model* (*Open (runs stay in this tab)* read like opening a file); the card's description ends in *Runs stay in this tab until you close it.*; *Start new (no runs)* stays, and the cards keep their height. The Save As note on the download path reads *This browser cannot write to the file, so later saves download again under this name and may add “ (1)”.*, since *Chrome and Edge save to the same file.* read as false in a Chromium browser that downloads; that sentence is in the user guide only. [Workspace](docs/packages/simcase/workspace.md).
