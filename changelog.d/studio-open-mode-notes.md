# Added

## English

- Studio: **guided or leaky, said for each open-boundary mode.** An open run's modes table now says, for every mode, whether it can leak, from data the run already stores (Re n_eff, the shapes, the open edges, the wavelength): *Mode 2 is a leaky mode: Re n_eff 1.773 is below the index of Substrate (3.478), which reaches the open window edge, so light can leak into Substrate. The loss shown is that leakage; it is part of this structure, not a fault of the solve.*, *… is guided: … so it cannot leak. The loss shown is numerical (mesh and PML), not leakage.*, or that Studio makes no claim (a layer reaching an open edge only sideways, or Re n_eff within 0.02 of an edge index). After a core or edge note the sentence follows it in the same note. The engine's gain bound guards it: a guided mode whose loss exceeds the bound gets no text, a leaky one within it says the solve resolves no leakage loss. Closed runs, Compare, sessions and run records are unchanged. Gates G1–G10, pre-registered in the design draft, run as slow tests (`tests/simcase/test_studio_mode_channel_gate.py`, `test_studio_mode_channel_mesh.py`), Node checks and the workspace browser check. [Guided or leaky open-boundary modes](docs/packages/simcase/workspace.md#guided-or-leaky-open-boundary-modes).

## 한국어

- Studio: **열린 경계 모드마다 도파인지 누설인지 밝힙니다.** 열린 실행의 모드 표가 이제 실행이 이미 저장한 데이터(Re n_eff, 도형, 열린 가장자리, 파장)로 모드마다 누설할 수 있는지 말합니다: *Mode 2 is a leaky mode: Re n_eff 1.773 is below the index of Substrate (3.478), which reaches the open window edge, so light can leak into Substrate. The loss shown is that leakage; it is part of this structure, not a fault of the solve.*, *… is guided: … so it cannot leak. The loss shown is numerical (mesh and PML), not leakage.*, 또는 Studio가 판단하지 않음(옆으로만 열린 가장자리에 닿는 층, 또는 Re n_eff가 가장자리 굴절률과 0.02 이내). 코어 또는 가장자리 안내가 있으면 같은 안내 안에서 그 뒤에 이어집니다. 엔진의 이득 한계가 이를 검사합니다: 손실이 한계를 넘는 도파 모드에는 문구가 없고, 한계 안의 누설 모드는 이 풀이가 누설 손실을 분해하지 못한다고 말합니다. 닫힌 실행, Compare, 세션과 실행 기록은 바뀌지 않습니다. 설계 초안에 미리 등록한 G1–G10은 느린 테스트(`tests/simcase/test_studio_mode_channel_gate.py`, `test_studio_mode_channel_mesh.py`), Node 검사, 작업 공간 브라우저 검사로 확인합니다. [열린 경계 모드의 도파/누설](packages/simcase/workspace.md#열린-경계-모드의-도파누설).
