# Changed

## English

- Studio: **the group-index estimate's rule for runs from a file or recovery is checked and documented.** Session files and browser-recovery records store a run's completion time but not its wall time, so a run opened or restored has none: the estimate beside Run study skips it and uses an older run of the tab with a wall time, or shows none. Behaviour and the session format are unchanged; new tests pin the rule (round 24, B5). [Workspace](docs/packages/simcase/workspace.md).
