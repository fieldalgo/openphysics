# Fixed

## English

- Studio: **a screen reader announces each job update once.** The job panel's text and Messages were both live regions with the same words, so every 0.7 s update of a running job (*Computing job … · 0:03 · …*), and its validation, loading, error and done states, were announced twice. The job panel's text is now plain text; Messages stays the live region and carries every state, with the same words (round 25, A6). [Workspace](docs/packages/simcase/workspace.md#running-stopping-the-wait-and-resuming).

## 한국어

- Studio: **화면 낭독기가 작업 갱신을 한 번씩만 알립니다.** 작업 패널의 문구와 Messages가 같은 문구의 라이브 영역이어서, 실행 중인 작업의 0.7초마다의 갱신(*Computing job … · 0:03 · …*)과 검증·로딩·오류·완료 상태를 두 번씩 알렸습니다. 이제 작업 패널의 문구는 일반 문구이고, Messages가 같은 문구로 모든 상태를 싣는 라이브 영역으로 남습니다(round 25, A6). [워크스페이스](packages/simcase/workspace.md#실행대기-중단재개).
