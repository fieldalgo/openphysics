# Added

## English

- Studio: **project files, one file for every model of a tab.** **File › Save** and **Save As…** now write a project file (`openphysics-studio-project`, version 1) holding the workspace model (the optical, steady heat or Joule heating inputs with the optical runs) and the multiphysics model, each as its unchanged session file with its size and SHA-256 check value; **File › Open…** reads it after every check has passed, never starts a run, and refuses a damaged, edited or newer file by name with the tab unchanged. The title bar names the project and its file (*Heater study · heater-study.json · saved 13:15*, *… · downloaded 13:15*, *… · changed since …*, *Untitled project · not saved to a file · …*), the footer keeps the shown model's own words, and the Library is headed by the same line with a **Project name** field and **Rename**. Switching models keeps both in the tab: a card whose model is in the project reads *In this project · N runs* and shows it as it was left, with no question; the leave question now guards only a file that replaces the project. One save notice names every model; the *… runs of this tab are not in this file* sentence stays only under **File › Export › Model with runs (session file)…**, which writes the shown model's session file (it always asks for the name). A session or model file opened with File › Open becomes an untitled project holding that model. Session files and model files are unchanged. **Project files need this Studio or a newer one; File › Export › Model with runs writes a file older Studios open.** [Project files](docs/packages/simcase/workspace.md#project-files).

## 한국어

- Studio: **탭의 모든 모델을 담는 파일 하나, 프로젝트 파일이 생겼습니다.** **File › Save**와 **Save As…**는 이제 작업 공간 모델(광학, 정상 열 또는 Joule 가열 입력과 광학 실행)과 다중물리 모델을 각각 바뀌지 않은 세션 파일로, 크기와 SHA-256 검사값과 함께 담은 프로젝트 파일(`openphysics-studio-project`, 버전 1)을 씁니다. **File › Open…**은 모든 검사를 통과한 뒤에만 읽고, 실행을 시작하지 않으며, 손상되거나 편집되거나 더 새로운 파일은 이유를 말하며 거부하고 탭은 그대로 둡니다. 제목 표시줄은 프로젝트와 그 파일을 알리고(*Heater study · heater-study.json · saved 13:15*, *… · downloaded 13:15*, *… · changed since …*, *Untitled project · not saved to a file · …*), 바닥줄은 보이는 모델의 문구를 그대로 쓰며, Library 맨 위에는 같은 줄과 **Rename**이 붙은 **Project name** 칸이 있습니다. 모델을 바꿔도 두 모델 모두 탭에 남습니다. 프로젝트에 있는 모델의 카드에는 *In this project · N runs*가 나오고 고르면 묻지 않고 두고 간 그대로 보이며, 떠나기 질문은 이제 파일이 프로젝트를 대신할 때만 나옵니다. 저장 알림 하나가 모든 모델을 말합니다. *… runs of this tab are not in this file* 문장은 보이는 모델의 세션 파일을 쓰는 **File › Export › Model with runs (session file)…**(늘 이름을 물음)에만 남습니다. File › Open으로 연 세션 파일이나 모델 파일은 그 모델을 담은 이름 없는 프로젝트가 됩니다. 세션 파일과 모델 파일은 바뀌지 않습니다. **프로젝트 파일에는 이 Studio나 더 새 Studio가 필요합니다. File › Export › Model with runs는 이전 Studio도 여는 파일을 씁니다.** [프로젝트 파일](packages/simcase/workspace.md#프로젝트-파일).
