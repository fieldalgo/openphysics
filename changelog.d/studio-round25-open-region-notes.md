## English

- Studio: **open-boundary results say where each mode lies, as closed windows do.** The modes table of an open run gets the closed window's note rows, with the same thresholds and measured over the physical window only (the PML excluded): *Mode 3 is the core mode: 64 % of |E|² in the window (PML excluded) is in Core, which does not touch the window edge.*, *Mode 2 is mostly in Substrate (93 % of |E|² in the window, PML excluded), which continues into the PML at the open window edge.*, and at a closed edge of the open run *… which touches the closed bottom edge; its n_eff depends on that closed edge. Open it in Geometry › Boundaries to leave it open.* The notes make no guided or leaky claim (round 25, A4). [Workspace](docs/packages/simcase/workspace.md#open-boundary-in-the-optical-workspace).
