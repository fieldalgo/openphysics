# Changed

## English

- `simcase`: **Studio 3D's view toolbar can hide regions (experimental).** **Regions** has a checkbox per region. An unchecked region is hidden in the geometry, mesh and result views, so an inner face can be picked: in the +z view, `via.z1` is picked once *Si (top)* is hidden. A face's names now end with *Any of these names selects this face.* The engine's names are unchanged.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D 보기 도구 막대에서 영역을 숨길 수 있습니다(실험적).** **Regions**에는 영역마다 확인란이 있습니다. 해제한 영역은 형상, 메시, 결과 보기에서 숨겨지므로 안쪽 면을 고를 수 있습니다: +z 보기에서 `via.z1`은 *Si (top)*을 숨기면 골라집니다. 면의 이름 목록 끝에 이제 *Any of these names selects this face.*가 있습니다. 엔진의 이름은 바뀌지 않습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
