# Fixed

## English

- Studio: **after File › Open or Restore, Compare offers the two newest runs for a named pair.** A pair read from a file or browser recovery whose two runs are both named is kept because they are named, not as picked by hand, so after a new run Compare reads *Run 4 is newer than this pair · Compare the two newest: Run 3 and Run 4*, as it does before a save; it offered *Compare Run 4 with B*. A pair read from a file whose runs are not both named keeps the earlier rule. No file format changes (round 25, A3). [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **File › Open이나 복원 뒤에도 이름 붙은 쌍이면 Compare가 가장 새 두 실행을 제안합니다.** 파일이나 브라우저 복구에서 읽은 쌍의 두 실행에 모두 이름이 있으면 직접 고른 쌍이 아니라 이름 때문에 유지되는 쌍으로 보므로, 새 실행 뒤 Compare는 저장 전과 같이 *Run 4 is newer than this pair · Compare the two newest: Run 3 and Run 4*를 보입니다. 전에는 *Compare Run 4 with B*를 제안했습니다. 두 실행에 모두 이름이 있지는 않은 쌍은 예전 규칙을 따릅니다. 파일 형식은 바뀌지 않습니다(round 25, A3).
