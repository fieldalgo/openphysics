# Changed

## English

- Studio: **one state, one message.** When an edit leaves the inputs equal to a run's, Messages keeps the edit's own sentence and the *No need to run: Run 6 already has these results. …* sentence, without *Run explicitly to compute new results.* beside it. The status bar of a run read from a file or recovered from this browser says it *has the results of the current inputs* (heated model: *… of the current model*) instead of *press Run to compute it here*, and the line beside Run study reads *If you run: drops Run 3 (…) · pin it to keep it*. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **상태 하나에 메시지 하나.** 편집 뒤 입력이 어떤 실행과 같으면 Messages는 편집 자신의 문장과 *No need to run: Run 6 already has these results. …* 문장만 두고, 그 옆의 *Run explicitly to compute new results.*를 뺍니다. 파일에서 읽었거나 이 브라우저에서 복구한 실행의 상태 표시줄은 *press Run to compute it here* 대신 *has the results of the current inputs*(가열 모델: *… of the current model*)라고 적고, Run study 옆 줄은 *If you run: drops Run 3 (…) · pin it to keep it*로 읽힙니다. [워크스페이스](packages/simcase/workspace.md).
