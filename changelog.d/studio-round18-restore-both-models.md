# Changed

## English

- Studio: **a browser-restore offer names the project's other model.** A recovery record holds one model, but its project file may hold both: when browser recovery also holds a record of the other model under the same file, the offer lists it with its runs, *· also in this project: Heated silicon waveguide · Run 1 (restored separately)* (or *(already in this tab)*). The button still restores its own model. [Workspace](docs/packages/simcase/workspace.md).
