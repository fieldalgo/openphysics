# Changed

## English

- Studio: **every run label names its boundary right after the run number and name.** Closed runs are tagged *closed* (they had no tag) and open runs *open (PML 1 µm)*, now before the shape list instead of after it, in the run list, the Compare pickers, the Compare headings and the n_eff table's run lines: *Run 7 · open (PML 1 µm) · Core 500 × 220 + Substrate 3000 × 700 nm · Silicon · λ 1550 nm*. A label cut short in a picker still shows the boundary. [Workspace](docs/packages/simcase/workspace.md).

- Studio: **모든 실행 이름이 실행 번호와 이름 바로 뒤에 경계를 밝힙니다.** 닫힌 실행은 *closed*(태그가 없었음), 열린 실행은 *open (PML 1 µm)* 태그가 붙고, 이제 형상 목록 뒤가 아니라 앞에 옵니다(실행 목록, Compare 선택 목록, Compare 제목, n_eff 표의 실행 줄): *Run 7 · open (PML 1 µm) · Core 500 × 220 + Substrate 3000 × 700 nm · Silicon · λ 1550 nm*. 선택 목록에서 이름이 잘려도 경계가 보입니다.
