# Changed

## English

- Studio: **the words say when fields move.** The run list's note and the Results block of a run without its fields now read *Fields are kept up to 16.8 MB. When a result or a recompute arrives, Studio keeps the selected run's fields first, then pinned runs', then the newest. Selecting a run does not bring its fields back; Recompute does.* Before a run with no run of the same geometry, boundary and Modes to find to estimate its size, the line beside **Run study** reads *If you run: older runs' fields may not be kept (16.8 MB limit) · pin a run to keep its fields first* when the room left is less than the smallest field kept; it names no run (round 25, A1). [Workspace](docs/packages/simcase/workspace.md#keeping-runs-values-and-fields).
