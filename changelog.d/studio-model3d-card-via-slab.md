# Added

## English

- `simcase`: **Studio's Library has a second 3D card, Copper via through a slab (experimental).** It is a copper cylinder through a slab, meshed by meshloom's `via_in_slab` builder shape, with 300 K at the bottom and 301 K at the top. Mesh 1 and Run take it as they take the first card. A project holds one 3D model: choosing the other card while one is open says so and changes nothing. The project file names the card (`via-slab-3d`), and Export suggests the card's file name. The first card's note now points to the round via, and its description no longer says meshing and heat come later.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio의 Library에 두 번째 3D 카드 Copper via through a slab이 생깁니다(실험적).** 슬래브를 지나는 구리 원기둥을 meshloom의 `via_in_slab` builder 형상으로 메시하며, 아래는 300 K, 위는 301 K입니다. Mesh 1과 Run은 첫 카드처럼 받습니다. 프로젝트는 3D 모델 하나를 담으므로, 하나가 열린 동안 다른 카드를 고르면 그렇게 말하고 아무것도 바꾸지 않습니다. 프로젝트 파일은 카드(`via-slab-3d`)를 밝히고, Export는 카드의 파일 이름을 제안합니다. 첫 카드의 안내는 이제 둥근 via를 가리키고, 설명은 더 이상 메시와 열이 나중에 온다고 말하지 않습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
