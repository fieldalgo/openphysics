# Changed

## English

- `simcase`: **Studio 3D: another 3D card opens in a new tab at one click, or replaces the held model after a question (experimental).**
  - While a project holds a 3D model, the other 3D card reads **Open in a new tab** with the reason, and one click opens it in a fresh tab.
  - **Replace the 3D model…** asks first. It names exactly what is dropped: the model, its runs, and whether it is saved in the project file, changed since, or not saved. It offers File › Save.
  - After Replace, **Undo** in Messages brings the earlier model and its run records back in one step.
  - The project's other models, their runs and browser recovery are not touched. A project still holds one 3D model.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D: 다른 3D 카드는 한 번에 새 탭으로 열거나, 물은 뒤 지금 모델을 바꿉니다(실험적).**
  - 프로젝트가 3D 모델을 담고 있는 동안 다른 3D 카드는 이유와 함께 **Open in a new tab**으로 읽히고, 한 번 누르면 새 탭에서 열립니다.
  - **Replace the 3D model…**은 먼저 묻습니다. 무엇이 빠지는지 정확히 밝힙니다: 모델, 그 실행, 그리고 프로젝트 파일에 저장되었는지, 그 뒤 바뀌었는지, 저장되지 않았는지. File › Save를 둡니다.
  - Replace 뒤 Messages의 **Undo**는 이전 모델과 실행 기록을 한 단계로 되돌립니다.
  - 프로젝트의 다른 모델, 그 실행, 브라우저 복구는 건드리지 않습니다. 프로젝트는 여전히 3D 모델 하나를 담습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
