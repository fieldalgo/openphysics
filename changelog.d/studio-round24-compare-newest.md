# Changed

## English

- Studio: **Compare offers the two newest runs when newer runs exist and the pair was not picked by hand.** A pair kept because both runs are named now reads *Run 7 is newer than this pair · Compare the two newest: Run 6 and Run 7*, one action that shows the newest pair, where it offered *Compare Run 7 with B*. A pair picked by hand keeps that swap and is never replaced by itself (round 24, B4). [Workspace](docs/packages/simcase/workspace.md).
