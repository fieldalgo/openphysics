# Changed

## English

- Studio: **after a change, the header keeps naming the file a recovered project came from.** A project restored from a browser record of a file (one that still matched it or not) now reads *both-models · changed since both-models.json, not saved · updating browser recovery* (or *… · kept for recovery in this browser*, *… without the fields of Run 6*) after the next change, where it fell back to *… · not saved to a file · …* beside the status bar's *Changed since session file both-models.json*. A project no file held keeps *not saved to a file* (round 24, B2). [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **변경 뒤에도 헤더가 복구한 프로젝트가 온 파일을 밝힙니다.** 파일의 브라우저 기록(그 파일과 같았든 아니든)에서 복원한 프로젝트는 다음 변경 뒤 상태 표시줄의 *Changed since session file both-models.json* 옆에서 *… · not saved to a file · …*로 돌아가던 대신 *both-models · changed since both-models.json, not saved · updating browser recovery*(또는 *… · kept for recovery in this browser*, *… without the fields of Run 6*)입니다. 파일에 담긴 적 없는 프로젝트는 *not saved to a file* 그대로입니다(round 24, B2). [워크스페이스](packages/simcase/workspace.md).
