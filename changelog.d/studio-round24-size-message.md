# Changed

## English

- Studio: **the over-the-limit message uses one unit and says first what browser recovery left out.** A run that makes an optical session go over the limit now adds *Session is now 17.0 MB, over the 16.8 MB limit. Browser recovery keeps every run's values; the field plots of Run 6 are not kept. File › Save will ask whether to keep the field plots of the selected and pinned runs only (Runs 1, 2 and 9).*, where it mixed MiB and MB and ended with *Browser recovery keeps every field but those of Run 6.* Save's refusals of selected and pinned runs over the limit use MB to one decimal too (round 24, B3). [Workspace](docs/packages/simcase/workspace.md).

Browser recovery keeps every run's values; the field plots of Run 6 are not kept. File › Save will ask whether to keep the field plots of the selected and pinned runs only (Runs 1, 2 and 9).*를 붙입니다. 전에는 MiB와 MB를 섞고 *Browser recovery keeps every field but those of Run 6.*으로 끝났습니다. 한도를 넘는 선택·고정 실행에 대한 저장 거부도 MB 소수 한 자리를 씁니다(round 24, B3).
