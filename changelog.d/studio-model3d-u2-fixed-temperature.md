# Changed

## English

- `simcase`: **Studio 3D's Use for → Fixed temperature opens what it made (experimental).** The new fixed temperature's node opens in Settings with Temperature focused. Messages follows a later value change (*Fixed temperature 310 K on stack.top.top.*), where before it kept saying 300 K. The name box beside the select has a visible label, **Selection name** or **Boundary name**.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).
