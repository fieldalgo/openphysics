# Changed

## English

- Studio: messages, notes and the Library say **File › Save** instead of “Save session” (*File › Save keeps it in a file*, *· File › Save keeps them*; the leave and open dialogs keep naming their own **Save session** button). The page tabs control one `role=tabpanel` page panel named by the selected tab. The n_g help of a run without n_g reads *Turn on Also compute group index in Study or Optical modes*. [Workspace](docs/packages/simcase/workspace.md).
