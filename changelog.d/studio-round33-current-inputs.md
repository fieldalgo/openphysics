# Changed

## English

- Studio: **after an optical model is opened from a project or session file, or restored from this browser, Messages names its current inputs** (round 33, M1). The inputs that become current are unchanged: those the file or record kept, often the last run saved. The open or restore line (for a project, also when both models are opened or restored) ends with *Current inputs are Run 2 · Design B's.* when the inputs are a run's (the newest such run; *Current inputs are Run 3's.* for an unnamed run), else with the save message's *Current inputs (650 × 300 nm) have no run yet.*; nothing is added without runs. The heated model's messages are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **광학 모델을 프로젝트나 세션 파일에서 열거나 이 브라우저에서 복원하면 Messages가 현재 입력을 밝힙니다**(33차, M1). 어떤 입력이 현재 입력이 되는지는 그대로이며, 파일이나 기록이 담은 입력(흔히 마지막으로 저장된 실행)입니다. 열기나 복원 줄(프로젝트에서는 두 모델을 함께 열거나 복원할 때도)은 입력이 실행의 것이면 *Current inputs are Run 2 · Design B's.*(그런 실행 중 가장 새것; 이름 없는 실행이면 *Current inputs are Run 3's.*), 아니면 저장 메시지와 같은 *Current inputs (650 × 300 nm) have no run yet.*로 끝나며, 실행이 없으면 아무것도 붙지 않습니다. 가열 모델의 메시지는 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
