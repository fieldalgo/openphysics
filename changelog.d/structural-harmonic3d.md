# Added

## English

- Solve the steady 3D vibration response to harmonic body and surface loads with Rayleigh damping. The Python solver returns complex displacement, elastic stress and support reactions across the supplied frequencies. [Usage](docs/packages/galerkin/structural_harmonic3d.md).

## 한국어

- 레일리 감쇠가 있는 3D 구조물에서 조화 체적력과 표면력에 의한 정상 진동 응답을 계산합니다. Python 솔버가 입력 주파수별 복소 변위, 탄성 응력과 지지 반력을 반환합니다. [사용법](packages/galerkin/structural_harmonic3d.md).
