# Changed

## English

- Studio: **Run study names the options that make the next run slower.** The group-index option, left on from an earlier task, made open runs about 3× slower without notice. Beside Run study the ribbon now reads *group index on · 3 solves* (with an open boundary's PML check, *PML check on · 3 solves*). The options keep their state.
