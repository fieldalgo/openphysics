# Changed

## English

- `simcase`: **Studio 3D opens a second 3D card in a new tab (experimental).** A project holds one 3D model. Choosing another 3D card now gives an **Open in a new tab** button beside the refusal. The button opens `/workspace?card=<card>&fresh=1`, a tab whose own project starts with that card. Nothing is restored into it. It offers no browser recovery and writes none, so the recovery of the tab it came from is unchanged. A 3D model is not kept for browser recovery: save the project or session to keep it. Card 1's note now reads *Square via: a box through the oxide, in a layer stack* and no longer names card 2.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D가 두 번째 3D 카드를 새 탭에서 엽니다(실험적).** 프로젝트는 3D 모델 하나를 담습니다. 다른 3D 카드를 고르면 이제 거절 옆에 **Open in a new tab** 단추가 있습니다. 이 단추는 `/workspace?card=<card>&fresh=1`을 엽니다: 그 카드로 자기 프로젝트를 시작하는 탭입니다. 그 탭에는 아무것도 복구되지 않습니다. 그 탭은 브라우저 복구를 제안하지도 쓰지도 않으므로, 그 탭을 연 탭의 복구는 바뀌지 않습니다. 3D 모델은 브라우저 복구에 보관되지 않습니다. 보관하려면 프로젝트나 세션을 저장하십시오. 카드 1의 설명은 이제 *Square via: a box through the oxide, in a layer stack*로 읽히며 카드 2를 더는 언급하지 않습니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
