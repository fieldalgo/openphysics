# Changed

## English

- `simcase`: **Studio 3D Compare explains the sign of a heat-rate difference (experimental).** One line under the table says that heat rates keep the run table's sign (positive into the model) and that B − A is run B minus run A, with an example from the pair, such as *−31.7515 W through z0 means more heat leaves through z0 in run B.*

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D Compare가 열률 차의 부호를 설명합니다(실험적).** 표 아래 한 줄이, 열률은 실행 표의 부호(모델로 들어가면 양수)를 따르고 B − A는 run B에서 run A를 뺀 값이라고 말하며, 짝에서 든 예를 붙입니다. 예: *−31.7515 W through z0 means more heat leaves through z0 in run B.*

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
