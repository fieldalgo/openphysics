# Fixed

## English

- Studio: **Library › Open returns to where you were.** Opening a model of the tab that has runs showed its Model page; now the heated model returns to its Results and the optical model to its Results or Compare with the run last viewed. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Library에서 모델을 열면 있던 곳으로 돌아갑니다.** 실행이 있는 탭의 모델을 열면 Model 페이지가 나왔습니다. 이제 가열 모델은 Results로, 광학 모델은 마지막으로 본 실행의 Results나 Compare로 돌아갑니다. [워크스페이스](packages/simcase/workspace.md).
