# Changed

## English

- `simcase` Studio workspace: **usability fixes: the screen says where a shown result came from** (screen words only; the solver, documents, results, tolerances and session files are unchanged). After Open session or a browser recovery, the dock heading, the status bar and the multiphysics step rows no longer say the run was solved: they read *Run 2 · read from file, not recomputed* (or *recovered from this browser, not recomputed*), with rows **From file** / **From this browser** and no solve times; a run made in the tab keeps its words and freshness works as before. *Imported file result — not recomputed or authenticated* becomes *Loaded from file, not recomputed. Studio checks the file for damage, not who made it.* (optical files, which carry no digest: *checks that the file is well formed*). The Models page says what Save session keeps of each model (the heated silicon waveguide with its runs; steady heat and Joule heating inputs, their results staying in the tab), how Undo and the coupled model relate, and drops a sentence about other views. Every recovery entry names its model and runs (*Optical waveguide · 2 runs · design A, Run 2*), optical run list entries show seconds, and opening the heated model over optical runs says in Messages where those runs stay. [Experimental model workspace](docs/packages/simcase/workspace.md#working-with-a-model).

## 한국어

- `simcase` Studio 작업 공간: **사용성 수정: 보이는 결과의 출처를 화면이 밝힙니다**(화면 문구만 바뀌며 솔버, 문서, 결과, 허용 오차, 세션 파일은 그대로입니다). Open session이나 브라우저 복구 뒤 도크 제목, 상태 표시줄, 다중물리 단계 행이 더는 실행을 풀었다고 하지 않고 *Run 2 · read from file, not recomputed*(또는 *recovered from this browser, not recomputed*)로, 행은 **From file** / **From this browser**로 풀이 시간 없이 표시합니다. 탭에서 만든 실행은 그 문구를 유지하고 최신 여부 판단은 그대로입니다. *Imported file result — not recomputed or authenticated*는 *Loaded from file, not recomputed. Studio checks the file for damage, not who made it.*이 됩니다(다이제스트가 없는 광학 파일은 *checks that the file is well formed*). Models 화면은 모델마다 Save session이 남기는 것(가열 실리콘 도파로는 모델과 실행, 정상 열과 줄 가열은 입력이며 결과는 탭에만 남음)과 Undo와 결합 모델의 관계를 밝히고, 다른 보기에 관한 문장을 뺍니다. 복구 항목은 모두 모델과 실행을 이름으로 보여 주고(*Optical waveguide · 2 runs · design A, Run 2*), 광학 실행 목록 항목은 초까지 나오며, 광학 실행이 있는 채로 가열 모델을 열면 Messages가 그 실행이 남는 곳을 알려 줍니다. [실험적 모델 작업공간](packages/simcase/workspace.md#모델-편집).
