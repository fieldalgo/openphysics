# Fixed

## English

- Studio: **the restore box and a model card name the same time for one record.** After a project save, the stored record of the model not shown is linked to the project file and its save time while the record itself is older, so the card read *same as file both-models.json, saved 8:31 AM* and the box *… saved 8:30 AM*. Both now give the file's save time for a record that still matches a file it was saved to, else the record's own time; the order of the offers is unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **복원 상자와 모델 카드가 한 기록에 같은 시각을 밝힙니다.** 프로젝트를 저장하면 보이지 않는 모델의 저장 기록이 프로젝트 파일과 그 저장 시각에 이어지지만 기록 자체는 더 오래되어, 카드는 *same as file both-models.json, saved 8:31 AM*, 상자는 *… saved 8:30 AM*이라고 적었습니다. 이제 둘 다 저장했던 파일과 아직 같은 기록에는 파일의 저장 시각을, 아니면 기록 자신의 시각을 씁니다. 제안의 순서는 그대로입니다. [워크스페이스](packages/simcase/workspace.md).
