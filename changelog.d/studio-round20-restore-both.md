# Changed

## English

- Studio: **one click restores both models of a project from this browser.** When the newest stored record's project file also holds the other model and browser recovery has that model's record, and the tab holds runs of neither model, the newest offer reads *Restore newest from this browser: Optical waveguide (6 runs) and Heated silicon waveguide (2 runs) · …* and restores both, the project name and file included, then shows the newest record's model. A second restore that fails keeps the first and names the model not restored. The per-model card offers stay; neither the session format nor the recovery record changed. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **한 번의 클릭으로 프로젝트의 두 모델을 이 브라우저에서 복원합니다.** 가장 새 저장 기록의 프로젝트 파일에 다른 모델도 있고 브라우저 복구에 그 모델의 기록이 있으며 탭이 두 모델 어느 쪽의 실행도 가지고 있지 않으면, 가장 새 제안이 *Restore newest from this browser: Optical waveguide (6 runs) and Heated silicon waveguide (2 runs) · …*로 읽히고 프로젝트 이름과 파일까지 둘 다 복원한 뒤 가장 새 기록의 모델을 보입니다. 두 번째 복원이 실패하면 첫 번째는 남기고 복원하지 못한 모델을 밝힙니다. 모델별 카드 제안은 그대로이며, 세션 형식과 복구 기록은 바뀌지 않았습니다. [워크스페이스](packages/simcase/workspace.md).
