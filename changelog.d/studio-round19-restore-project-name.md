# Fixed

## English

- Studio: **a browser restore keeps the project's name and file.** A record changed since the project file it was saved to brings back that name and file (the header reads *changed since saved …*); it did so only for a record that still matched the file. A record of a file that was opened holds no project name, so none is guessed: the header names the source, *Untitled project · recovered from a copy of both-models.json · not saved to a file · …*, as the status bar does. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **브라우저 복원이 프로젝트 이름과 파일을 지킵니다.** 저장했던 프로젝트 파일 이후로 바뀐 기록도 그 이름과 파일을 되살립니다(헤더 *changed since saved …*). 전에는 파일과 아직 같은 기록만 그랬습니다. 연 파일의 기록에는 프로젝트 이름이 없으므로 짐작하지 않습니다: 헤더가 상태 표시줄처럼 출처를 밝힙니다, *Untitled project · recovered from a copy of both-models.json · not saved to a file · …*. [워크스페이스](packages/simcase/workspace.md).
