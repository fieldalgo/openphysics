# Changed

## English

- Studio: **beside Run study, what the next run does and how long the last such run took.** The line now always names the boundary, an open boundary's searches and the options that add solves, then the wall time of the last run in this tab with the same boundary kind and group-index state: *Open boundary · 2 searches · group index on (3 solves) · last such run 3:40*, or *no earlier run* (round 17 named the slow options only, and all five round-18 users missed it). The time is kept in the tab only; opened and recovered runs have none. Choosing Open boundary while the group index is on adds a warning to Messages: *Group index is on: open-boundary runs with it take about three times as long.* The line sits in a box of fixed size, so the ribbon does not move. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Run study 옆에 다음 실행이 무엇을 하는지와 마지막 같은 종류의 실행이 얼마나 걸렸는지가 나옵니다.** 이 줄은 이제 늘 경계, 열린 경계의 검색 수, 풀이를 늘리는 선택을 밝히고, 그다음 이 탭에서 경계 종류와 군굴절률 상태가 같은 마지막 실행의 실제 시간을 적습니다: *Open boundary · 2 searches · group index on (3 solves) · last such run 3:40*, 없으면 *no earlier run*(round 17은 느리게 하는 선택만 밝혔고 round 18 사용자 다섯 모두 놓쳤음). 시간은 탭에만 보존되며 연 실행과 복원한 실행에는 없습니다. 군굴절률이 켜진 채 Open boundary를 고르면 Messages에 경고가 붙습니다: *Group index is on: open-boundary runs with it take about three times as long.* 이 줄은 크기가 고정된 상자에 있어 리본이 움직이지 않습니다.
