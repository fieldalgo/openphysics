# Added

## English

- `simcase`: **`thermal.steady3d` solves on an existing mesh.** `simcase.build_thermal3d_mesh(document)` makes the mesh the kind solves on by its own route choice (the `meshine.extrude` mesh for a lone slab `layers` component, otherwise `build_mesh3d`'s), with no physics block needed; `simcase.solve_thermal3d(doc, mesh)` solves on it and returns `simcase.run`'s result bit for bit; `simcase.mesh3d_to_arrays` and `simcase.mesh3d_from_arrays` write such a mesh as plain NumPy arrays (`numpy.load(..., allow_pickle=False)` reads them) and read it back bit for bit, refusing arrays of another format, other geometry or mesh blocks or another component; that arrays format is experimental and internal to Studio's process hand-off, not a file format users save. `simcase.run` is now that mesh step and then the same solve; the keys and results of `thermal.steady3d` are unchanged. `simcase.estimate_mesh3d` now answers a lone slab component with the extrude route's own count (exact up to 10,000 footprint triangles, a lower bound above, the exact count then checked before extruding), and its result gains `route` and `count`. [On an existing mesh](docs/packages/simcase/thermal_steady3d.md#on-an-existing-mesh).

## 한국어

- `simcase`: **`thermal.steady3d`가 이미 있는 메시에서 풉니다.** `simcase.build_thermal3d_mesh(document)`가 이 종류의 경로 선택대로(판 `layers` 하나만 가진 구성 요소는 `meshine.extrude` 메시, 그 밖에는 `build_mesh3d`의 것) physics 블록 없이 메시를 만들고, `simcase.solve_thermal3d(doc, mesh)`가 그 위에서 풀어 `simcase.run`의 결과를 비트까지 같게 돌려줍니다. `simcase.mesh3d_to_arrays`와 `simcase.mesh3d_from_arrays`는 그런 메시를 평범한 NumPy 배열로 쓰고(`numpy.load(..., allow_pickle=False)`로 읽힘) 비트까지 같게 되읽으며, 다른 형식, 다른 형상·메시 블록, 다른 구성 요소의 배열은 거부합니다. 이 배열 형식은 실험 단계이며 Studio의 프로세스 사이 넘겨주기 전용이고, 사용자가 저장하는 파일 형식이 아닙니다. 이제 `simcase.run`은 그 메시 단계 다음에 같은 풀이를 돌리며, `thermal.steady3d`의 키와 결과는 그대로입니다. `simcase.estimate_mesh3d`는 판 `layers` 하나만 가진 구성 요소에 압출 경로의 개수를 답하고(발자국 삼각형 10,000개까지 정확, 그 위로는 하한이며 그때는 압출 전에 정확한 개수를 확인), 결과에 `route`와 `count`가 더해집니다. [이미 있는 메시에서](packages/simcase/thermal_steady3d.md#이미-있는-메시에서).
