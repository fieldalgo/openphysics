# Fixed

## English

- `simcase`: **Studio 3D's Result view keeps a selected face's temperature colours (experimental).**
  - A face selected in the Result view was filled in solid red, the colour bar's hot end, so a 330 K top face read as the maximum.
  - It now keeps its temperature colours and is outlined in near-black. The geometry and mesh views are unchanged.
  - While a region is hidden, **Regions** reads *Regions (1 hidden)* and a line above the view reads *Hidden: Si (top). Faces shown where it was are interior.*

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 Result 보기가 선택한 면의 온도 색을 유지합니다(실험적).**
  - Result 보기에서 선택한 면이 색 막대의 뜨거운 끝인 빨강으로 채워져, 330 K 윗면이 최대처럼 읽혔습니다.
  - 이제 온도 색을 유지하고 검정에 가까운 윤곽선으로 표시됩니다. 형상 보기와 메시 보기는 그대로입니다.
  - 영역을 숨긴 동안 **Regions**는 *Regions (1 hidden)*로 읽히고 보기 위의 줄은 *Hidden: Si (top). Faces shown where it was are interior.*로 읽힙니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
