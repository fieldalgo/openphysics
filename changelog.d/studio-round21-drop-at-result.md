# Changed

## English

- Studio: **Run study starts at once.** The question before a run that the six-run limit would make drop a run (*Running drops Run 3 (…)* with Pin Run 3 and run, Run, Cancel) is gone, in the optical and the heated model. While the run computes, the line beside Run study reads *When this run finishes, Run 3 (…) is dropped*, and **Pin Run 3** keeps it; the drop happens when the result arrives. Messages then says *Run 3 (…) was dropped* and, when another unpinned run exists, offers **Keep Run 3, drop Run 4 (…) instead** until the next run starts. The tab never holds more than six runs. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Run study가 바로 시작합니다.** 실행 여섯 개 한도 때문에 실행 하나를 내보내게 되는 실행 전의 질문(*Running drops Run 3 (…)*와 Pin Run 3 and run, Run, Cancel)이 광학 모델과 가열 모델에서 없어졌습니다. 실행이 계산하는 동안 Run study 옆 줄은 *When this run finishes, Run 3 (…) is dropped*로 읽히고 **Pin Run 3**가 그 실행을 남깁니다. 내보내기는 결과가 도착할 때 일어납니다. 그 뒤 Messages는 *Run 3 (…) was dropped*라고 적고, 고정되지 않은 다른 실행이 있으면 다음 실행이 시작될 때까지 **Keep Run 3, drop Run 4 (…) instead**를 둡니다. 탭은 실행을 여섯 개보다 많이 두지 않습니다. [워크스페이스](packages/simcase/workspace.md).
