# Changed

## English

- Studio no longer writes a Messages sentence when an optical tab's fields switch to single precision. The note under the run list ("When fields would not all fit, they are kept at single precision.") and the line under a compact run's field view ("Field at single precision (float32). The values above are the engine's.") still say it where it applies. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- 광학 탭의 필드가 단정밀도로 바뀔 때 Studio가 더는 Messages 문장을 쓰지 않습니다. 실행 목록 아래 안내("When fields would not all fit, they are kept at single precision.")와 압축 실행의 장 보기 아래 줄("Field at single precision (float32). The values above are the engine's.")이 해당하는 곳에서 그대로 알립니다. [작업 공간](packages/simcase/workspace.md).
