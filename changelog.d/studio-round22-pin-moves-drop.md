# Changed

## English

- Studio: **pinning moves the drop, and Messages says so.** With six runs, **Pin Run 4** on the line beside Run study now says *Run 4 pinned. If you run: drops Run 5 (…) · pin it to keep it*. When a result drops a run and every other earlier run is pinned, the dropped words add *; every other earlier run is pinned, so no other run can be dropped instead*, which is why no swap is offered. In the optical and the heated model. [Workspace](docs/packages/simcase/workspace.md).
