# Changed

## English

- Studio: **the reason Open boundary set Modes to find back stays under the field** (round 35, L4). After the slab shortcut changed Modes to find from 2 to 4, choosing Open boundary still sets 2 back and ends the Messages line with *Modes to find back to 2: 4 was for the closed window's search near 2.46.*; the same reason now also stays under **Modes to find** in Physics › Optical modes, *Back to 2 with Open boundary: 4 was for the closed window's search near 2.46.*, because the next notice replaces the Messages line. It is kept until the next run starts or Modes to find or the outer boundary changes again (typed, Undo, Redo, Use this run's inputs, a new model or file). A browser check confirms the same on the *Slab modes first* dialog's **Set search near 2.46 · 4 modes and run** path after its closed run. The count rule, which inputs are current, Undo grouping, file formats, values and run records are unchanged. [Workspace](docs/packages/simcase/workspace.md).
