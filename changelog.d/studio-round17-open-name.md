# Fixed

## English

- Studio: **the ribbon's Open… button is named Open….** Its accessible name was *Open* while it showed *Open…*, so a click on the visible name reached the hidden File menu item and no file chooser opened. It is now named by its visible text. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **리본의 Open… 버튼 이름이 Open…입니다.** 화면에는 *Open…*인데 접근성 이름은 *Open*이라, 보이는 이름으로 누르면 숨은 File 메뉴 항목에 닿아 파일 선택 창이 열리지 않았습니다. 이제 보이는 글자로 이름을 붙입니다. [워크스페이스](packages/simcase/workspace.md).
