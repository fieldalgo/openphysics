# Changed

## English

- `simcase`: **Studio 3D says a run just finished is up to date (experimental).** Right after a run, Run's reason now reads *Run 1 is up to date with these inputs.* Before, *No need to run: Run 1 already has these results.* read as if nothing had run. The earlier wording returns after any edit, for example an edit that is then undone.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D가 막 끝난 실행이 최신이라고 말합니다(실험적).** 실행 직후 Run의 이유는 이제 *Run 1 is up to date with these inputs.*로 읽힙니다. 전에는 *No need to run: Run 1 already has these results.*가 아무것도 실행되지 않은 것처럼 읽혔습니다. 편집하면(예: 편집했다가 되돌려도) 이전 말로 돌아갑니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
