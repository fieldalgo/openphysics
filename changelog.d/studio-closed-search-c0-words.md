# Changed

## English

- Studio: **the closed-window placement note no longer says that more modes reach the core mode.** It now ends *Use Open boundary to leave that edge open.*, and its button reads **Set Modes to find to 4** (was *Find 4 modes*). Above a silicon substrate a closed window has many substrate modes above the core mode: the strip over a substrate's core TE mode (2.43931663) is mode 32 of a default closed run. [Workspace](docs/packages/simcase/workspace.md#modes-table).

## 한국어

- Studio: **닫힌 창 위치 안내가 더 이상 모드를 더 찾으면 코어 모드에 닿는다고 말하지 않습니다.** 이제 *Use Open boundary to leave that edge open.*으로 끝나고 버튼은 **Set Modes to find to 4**(이전 *Find 4 modes*)입니다. 실리콘 기판 위 닫힌 창에는 코어 모드보다 위에 기판 모드가 많습니다: 기판 위 스트립의 코어 TE 모드(2.43931663)는 기본 닫힌 실행의 32번째 모드입니다. [워크스페이스](packages/simcase/workspace.md#모드-표).
