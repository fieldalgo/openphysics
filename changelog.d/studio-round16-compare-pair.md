# Fixed

## English

- Studio: **Compare keeps a pair the user picked or a pair of two named runs.** Each new run moved Compare to the two newest runs, so a project saved Run 4 against Run 5 instead of Design A against Design B. A picked or named pair now stays, with *Run 5 is newer than this pair · Compare Run 5 with B*; otherwise Compare still opens on the two newest runs (Run 1 against Run 2). The project file stores the kept pair and opening it shows that pair. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare는 사용자가 고른 쌍이나 두 실행 모두 이름 있는 쌍을 유지합니다.** 새 실행마다 Compare가 가장 새 두 실행으로 옮겨 가, 프로젝트가 Design A 대 Design B 대신 Run 4 대 Run 5를 저장했습니다. 이제 고르거나 이름 붙인 쌍은 남고 *Run 5 is newer than this pair · Compare Run 5 with B*가 나옵니다. 그 밖에는 여전히 가장 새 두 실행(Run 1 대 Run 2)으로 엽니다. 프로젝트 파일은 유지한 쌍을 저장하고 열면 그 쌍을 보여 줍니다. [워크스페이스](packages/simcase/workspace.md).
