# Changed

## English

- Studio: the optical model keeps its runs' fields within one budget, the 16 MiB session less 16 KiB kept for the inputs (16.8 MB), shared by the tab, File › Save, the project entry and browser recovery, so a restore or an opened file brings back what the tab shows. When a field arrives (a result, Add runs from file, Open or Restore) the fields kept are the selected run's, then the pinned runs', then the newest others'; the other runs keep their values (n_eff, TE fractions, effective areas, n_g and the open-boundary candidates), and Messages names them: "Run 3 (…) keeps its values; its fields were not kept (16.8 MB limit)." with Keep Run 3's fields, not Run 4's (…). Selecting, pinning, naming or comparing runs never lets a field go. File › Save of the optical model no longer asks about 16 MiB (except when the selected run alone is over it), and the header no longer names fields that recovery left out. The run list marks a run without its fields "values only"; Results shows its values with a sentence in place of the field view; Compare lists its modes by number. Before a run, the line beside Run study says which runs would keep their values only, when a run of the same geometry, boundary and Modes to find gives the size. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: 광학 모델은 실행의 필드를 하나의 예산 안에서 보관합니다. 예산은 16 MiB 세션에서 입력용으로 남겨 두는 16 KiB를 뺀 크기(16.8 MB)이며, 탭, File › Save, 프로젝트 항목, 브라우저 복구가 함께 씁니다. 그래서 복원하거나 연 파일은 탭이 보여 주던 것을 그대로 되돌려 줍니다. 필드가 들어올 때(결과, Add runs from file, Open, Restore) 선택된 실행, 고정된 실행, 그다음 최신 실행 순으로 필드를 보관하고, 나머지 실행은 값(n_eff, TE 비율, 유효 면적, n_g, 열린 경계 후보)만 남기며 Messages가 그 실행을 알려 줍니다: "Run 3 (…) keeps its values; its fields were not kept (16.8 MB limit)."와 함께 Keep Run 3's fields, not Run 4's (…) 버튼. 실행을 선택하거나, 고정하거나, 이름을 붙이거나, 비교해도 필드는 빠지지 않습니다. 광학 모델의 File › Save는 더 이상 16 MiB를 묻지 않으며(선택된 실행 하나만으로 넘을 때는 예외), 머리글도 복구에서 빠진 필드를 나열하지 않습니다. 실행 목록은 필드가 없는 실행에 "values only"를 표시하고, Results는 필드 보기 대신 한 문장과 함께 그 값을 보여 주며, Compare는 그 모드를 번호 순으로 나열합니다. 실행 전에는 같은 형상, 경계, Modes to find의 실행으로 크기를 알 수 있을 때 Run study 옆 줄이 값만 남게 될 실행을 알려 줍니다.
