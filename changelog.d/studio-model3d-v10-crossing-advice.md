# Changed

## English

- `simcase`: **Studio 3D suggests how to fix a cylinder that crosses a domain side (experimental).** The refusal now reads, for example, *Cylinder via crosses the domain side x = 1 m. Keep cx ≤ 0.7 m (cx + r ≤ 1 m), or r ≤ 0.2 m.*, computed from the side and the radius. The engine's sentence and code are under Details.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

- `simcase`: **Studio 3D가 영역 옆면을 가로지르는 원기둥을 고치는 법을 제안합니다(실험적).** 이제 거부는 옆면과 반지름에서 계산해, 예를 들어 *Cylinder via crosses the domain side x = 1 m. Keep cx ≤ 0.7 m (cx + r ≤ 1 m), or r ≤ 0.2 m.*로 읽힙니다. 엔진의 문장과 코드는 Details 아래에 있습니다.
