# Changed

## English

- `simcase` Studio workspace: **fixes from the third agent usability round** (screen only; the solver, documents, results and session files are unchanged). (N1) The title holds one save indicator and the footer repeats it word for word: *Not saved to a file · kept for recovery in this browser* (or *updating browser recovery*, *browser recovery unavailable*) before a file save, *Sent to session file … · time* after one, never a claim that the file reached the disk. (N2) The routes back say which copy is durable: **Recover (this browser only)**, **Open session file (portable)…** and a line saying the session file is the copy that moves between computers; **Import runs from file** is now **Add runs from file (inputs unchanged)**. (N3) Field, mesh and profile plot axes, the point inspector and the profile coordinate are in nm, with ticks on round values (the saved view stays in µm); n_eff has 8 decimals everywhere, the candidate list included; the solver document summary now names its units correctly (geometry in nm, other lengths as quantities). (N4) The start page says model throughout: the **Models** tab, *Choose a model*, *Choosing a model changes physics selections …*. (R4) The Optical modes settings are headed *Optical modes*, and the Study step's **λ 1550 nm** opens the wavelength field. (N6) Compare field headings no longer repeat a run's name, and the plots come before the n_eff table. (R1) The separate **Pin this run** button is gone: naming a run pins it, and **Unpin this run** remains. [Workspace guide](docs/packages/simcase/workspace.md).

## 한국어

- `simcase` Studio 작업 공간: **세 번째 에이전트 사용성 라운드에서 나온 수정**(화면만 바뀌며 솔버, 문서, 결과, 세션 파일은 그대로). (N1) 제목에 저장 표시가 하나 있고 하단은 같은 문구를 그대로 보여 줍니다. 세션 파일 저장 전에는 *Not saved to a file · kept for recovery in this browser*(또는 *updating browser recovery*, *browser recovery unavailable*), 저장 뒤에는 *Sent to session file … · 시각*이며, 파일이 디스크에 저장됐다고 주장하지 않습니다. (N2) 돌아가는 길마다 어느 사본이 남는지 밝힙니다: **Recover (this browser only)**, **Open session file (portable)…**, 그리고 세션 파일이 컴퓨터 사이를 옮기는 사본이라는 한 줄. **Import runs from file**은 **Add runs from file (inputs unchanged)**가 되었습니다. (N3) 장·메시·단면 그림의 축, 점 조회, 단면 좌표는 nm이고 눈금은 둥근 값입니다(저장되는 보기는 µm 그대로). n_eff는 후보 목록을 포함해 어디서나 소수 8자리이고, 솔버 문서 요약은 단위를 바르게 밝힙니다(기하는 nm, 다른 길이는 양 문자열). (N4) 시작 화면은 model이라는 한 단어를 씁니다: **Models** 탭, *Choose a model*, *Choosing a model changes physics selections …*. (R4) Optical modes 설정 제목이 *Optical modes*이고, Study 단계의 **λ 1550 nm**가 파장 입력란을 엽니다. (N6) Compare 장 그림 제목이 실행 이름을 반복하지 않고 그림이 n_eff 표보다 먼저 나옵니다. (R1) 별도의 **Pin this run** 버튼을 없앴습니다. 이름을 붙이면 고정되며 **Unpin this run**은 남습니다. [작업 공간 안내](packages/simcase/workspace.md).
