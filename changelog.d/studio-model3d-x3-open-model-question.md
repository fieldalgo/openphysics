# Changed

## English

- `simcase`: **Studio 3D's other card reads Open model and asks first (experimental).**
  - While the project holds one 3D model, the Library's other 3D card reads **Open model**.
  - A click opens a question that names the held model and what would be lost, with **Save and replace**, **Replace without saving**, **Open in a new tab** and **Cancel**.
  - Save and replace replaces only once the project file holds the 3D model as it is; otherwise Messages reads *Not replaced: the project file was not saved.*
  - The separate **Replace the 3D model…** button and the reason line on the card are gone. Messages' one-step **Undo** stays.

  [3D models](docs/packages/simcase/workspace.md#3d-models-experimental).

## 한국어

- `simcase`: **Studio 3D의 다른 카드가 Open model로 읽히고 먼저 묻습니다(실험적).**
  - 프로젝트가 3D 모델 하나를 담는 동안 Library의 다른 3D 카드는 **Open model**로 읽힙니다.
  - 누르면 담긴 모델과 잃게 될 것을 밝히는 질문이 열리고, **Save and replace**, **Replace without saving**, **Open in a new tab**, **Cancel**을 둡니다.
  - Save and replace는 프로젝트 파일이 3D 모델을 지금 그대로 담을 때만 바꿉니다. 아니면 Messages는 *Not replaced: the project file was not saved.*로 읽힙니다.
  - 따로 있던 **Replace the 3D model…** 버튼과 카드의 이유 줄은 없어졌습니다. Messages의 한 단계 **Undo**는 그대로입니다.

  [3D 모델](packages/simcase/workspace.md#3d-모델실험적).
