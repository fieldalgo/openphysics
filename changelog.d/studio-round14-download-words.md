# Changed

## English

- Studio: **a downloaded session file reads *downloaded*, not *saved*.** On the download path the header and the footer read *<name> · downloaded 05:44* and, after an edit, *<name> · changed since downloaded*, with the title text *Your browser may have added “ (1)” to the file name.*; *saved* is said only after the browser's save dialog wrote the file. The Save As name dialog adds *Later saves download again under this name; your browser may add “ (1)”.* A restore from this browser whose record still matched its file (*same as file X*) makes X the current file, so **Save** downloads under X and **Save As** suggests it (*X · changed since restored* after an edit). [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **내려받은 세션 파일은 *saved*가 아니라 *downloaded*로 표시합니다.** 다운로드 경로에서 헤더와 하단은 *<name> · downloaded 05:44*, 편집 뒤에는 *<name> · changed since downloaded*이고, title 텍스트 *Your browser may have added “ (1)” to the file name.*이 붙습니다. *saved*는 브라우저의 저장 대화상자가 파일을 쓴 뒤에만 씁니다. Save As 이름 대화상자에는 *Later saves download again under this name; your browser may add “ (1)”.*이 더해집니다. 기록이 파일과 아직 같았던(*same as file X*) 브라우저 복원은 X를 현재 파일로 삼으므로 **Save**는 X로 내려받고 **Save As**는 X를 제안합니다(편집 뒤 *X · changed since restored*).
