# Changed

## English

- Studio: **Compare offers the closed core search** (round 37, D3). When Compare matches no modes and a closed run's note reads *A · Run 2: its modes are mostly in Substrate, which touches the window edge; the core mode was not found.* and that run has no core mode (the T18 closed run as set), a button beside the note reads the shortcut for that run's geometry, *Set search near 2.46 · 4 modes*. Pressing it runs nothing: it makes that run's inputs current, as *Use this run's inputs* does, sets the shortcut (Modes to return nearest to n_eff 2.46, Modes to find 4) and opens Model, where the Messages line is the shortcut's and offers *Show Run 3* when a run already has these results. Undo takes back Modes to find first, then the run's inputs. No button for a run with a core mode, an open run, or matched modes. The matching, Compare's other text, values, file formats, run records and the *Slab modes first* dialog are unchanged. [Workspace](docs/packages/simcase/workspace.md).

## 한국어

- Studio: **Compare가 닫힌 코어 검색을 제안합니다**(37차, D3). Compare가 모드를 하나도 짝짓지 못하고 닫힌 실행의 안내가 *A · Run 2: its modes are mostly in Substrate, which touches the window edge; the core mode was not found.*이며 그 실행에 코어 모드가 없으면(T18에서 그대로 실행한 닫힌 실행), 안내 옆에 그 실행의 형상에 맞는 바로 가기 단추 *Set search near 2.46 · 4 modes*가 나옵니다. 누르면 아무것도 실행하지 않고, *Use this run's inputs*처럼 그 실행의 입력을 현재 입력으로 만들고, 바로 가기를 설정하며(Modes to return은 n_eff 2.46에 가장 가까운 모드, Modes to find는 4) Model을 엽니다. 거기서 Messages 줄은 바로 가기의 문구이며, 이미 이 결과를 가진 실행이 있으면 *Show Run 3*을 제안합니다. Undo는 먼저 Modes to find를, 다음에 그 실행의 입력을 되돌립니다. 코어 모드가 있는 실행, 열린 실행, 짝지어진 모드에는 단추가 없습니다. 짝짓기, Compare의 다른 문구, 값, 파일 형식, 실행 기록과 *Slab modes first* 대화 상자는 바뀌지 않습니다. [Workspace](packages/simcase/workspace.md).
