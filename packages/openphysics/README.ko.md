[영어·한국어 문서와 번역 상태](https://github.com/fieldalgo/openphysics/blob/codex/openphysics-thermal-simcase-release-check/docs/locales/ko/pages/index.md)

OpenPhysics 제품군의 이름 예약 배포판입니다.

이 배포판은 의도적으로 비어 있습니다. OpenPhysics는 각각 독립 설치할 수 있는 여섯 패키지로 개발됩니다.

| 패키지 | 역할 |
|---|---|
| `galerkin` | 유한요소 엔진 |
| `galerkin-refsol` | 엔진 검증에 사용하는 해석적 참조해 |
| `meshine` | 2D 품질 메시 생성기 |
| `gmshio` | Gmsh 실행기와 MSH 판독기 |
| `physmat` | 재료 및 광학 분산 |
| `simcase` | 모델 문서, 헤드리스 실행기, 선택적 브라우저 스튜디오 |

필요한 패키지만 설치하세요. 이 배포판은 향후 릴리스에서 전체 제품군을 함께 설치하는 우산 패키지가 될 예정입니다. 그 전까지는 이름을 예약하고 이 저장소를 안내합니다.

소스: https://github.com/FieldAlgo/openphysics
