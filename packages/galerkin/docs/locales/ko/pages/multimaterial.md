# 이름 있는 영역별 구간 상수 재료

[English original](../../../multimaterial.md)

정상·과도 열전도, 정적 탄성, 처방 온도 기계단계, 정상·과도 열→역학 워크플로는 2D
메시의 이름 있는 영역마다 다른 재료를 줄 수 있습니다.
이 문서는 공통 입력 규칙, 각 계약과 그 독립 검증을 담습니다. 다른 물리는 검증되는
대로 이 문서에 추가하며, 그 전까지 각 문서는 균질 재료 하나만 받는다고 적습니다.

## 입력 규칙

각 재료 물성 인자는 다음 중 정확히 하나를 받습니다.

| 형태 | 의미 |
| --- | --- |
| 유한 실수 스칼라 | 균질 재료 하나(원래 계약, 변경 없음) |
| `{영역 이름: 스칼라}` | 영역마다 값 하나. 키는 `mesh.region_names`와 정확히 같아야 함 |

```python
from galerkin.mesh import layered_rectangle_mesh
from galerkin.thermal import solve_steady_heat

mesh = layered_rectangle_mesh([0.02, 0.05], 0.02, [4, 6], 4, ["steel", "foam"])
dirichlet = {int(i): 400.0 for i in mesh.boundary["left"]}
dirichlet.update({int(i): 300.0 for i in mesh.boundary["right"]})
result = solve_steady_heat(
    mesh,
    conductivity={"steel": 45.0, "foam": 0.04},   # W/(m K)
    heat_source={"steel": 2e5, "foam": 0.0},      # W/m^3
    dirichlet=dirichlet,
)
```

- 영역 이름은 `Mesh.region_names`에서 옵니다: `disk_mesh`,
  `layered_rectangle_mesh`, `layered_annulus_mesh`, 또는 gmshio로 읽은 gmsh 물리
  그룹. `mesh.regions`는 삼각형마다 영역 번호 하나를 가집니다.
- 빠진 이름, 모르는 이름, 문자열이 아닌 키, 물성 자체 검사(예: k <= 0)를 통과하지
  못한 값은 해당 영역 이름을 담은 `ValueError`를 냅니다. 영역 정보가 없는 메시에
  매핑을 주면 거부합니다.
- 물리 API는 맨 삼각형별 배열을 받지 **않습니다**. 길이 M 수열은 벡터·텐서 입력과
  구분되지 않고, 원래 계약도 그런 수열을 거부합니다. 저수준 조립 함수
  (`assemble_stiffness`, 전자기 모드 해석기의 `eps_r`)는 지금처럼 삼각형별 배열을
  받습니다.
- 단위는 스칼라 인자의 단위와 같습니다. 매핑은 단위를 바꾸지 않습니다.
- 스칼라 입력은 원래 코드 경로를 따르므로 균질 결과는 비트 단위로 같습니다. 모든
  영역에 같은 값을 준 매핑은 스칼라와 같은 배열을 냅니다(열: 동일, 탄성: 삼각형별
  구성 행렬 축약의 합산 순서가 달라 상대 1e-12 이내).

재료 물성은 삼각형 안에서 상수입니다. 경계면은 요소 변 위에 있어야 합니다(위
생성기들처럼 영역 경계를 따르는 메시). 삼각형을 가로지르는 영역은 표현할 수 없습니다.

## 정상 열전도

`galerkin.thermal.solve_steady_heat`는 영역별 `conductivity` k > 0(W/(m K))와
영역별 상수 `heat_source` Q(W/m^3)를 받습니다. 스칼라와 기존 좌표 콜백 Q는 그대로
입니다. 약형식은 k와 Q가 삼각형마다 상수인 것 말고는 같습니다.

```text
K_ij = sum_e k_e integral_e grad(N_i).grad(N_j) dA,   f_i = sum_e Q_e integral_e N_i dA
heat_flux_e = -k_e grad(T_h) on triangle e
```

온도는 연속입니다(P1). 정확해의 수직 열유속은 경계면에서 연속이고 기울기는 열전도율
비만큼 뜁니다. 요소 상수 P1 열유속은 이를 극한에서만 만족하며 점프는 O(h)입니다.
완전 열접촉을 가정합니다: 접촉 저항도 경계면 열원도 없습니다. 경계 조건, 반력,
수지 검사는 [thermal_steady2d](thermal_steady2d.md)와
[thermal_flux_robin](thermal_flux_robin.md)과 같습니다.

## 독립 정답

`refsol.thermal_multilayer`는 닫힌 형태 두 개를 계산하며 NumPy만 import합니다.

- `layered_slab`: 직렬 벽 0 < x_1 < ... < x_n = L, 층마다 k_i와 균일 Q_i,
  T(0)=T_L, T(L)=T_R. 열유속 q(x) = q_0 + Q의 적분, T' = -q/k이며 q_0는 T(L)에서
  정해집니다. 열원이 없으면 직렬 열저항 q_0 = (T_L-T_R)/sum(L_i/k_i)입니다.
- `composite_cylinder`: 동심 껍질 r_0 < ... < r_n, k_i와 Q_i, T(r_0)=T_i,
  T(r_n)=T_o. r q_r = C + Q r dr의 적분이고 각 껍질에서
  T = A_i - (C + offset_i) ln(r)/k_i - Q_i r^2/(4 k_i)입니다.

정답 시험은 유한차분만으로 각 층의 푸리에 법칙과 에너지 수지, 모든 경계면의 온도·
열유속 연속, 경계값, 열원 없는 직렬/로그 열저항 공식, 열유속의 반경 방향, 단일층
교과서 공식을 확인합니다. 선택 인자 `layer=`는 층의 닫힌 형태를 해석적 연장으로
계산하므로, 곡선 경계면 바로 바깥에 놓인 다각형 메시 삼각형의 점을 그 삼각형 자신의
재료로 비교합니다.

## 정적 탄성

`galerkin.elasticity.solve_elasticity`는 `young_modulus`(Pa)와 `poisson_ratio`를
각각 스칼라 또는 영역 매핑으로 받습니다. 하나는 스칼라, 다른 하나는 매핑이어도 됩니다.
영역마다 E > 0, -1 < nu < 0.5여야 하며 `plane`('stress' 또는 'strain')은 모든 영역에
적용됩니다. 요소 행렬은 영역 자신의 `D_e`로 `K_e = A_e B_e^T D_e B_e`이고, 보고하는
응력은 `D_e` 곱하기 요소 변형률입니다. 체적력, 견인력, Dirichlet 자료, 반력, 잔차 검사는
그대로입니다([elasticity2d](elasticity2d.md), [elasticity_traction](elasticity_traction.md)).
완전 접합을 가정합니다: 변위는 연속이고, 경계면을 가로지르는 견인력 `sigma.n`은 극한에서만
연속입니다(요소 상수 P1 응력의 O(h) 점프). 이종 재료 자유단의 경계면 응력 특이성은
물리적이며 이 요소로 분해하지 않습니다.

`refsol.elasticity_multilayer`(NumPy만 사용)는 정확한 상태 세 가지를 줍니다.

- `laminate_axial`: 하중 방향에 수직으로 쌓은 층, 균일 축 변형률, 자유면. 변위는 연속
  구간 선형이고 층마다 sigma_xx = E' eps(평면 응력 E' = E, 평면 변형률 E/(1-nu^2)).
- `series_bar`: 균일 sigma_xx 아래 직렬 층. 모든 층의 측면 변형률이 같을 때만
  정확합니다(평면 응력 nu/E 같음, 평면 변형률 nu(1+nu)/E 같음). 그 밖의 자료는 실제 해가
  경계면 특이성을 가지므로 거부합니다.
- `composite_cylinder`: 내·외압을 받는 동심 껍질, 껍질마다 u_r = A_i r + B_i/r,
  변위와 반경 응력 연속. 2n개 계수는 작은 밀집 선형계로 구합니다.

정답 시험은 변위의 중심차분으로 등방 법칙, 응력의 중심차분으로 직교좌표 평형, 경계면의
변위·반경 견인력 연속, 무견인·압력 경계, Voigt 합력, 단일 껍질 교과서 Lamé 공식을
확인합니다.

## 열탄성과 열→역학 연성

`galerkin.thermoelasticity.solve_thermoelasticity`는 `thermal_expansion_per_k`(1/K),
`young_modulus`, `poisson_ratio`를 각각 스칼라 또는 영역 매핑으로 받습니다. 매핑이
하나라도 있으면 삼각형 e는 자신의 `D_e`와 열응력 계수(평면 응력 E/(1-nu), 평면 변형률
E/(1-2nu))를 쓰고, 요소 절점의 열 변형률은 `alpha_e (T - T_ref)`입니다. 열 하중, 중심
값, `sigma_zz`/`epsilon_zz`, 축약 물리 에너지도 같은 삼각형별 값을 씁니다. 결과는 각
재료를 float 또는 `{영역 이름: float}` 사본으로 돌려줍니다. 모두 스칼라인 호출은 원래
코드 경로를 그대로 씁니다.

`galerkin.thermal_mechanical.solve_steady_thermoelasticity`는 `conductivity`,
`young_modulus`, `poisson_ratio`, `thermal_expansion_per_k`, 상수 `heat_source`에
매핑을 받습니다. `input` 단계에서 검증하고 열·기계 단계로 넘깁니다. manifest는 재료를
정렬된 사전으로, 영역별 열원을 `{'kind': 'per_region', 'value': ...}`로 기록하며 스칼라
manifest는 그대로입니다. `galerkin.transient_thermal_mechanical`도 같은 기계 매핑을
받습니다(영역별 과도 열전도는 별도 단계).

**정답.** `thermal_expansions`와 `temperature_change` 행 (a_i, b_i), dT = a_i +
b_i ln(r/r_0)를 준 `refsol.elasticity_multilayer.composite_cylinder`: 각 껍질에서
u_r = kappa_i I(r)/r + A_i r + B_i/r, I = s dT ds의 적분,
kappa_i = beta_i/(lambda_i+2 mu_i)(평면 변형률 beta = (3 lambda + 2 mu) alpha,
평면 응력 E alpha/(1-nu)). 정답 시험은 Timoshenko-Goodier 두꺼운 원통 열응력(온도
적분을 독립 Gauss 적분으로 계산), 단일 재료 균일 가열의 무응력, 유한차분 평형·연속을
재현합니다. 열원 없는 정상 열전도는 각 껍질에서 정확히 dT = a_i + b_i ln(r/r_0)이므로
연성 문제는 두 정답으로 만든 정확해를 가집니다.

바이메탈 띠(Timoshenko 1925)는 자유단 응력 집중을 무시하는 보 이론 근사이므로 수용
기준 정답으로 쓰지 않습니다.

| 경우 | 메시 | 기준 |

## 과도 열전도

`galerkin.transient_heat.solve_transient_heat`는 `conductivity`(W/(m K)),
`volumetric_heat_capacity`(J/(m^3 K)), 상수 `heat_source`(W/m^3)를 스칼라 또는 영역
매핑으로 받습니다. Q 콜백은 그대로입니다. 일관 질량 `M_e = c_e A_e/12 [[2,1,1],[1,2,1],[1,1,2]]`와
강성은 삼각형마다 자기 값을 쓰며, backward Euler, offset, 보정, 모든 잔차·수지 검사는
그대로입니다([transient_heat](transient_heat.md)). 결과는 `conductivity_w_mk`와
`volumetric_heat_capacity_j_m3k`를 float 또는 `{영역 이름: float}` 사본으로 기록합니다.

**정답.** `refsol.transient_heat_multilayer.LayeredWall`: 양끝 온도가 고정된 층상 벽,
T = T_s(x) + sum A_m X_m(x) exp(-lambda_m t). X_m은 X와 k X'가 연속인
-(k X')' = lambda c X의 해입니다. m번째 고유값은 전달 행렬 해의 내부 영점 개수로
이분법을 해서 구하며, 영점 개수는 층마다 Prüfer 위상으로 정확히 셉니다(Sturm 진동
정리). 그래서 두 근이 아무리 가까워도 건너뛰지 않습니다. 초기장을 T_s + sum A_m X_m으로
주면 유한 급수가 정확해입니다. 정답 시험은 단일층 사인 고유값, 2층 특성방정식, m번째
모드의 내부 영점이 정확히 m개인지, 독립적인 고운 1D 유한요소 고유값 풀이와의 일치(상대
1e-4; 시험 벽과, 근이 몰리는 폼/구리/폼 샌드위치 k 0.03/400/0.03), c 가중 직교성,
경계면 연속, 유한차분으로 PDE와 푸리에 법칙, 경계값, 정상 극한을 확인합니다.

첫 버전은 고정된 sqrt(lambda) 격자에서 근 구간을 잡았는데, 검토에서 격자 간격보다 가까운
두 근(대비가 큰 샌드위치 벽)을 건너뛸 수 있음이 드러났습니다. 시험 벽은 영향이 없었고
아래 기록 결과도 그대로입니다.

| 경우 | 메시 / 시간 | 기준 |
| --- | --- | --- |
| 균일 매핑(k, c, Q) 대 스칼라 | 2영역 사각형 | 모든 이력 배열 동일 |
| 독립 밀집 영역별 M·K로 본 BE 단계 | 2층 사각형, 다른 시간 간격 | 자유 잔차 <= 1e-9, 반력·열량 일치 |
| 강철/단열재 벽 10 + 20 mm, k 45/0.5, c 3.6e6/1.2e6, 양끝 400/300 K, 모드 셋 A = 60/-25/10 K | 층상 사각형 [n, 2n] x n, n=1,2,4,8; dt = 1/32 s, 120 s까지; 10, 40, 120 s 관측 | 모든 관측 시각에서 마지막 두 구간 T L2 차수 >= 1.8, 열유속 L2 차수 >= 0.9; n=8에서 dt를 절반으로 하면 모든 오차 변화 <= 5% |

| 잘못된 영역 | — | 빠진/모르는 이름, k나 c <= 0, 비유한 Q, 맨 배열, 영역 정보 없는 매핑은 `ValueError`; 실수가 아닌 영역 값은 영역 이름이 붙은 메시지 |

## 레퍼런스 도구 비교

수용 여부는 위의 해석 기준이 정합니다. 그와 별도로 같은 문제를 scikit-fem 12.0.2
(BSD-3-Clause)로도 풀었습니다. 두 도구의 일치는 코드 대 코드 근거이지 수렴 근거가 아닙니다.

- CI에서 `tests/test_crosscheck_skfem_multimaterial.py`가 세 영역 벽을 같은 메시와 같은
  삼각형별 값으로 두 도구에서 풉니다: 정상 열전도, 두 평면의 탄성과 열탄성, backward Euler
  과도 열전도. 온도·변위·열유속·응력이 1.6e-12 이내로 일치하며 기준은 1e-9입니다
  ([레퍼런스 비교](https://github.com/fieldalgo/openphysics/blob/main/docs/locales/ko/pages/reference-comparisons.md)).
- 별도 연구(2026-10-19)에서 정상 열전도, 탄성, 열탄성, 강철/단열재 벽 과도 기준 문제를 네 메시
  수준 모두에서 반복했습니다. 벽 B와 영점 개수 고유값 탐색을 넣기 전 코드였으므로, 벽 B와 그
  잘못된 물성 검사는 아직 도구 비교가 없습니다. 같은
  메시 P1 필드는 1.4e-12(온도·변위), 6.2e-11(열유속·응력) 이내로 일치했습니다. 같은
  refsol 정답에 대한 scikit-fem P2 결과가 정답을 확인했습니다: 직선 변 고리 메시에서는 다각형
  형상 때문에 P2가 약 2차에 머물고, 곡선 형상의 isoparametric P2는 약 3차에 이릅니다. 열원이
  있는 층상 벽(dt = 1/4 s)에서는 scikit-fem P2도 가장 고운 메시에서 공간 차수를 잃었고 시간
  Richardson 외삽으로 되찾았으므로, 그 구성은 공간 이산화가 아니라 backward Euler 시간 오차가
  지배했습니다.
