# OpenPhysics contributor instructions

Read [CLAUDE.md](CLAUDE.md) for repository layout, validation and bilingual
documentation rules. Use `main` as the only trunk; follow CONTRIBUTING.md for PRs, required CI and exact-commit fast-forward landing. Documentation changes also require CI. Keep private material,
credentials and generated artifacts out of the repository. GitHub Actions is enabled. Review the exact workflow run and its artifacts
before treating a candidate as validated.
