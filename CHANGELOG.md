# Changelog

All eight OpenPhysics distributions (`galerkin`, `galerkin-refsol`, `meshine`,
`gmshio`, `physmat`, `simcase`, `sipi` and the `openphysics` meta distribution) release
together under one version number. This file records what each release changes.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
[한국어](docs/locales/ko/pages/changelog.md)

## Stability in 0.x

0.x releases are alphas.

- The Python API of every package may change in any minor release (0.1 to 0.2).
  Patch releases (0.1.x) fix bugs and are not meant to change the API.
- The JSON model document format `"openphysics": "0.2"` is a contract: a document
  that is valid in this format keeps validating and keeps its meaning. A change
  that would break that gets a new format version.
- Saved result format and field layout identifiers, such as
  `thermal.steady2d-result-v1` or `cavity3d-edge-v1`, are contracts: a file
  carrying an identifier keeps that layout. A changed layout gets a new identifier.

What each package implements, and its limits, is in the
[overview](docs/overview.md).

- `galerkin`: shape derivatives of transient heat: `solve_transient_heat(..., motion=MeshMotion(W, t))` solves the backward-Euler history on the nodes X₀ + t·W, with the initial and Dirichlet temperatures attached to their nodes, and every history (temperature, flux, loads, reaction, residual, storage, heat content, quadratic functional, outward rates) carries the derivative with respect to the JAX or PyTorch scalar t. Region k and c, a constant or region source, and outward flux and convection on moving edges are taken; callbacks of time alone are allowed. Coordinate callbacks, live inputs with a motion, axisymmetric heat and `checkpoint_every` are refused by name. Without `motion` results are unchanged. [Documentation](docs/packages/galerkin/shape_derivative.md#transient-heat).
- `galerkin`: shape derivatives of thermoelasticity (approved 2026-11-10): `solve_thermoelasticity(mesh, snapshot, ..., motion=MeshMotion(W, t))` keeps the snapshot's nodal temperatures attached to their moving nodes, and `solve_steady_thermoelasticity(..., motion=)` solves the heat stage again on the moving mesh so the derivative includes the change of the temperature field. Displacement, strains, stress, σzz, εzz, loads, reaction, residual and the physical elastic energy (and the workflow's heat result) carry the derivative with respect to the JAX or PyTorch scalar t. Callbacks and live coefficients, temperatures or loads with a motion are refused by name. Without `motion` results are unchanged. [Documentation](docs/packages/galerkin/shape_derivative.md#thermoelasticity).

- `galerkin`: `solve_modes` does not return roots of the vector formulation's static β² = 0 family with `|β²| ≤ STATIC_ROOT_TOL·|σ|` (`STATIC_ROOT_TOL = 1e-10`, that is `|n_eff| ≤ 1e-5·|n_target|`). A 0-d complex JAX or PyTorch input (for example `2 - 0.1j * t`) no longer fails when its numbers are read. Real inputs give the same results.

### Added

### Changed

- `openphysics` is a meta distribution: it has no code and requires the six
  implementation packages. Its extras `studio`, `export` and `rii` install
  `simcase[studio]`, `simcase[export]` and `physmat[rii]`. No extra installs Gmsh.
  The earlier `openphysics` 0.0.1 was an empty name reservation, like the 0.0.1
  of the other six names.
- Every package requires Python 3.12 or later. The minimum numpy, scipy, shapely
  and matplotlib are now 1.26, 1.11.2, 2.0.2 and 3.8, their first releases with
  Python 3.12 wheels.
- Requirements between the packages are limited to the 0.0 series
  (`>=0.0.2,<0.1`).
